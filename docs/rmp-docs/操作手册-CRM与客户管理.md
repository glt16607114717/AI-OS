# 操作手册 - CRM 与客户管理

> 本手册面向 RMP 平台业务人员（销售、市场、客户项目经理、运维等角色），介绍 CRM 与客户管理模块的用途、页面入口、操作流程、校验规则和状态流转。
>
> 本手册**不包含**数据库表结构、字段类型、SQL 等技术细节。

---

## 模块总览

CRM 与客户管理模块覆盖从"线索 → 客户 → 部署"的完整业务闭环，主要解决以下问题：

1. **线索管理**：录入线索、领取/分配线索、跟进、作废、转入客户池
2. **客户管理**：客户信息登记、客户详情、客户经理绑定、客户状态流转
3. **客户生命周期**：潜在 → 意向 → 试运行 → 正式 → 终止 / 撤回
4. **部署交付**：部署计划、部署清单、部署验收、作业证（上岗订单）
5. **加盟信息登记**：外部人员加盟信息收集

## 一、我的客户（myCustomer）

### 【用途】
展示当前用户负责的客户列表，支持按"未跟进 / 已跟进 / 作废"三个状态筛选，查看客户详情、跟进客户、修改客户信息。

### 【页面路径】
- 菜单路径：CRM → 我的客户
- 前端路由：`/CRM/myCustomer`

### 【主要功能】
页面顶部为 Tab 切换区，下方为筛选区和数据表格。

**Tab 分类：**

| Tab 名称 | 说明 |
|---------|------|
| 未跟进客户（默认） | 需要跟进的客户 |
| 已跟进客户 | 已有跟进记录的客户 |
| 作废 | 已作废的客户 |

**常用筛选条件：**
- 客户编号（支持排序）
- 客户等级、客户来源
- 工人规模、参保人数（区间筛选）
- 已部署机器人数、剩余保护期（区间筛选）
- 市场经理、销售代表、销售助理
- 客户状态

**操作按钮：**
- 刷新：重新加载列表
- 重置：清空所有筛选条件

### 【操作步骤】
1. 进入"CRM → 我的客户"
2. 通过顶部 Tab 选择客户类型（未跟进/已跟进/作废）
3. 使用筛选条件查找目标客户
4. 点击客户名称或"查看"进入客户详情页（跳转至 myCustomerDetails）

### 【校验规则】
- 列表查询无特殊校验
- 点击客户需有查看权限

### 【状态说明】
- 客户状态会显示在列表中，常见状态：潜在、意向、试运行、正式、终止、撤回等

### 【常见问题】
- **Q：为什么看不到某些客户？**
  A：客户数据有权限范围限制（仅本人/本公司/子公司），请联系管理员确认数据可见范围。
- **Q：如何快速找到某个客户？**
  A：使用客户编号或客户名称进行全文检索（esSearch）。

## 二、客户详情 / 编辑（myCustomerDetails / editCustomer / seeCustomer）

### 【用途】
查看客户完整信息、编辑客户基础信息、跟进客户、管理联系人、场地、子公司、档案等。这三个页面共享同一个详情组件（clueDetails），根据来源（type 参数）显示不同的操作按钮。

### 【页面路径】
- 菜单路径：从客户列表点击客户名称进入
- 前端路由：`/CRM/myCustomerDetails?id=xxx`、`/customerManage/editCustomer?id=xxx`、`/customerManage/seeCustomer?id=xxx`

### 【主要功能】
详情页分为多个信息区块，并带有操作按钮区。

**顶部操作按钮（根据权限和状态显示）：**
- 跟进：进入跟进编辑模式
- 跳转至客户运营：仅在正式客户详情显示
- 作废：作废当前客户/线索
- 移入客户池：将客户移入公海
- 转为潜在客户：将线索转为客户
- 保存：保存修改
- 删除：删除线索/客户（仅客户池/公海可用）
- 取消：退出编辑
- 锁定客户/锁定线索：锁定防止他人编辑

**信息区块：**
1. **创建信息**：客户来源、创建时间、销售代表、销售助理、市场经理、创建人等
   - 客户来源选择"介绍人"时，需选择介绍人
   - 客户来源选择"介绍客户"时，需选择介绍客户
   - 客户来源选择"展会"时，需填写展会名称和展会开始时间
2. **基础信息**：客户名称、客户简称、统一社会信用代码（含查重按钮）、固定电话、法定代表人、注册资本、主要客户品牌、参保人数、主场地名称、地区、详细地址、成立时间、网址
3. **联系人**：联系人名称、手机号、联系电话、职位（可添加多个）
4. **参数信息**：现场面积、日结时间点、正常待料时间上限、夜班、第三个月平均结算、公司规模、工人规模、临时工工资等
5. **行业信息**：所属行业、工艺类别、产品类别、产品名称、自动化程度、导入意向程度、预计可导入机器人数量

### 【操作步骤】
1. 从客户列表进入客户详情
2. 点击"跟进"按钮进入编辑模式
3. 修改各信息区块内容
4. 点击"保存"提交修改
5. 如需作废，点击"作废"按钮（需填写作废原因）

### 【校验规则】
- 客户名称：必填，最多 50 字符
- 客户简称：必填，最多 50 字符
- 省份：必填
- 城市：必填
- 详细地址：必填
- 参保人数：必填，必须为正整数且大于 0
- 客户联系人：至少需要 1 个联系人（姓名、职位、手机号或联系电话必填）
- 联系人手机号：需符合手机号格式
- 联系人联系电话：需符合座机号格式
- 公司规模、工人规模、临时工规模等：必须为正整数
- 现场面积：必须为数字
- 统一社会信用代码：转意向客户时必填
- 若客户来源为"介绍人"：需选择介绍人
- 若客户来源为"介绍客户"：需选择介绍客户
- 若客户来源为"展会"：需填写展会名称和展会日期

### 【状态说明】
- 编辑模式可修改信息，查看模式为只读
- 锁定状态下只有锁定人可编辑

### 【常见问题】
- **Q：统一社会信用代码查重提示已存在怎么办？**
  A：说明该客户已被他人录入，请确认是否为同一客户，避免重复创建。
- **Q：为什么某些按钮不显示？**
  A：按钮显示受权限和客户状态控制，如"转为潜在客户"仅在特定状态显示。

## 三、正式客户（officialCustomer）

### 【用途】
展示所有正式客户（含已部署机器人的客户），支持多维度筛选和查看，可进行客户回收操作。

### 【页面路径】
- 菜单路径：CRM → 正式客户
- 前端路由：`/CRM/officialCustomer`

### 【主要功能】
**Tab 分类：** 按客户状态分类（潜在/意向/试运行/正式等）

**筛选条件：**
- 客户名称、联系人名称、联系电话
- 所属地区（省/市/区）
- 产品类别、统一社会信用代码
- 创建时间范围、跟进时间范围
- 行业、工艺类型
- 参保人数、工人规模（区间）
- 市场经理、销售代表、销售助理
- 客户来源、客户等级

**操作按钮：**
- 刷新、重置
- 客户回收（recoveryCustomer）

### 【操作步骤】
1. 进入"CRM → 正式客户"
2. 通过筛选条件查找目标客户
3. 点击客户名称进入详情
4. 如需回收客户，点击"回收"按钮

### 【校验规则】
- 回收客户时需提供线索 ID

### 【状态说明】
- 回收后客户将回到公海/客户池

### 【常见问题】
- **Q：正式客户和我的客户有什么区别？**
  A："我的客户"只显示当前用户负责的客户；"正式客户"显示权限范围内所有客户。

## 四、客户信息登记（addCustomer / newCustomer）

### 【用途】
新建客户信息，填写完整的客户基础资料、联系人、场地等信息，并提交审核流程。

### 【页面路径】
- 菜单路径：客户管理 → 客户信息登记（新增）
- 前端路由：`/customerManage/addCustomer`、`/CRM/newCustomer`

> 注意：`newCustomer` 实际复用了"新建线索"表单组件（setClues），支持线索和客户两种录入模式。

### 【主要功能】
**顶部操作：**
- Tab 切换（多页签信息录入）
- 保存、取消按钮
- 审批流程按钮（提交审核、审批等）

**表单区块：**

1. **创建信息**
   - 客户来源（下拉选择）
   - 介绍客户（来源为"介绍客户"时显示）
   - 介绍人（来源为"介绍人"时显示）
   - 展会开始时间、展会名称（来源为"展会"时显示）
   - 创建时间（自动填充）
   - 销售代表（必填，非线索池时）
   - 销售助理
   - 市场经理
   - 创建人（自动填充）

2. **基础信息**
   - 客户名称（必填）
   - 统一社会信用代码（含"查重"按钮）
   - 客户简称（必填）
   - 固定电话
   - 法定代表人
   - 注册资本
   - 主要客户品牌
   - 参保人数（必填，正整数）
   - 主场地名称
   - 地区（必填，省市区联动选择）
   - 详细地址（必填，含"新增其他场地"按钮）
   - 成立时间
   - 网址

3. **联系人**（可添加多个）
   - 联系人名称
   - 手机号
   - 联系电话
   - 职位

4. **参数信息**
   - 现场面积
   - 日结时间点
   - 正常待料时间上限
   - 夜班（是/否）→ 白班/夜班比例、夜班开始/结束时间
   - 是否第三个月平均结算
   - 公司规模、工人规模、临时工规模/工资
   - 工人工资、计工方式

5. **行业信息**
   - 所属行业
   - 工艺类别
   - 产品类别、产品名称
   - 自动化程度、导入意向程度
   - 预计可导入机器人数量

6. **多媒体资料**
   - 外部照片/视频
   - 现场照片/视频
   - 产品照片/视频
   - 工艺照片/视频
   - 推荐工位照片/视频

### 【操作步骤】
1. 进入"客户信息登记"页面
2. 选择客户来源
3. 依次填写创建信息、基础信息、联系人、参数信息、行业信息
4. 点击统一社会信用代码旁的"查重"按钮，确认客户是否已存在
5. 点击"保存"暂存信息，或点击"提交审核"走审批流程
6. 在审批流程中，审批人可"通过"或"驳回"

### 【校验规则】
- 客户名称：必填，最多 50 字符
- 客户简称：必填，最多 50 字符
- 省份：必填
- 城市：必填
- 详细地址：必填
- 参保人数：必填，必须为正整数且大于 0
- 销售代表：非线索池新建时必填
- 统一社会信用代码：状态为"意向"时必填
- 若来源为"介绍人"：介绍人必填
- 若来源为"介绍客户"：介绍客户必填
- 若来源为"展会"：展会名称和展会日期必填
- 联系人手机号：需符合手机号格式校验
- 联系人联系电话：需符合座机号格式校验
- 公司规模、年营业额、工人规模、工人工资、临时工规模、临时工工资、夜班人数、白班人数：必须为正整数
- 现场面积：必须为数字（浮点）
- 预计可导入机器人数量：必须为正整数

### 【状态说明】
- 草稿：保存但未提交审核
- 待审核：已提交审核，等待审批
- 审核通过：审批通过，转为正式客户信息
- 审核驳回：审批未通过，退回修改

### 【常见问题】
- **Q：保存后找不到客户？**
  A：草稿状态的客户只有创建人可见，确认是否已提交审核。
- **Q：统一社会信用代码查重显示已存在？**
  A：该客户可能已被他人录入，请联系管理员确认。
- **Q：提交审核后还能修改吗？**
  A：审核中无法修改，需等审批结果。如需修改，可联系审批人驳回。

## 五、我的线索（myClues）

### 【用途】
展示当前用户负责的线索列表，支持领取线索、分配线索、跟进、转为客户等操作。此页面与"线索池"共享同一个组件（publicAssembly），通过 type 参数区分。

### 【页面路径】
- 菜单路径：CRM → 我的线索
- 前端路由：`/CRM/myClues`

### 【主要功能】
**Tab 分类：** 按线索状态分类（待跟进/跟进中/已作废等）

**操作按钮：**
- 录入线索：新建线索（跳转至 newClue）
- 批量导入：通过 Excel 批量导入线索
- 刷新、重置

**筛选条件：**
- 客户名称、联系人名称、联系电话、产品
- 所属地区、创建时间范围
- 行业、工艺类型、客户来源、客户等级
- 参保人数、工人规模（区间）
- 销售代表、市场经理、销售助理

### 【操作步骤】
1. 进入"CRM → 我的线索"
2. 点击"录入线索"新建线索，或通过筛选查找已有线索
3. 点击线索名称进入线索详情
4. 在详情页可进行：跟进、转为潜在客户、移入客户池、作废等操作

### 【校验规则】
- 批量导入仅支持 .xls / .xlsx 格式，不支持 .csv
- 领取线索前系统会校验当月领取额度

### 【状态说明】
线索常见状态：
- 待跟进：新建或领取后未跟进
- 跟进中：已有跟进记录
- 已作废：被作废的线索
- 保护期内：有保护期限制，他人不可领取

### 【常见问题】
- **Q：为什么领取线索按钮不可点击？**
  A：可能已达当月领取上限，或无领取权限。
- **Q：线索的保护期是什么？**
  A：领取线索后会进入保护期，保护期内他人无法领取该线索。

## 六、线索池 / 公海（cluePool / highSeas）

### 【用途】
- **线索池（cluePool）**：展示未被分配的线索，管理员可分配销售、分配市场、回收线索。
- **客户池 / 公海（highSeas）**：展示回收/未分配的客户，支持领取客户、分配销售、分配市场。

### 【页面路径】
- 菜单路径：CRM → 线索池、CRM → 客户池（公海）
- 前端路由：`/CRM/cluePool`、`/CRM/highSeas`

### 【主要功能】

**线索池（cluePool）操作按钮（根据权限显示）：**
- 录入线索、批量导入
- 回收（cluePoolRecovery）：回收已分配的线索
- 领取线索（cluePoolCollectClue）：领取线索到自己名下
- 分配销售（cluePoolAllocateSales）：将线索分配给指定销售
- 分配市场（clueCistributionMarket）：将线索分配给指定市场经理
- 刷新、重置

**客户池 / 公海（highSeas）操作按钮：**
- 领取客户（highSeasCustomerAcquisition）：领取客户到自己名下
- 分配销售（highSeasDistributionSales）：将客户分配给指定销售
- 分配市场（highSeasCistributionMarket）：将客户分配给指定市场经理
- 刷新、重置

**分配弹窗（selectClue / DistributionMarket）：**
- 勾选要操作的线索/客户
- 选择分配至公司
- 选择分配至人员
- 确认分配

### 【操作步骤】
**分配线索/客户：**
1. 进入"线索池"或"客户池"
2. 勾选目标线索/客户（表格多选）
3. 点击"分配销售"或"分配市场"
4. 在弹窗中选择分配公司和分配人员
5. 点击确认完成分配

**领取线索/客户：**
1. 进入"线索池"或"客户池"
2. 勾选目标线索/客户
3. 点击"领取线索"或"领取客户"
4. 系统校验领取额度后完成领取

**回收线索：**
1. 进入"线索池"
2. 切换到已分配的 Tab
3. 勾选目标线索
4. 点击"回收"

### 【校验规则】
- 分配销售时：销售代表必填
- 分配市场时：市场经理和公司必填
- 领取时：系统校验当月领取上限和今日剩余额度
- 领取线索需有领取权限（receive_clue_per）

### 【状态说明】
- 线索/客户在池中为"未分配"状态
- 领取后进入"保护期"
- 分配后归属于指定销售人员

### 【常见问题】
- **Q：分配时提示"请选择分配公司"？**
  A：分配市场和分配销售需要先选择公司，再选择人员。
- **Q：领取提示额度不足？**
  A：当月领取数量已达上限，请次月再领取或联系管理员调整额度。

## 七、新建线索（newClue）

### 【用途】
录入新的线索信息，填写客户基础资料和业务信息。此页面复用"新建客户"表单组件（setClues），支持线索录入模式。

### 【页面路径】
- 菜单路径：CRM → 我的线索 → 录入线索
- 前端路由：`/CRM/newClue`

### 【主要功能】
表单与"客户信息登记"基本一致，包含：
- 创建信息（客户来源、销售代表、市场经理等）
- 基础信息（客户名称、简称、统一社会信用代码含查重、地址等）
- 联系人（可添加多个）
- 参数信息（现场面积、夜班、规模等）
- 行业信息
- 多媒体资料

**操作按钮：**
- 保存：保存线索
- 取消：返回上一页

### 【操作步骤】
1. 从"我的线索"或"线索池"点击"录入线索"
2. 选择客户来源（如介绍人/介绍客户/展会等会显示额外字段）
3. 填写基础信息，点击"查重"确认统一社会信用代码
4. 添加联系人信息
5. 填写参数和行业信息
6. 点击"保存"

### 【校验规则】
- 客户名称：必填
- 客户简称：必填
- 省份：必填
- 城市：必填
- 客户来源：必填
- 详细地址：必填
- 参保人数：必填，正整数且大于 0
- 销售代表：从"我的线索"进入时必填
- 统一社会信用代码：状态为意向（status=2）时必填
- 介绍人：来源为"介绍人"时必填
- 介绍客户：来源为"介绍客户"时必填
- 展会名称、展会日期：来源为"展会"时必填
- 联系人手机号：需符合手机号格式
- 联系人联系电话：需符合座机号格式

### 【状态说明】
- 新建线索默认为"待跟进"状态
- 线索有保护期机制

## 八、线索详情（clueDetails）

### 【用途】
查看和编辑线索完整信息，进行跟进、转为客户、移入客户池、作废等操作。此组件同时用于"我的客户详情"。

### 【页面路径】
- 从线索列表或客户列表点击进入
- 前端路由：`/CRM/clueDetails?id=xxx&type=myClues`

### 【主要功能】
**顶部操作按钮（根据来源 type 和权限显示）：**
- 跟进：进入编辑模式
- 作废：作废线索（需填写作废原因）
- 移入客户池：将线索移入公海
- 转为潜在客户：将线索转为客户
- 保存：保存修改
- 删除：删除线索（仅客户池/公海可用）
- 取消：退出编辑
- 锁定线索：锁定防止他人编辑
- 跳转至客户运营：仅正式客户显示

**信息区块：**
1. **创建信息**（含剩余保护期天数显示）
2. **基础信息**
3. **联系人**
4. **参数信息**
5. **行业信息**
6. **跟进记录**：查看历史跟进、添加新跟进、回复跟进
7. **变更记录**：查看线索状态变更历史
8. **邮寄记录**：查看/添加邮寄记录

### 【操作步骤】
**跟进线索：**
1. 进入线索详情
2. 点击"跟进"按钮进入编辑模式
3. 修改信息后点击"保存"
4. 在跟进记录区添加跟进内容

**转为潜在客户：**
1. 进入线索详情
2. 确认联系人信息完整（姓名、职位、电话必填）
3. 点击"转为潜在客户"
4. 系统校验联系人信息后完成转换

**移入客户池：**
1. 进入线索详情
2. 点击"移入客户池"
3. 确认操作

**作废线索：**
1. 进入线索详情
2. 点击"作废"
3. 填写作废原因
4. 确认作废

### 【校验规则】
- 转为潜在客户前：必须至少有 1 个联系人，且联系人姓名、职位、电话（手机号或座机）不能为空
- 作废时：作废原因必填
- 线索基础信息校验与新建线索一致

### 【状态说明】
- 待跟进 → 跟进中 → 转为客户 / 移入客户池 / 作废
- 锁定状态下其他用户不可编辑

### 【常见问题】
- **Q：转为潜在客户提示"请先添加客户联系人信息"？**
  A：转为客户前必须添加至少一个完整的联系人（姓名、职位、电话）。
- **Q：移入客户池后还能找回吗？**
  A：可以，在"客户池"中可以找到并重新领取或分配。

## 十、公海规则（publicAssembly）

### 【用途】
"公海规则"是"我的线索"和"线索池"的共享列表组件（publicAssembly），负责展示线索列表、提供筛选和批量操作能力。它不是一个独立的"规则配置"页面，而是线索列表的通用框架。

### 【页面路径】
- 被 `/CRM/myClues`（type=myClues）和 `/CRM/cluePool`（type=cluePool）调用

### 【主要功能】
**根据 type 参数动态显示不同按钮：**

**线索池（cluePool）专属按钮：**
- 回收（仅已分配状态显示）
- 领取线索（未分配状态显示，校验领取权限）
- 分配销售（未分配状态显示）
- 分配市场（未分配状态显示）

**通用按钮：**
- 录入线索：新建线索
- 批量导入：Excel 导入线索
- 刷新、重置

**分配弹窗组件：**
1. **selectClue**：用于回收、领取、分配销售等操作
   - 显示勾选的线索列表
   - 领取时显示当月额度信息（当月最多领取数、已领取数、今日剩余）
   - 分配时选择分配公司和人员
2. **DistributionMarket**：用于分配市场
   - 勾选线索
   - 选择分配公司
   - 选择分配人员
3. **promptBox**：线索池分配提醒
4. **promptTest**：社会统一信用代码已存在提醒

### 【操作步骤】
详见"我的线索"（五）和"线索池"（六）。

### 【校验规则】
- 领取线索前系统校验：
  - 当月领取上限
  - 今日剩余领取额度
  - 是否有领取权限
- 分配时公司和人员必填
- 批量导入仅支持 Excel 格式

### 【常见问题】
- **Q：领取额度如何计算？**
  A：系统按月计算领取上限，显示格式为"当月最多领取X条，已领取Y条，今日还可领取Z条"。

## 十二、部署计划 / 验收 / 清单（deploymentPlan / deploymentAccept / deploymentList）

### 【用途】
管理机器人部署的完整流程：
- **部署计划（deploymentPlan）**：制定客户合作期前 12 周的生产计划和进场部署计划。
- **部署验收（deploymentAccept）**：部署完成后进行验收，记录各项验收结果。
- **部署清单（deploymentList）**：查看和导出部署设备清单。

### 【页面路径】
- 部署计划：`/customerManage/deploymentPlan?id=xxx`
- 部署验收：`/customerManage/deploymentAccept?id=xxx`
- 部署清单：`/customerManage/deploymentList?work_station_ids=xxx`

### 【主要功能】

#### 部署计划（deploymentPlan）
**操作按钮：** 编辑、保存、打印

**内容区块：**
1. **合作期前 12 周生产计划**
   - 起始日期（年/月/日输入）
   - 表格：产品名称 × 12 周产量计划
   - 可新增一行
   - 注：最少填报 4 周

2. **进场部署计划**
   - 进场起始日期
   - 表格：部署计划项 / 时序安排 / 客户协助
   - 包含：设备运输到场、设备安装、联调测试、试产验收等步骤

#### 部署验收（deploymentAccept）
**操作按钮：** 编辑、保存、打印

**表头信息：**
- 客户名称、工位名称、工位编号、订单编号
- 验收日期（日期选择）、产品名称

**验收项目表格：**
| 项次 | 验收内容 | 验收标准 | 标准值 | 检查结果 |
|------|---------|---------|--------|---------|
| 1 | 产能验收 | 实际产能是否达到上岗单产能要求的 100% | 上岗单签订的产能 | OK / NG |
| 1 | 验收实际产能 | - | - | OK / NG |
| 2 | 现场部署 | 线路气管和控制器固定 | 控制盒摆放规范 | OK / NG |
| ... | ... | ... | ... | ... |

#### 部署清单（deploymentList）
**操作按钮：** 导出（PDF）、返回

**内容：** 展示各工位的部署设备明细和金额合计

### 【操作步骤】
**部署计划：**
1. 进入部署计划页面
2. 点击"编辑"进入编辑模式
3. 填写起始日期和 12 周生产计划
4. 填写进场部署计划
5. 点击"保存"
6. 可点击"打印"输出纸质文档

**部署验收：**
1. 进入部署验收页面
2. 点击"编辑"
3. 选择验收日期，填写产品名称
4. 逐项勾选验收结果（OK / NG）
5. 点击"保存"
6. 验收完成后可"打印"验收单

**部署清单：**
1. 从工位管理页面跳转进入（携带 work_station_ids 参数）
2. 查看设备清单
3. 点击"导出"下载 PDF

### 【校验规则】
- 部署清单需要 work_station_ids 参数，缺少参数会提示错误
- 部署计划生产计划最少填报 4 周

### 【状态说明】
- 部署计划：编辑 / 已保存
- 部署验收：待验收 / 已验收

### 【常见问题】
- **Q：部署清单页面提示"缺少工作站 ID 参数"？**
  A：需要从工位管理页面进入，不能直接访问 URL。

## 十三、作业证（workPermit）

### 【用途】
机器人工位上岗订单（作业证），定义工位的计价方式、保底产能、价格等，并走审批流程。是机器人正式上岗的服务合同凭证。

### 【页面路径】
- 前端路由：`/customerManage/workPermit?id=xxx`

### 【主要功能】
**操作按钮（受审批流程控制）：**
- 编辑（workPermitEdit）：进入编辑模式
- 保存（workPermitSave）：保存修改
- 打印（workPermitPrint）：打印作业证
- 审批流程按钮：提交、审批、驳回、反审核等

**表头信息（甲乙方信息）：**

| 甲方（客户） | 乙方（服务方） |
|-------------|--------------|
| 客户名称 | 公司名称 |
| 联系人 | 联系人 |
| 电话 | 电话 |
| 地址 | 地址 |

**工位计价表格：**

| 列名 | 说明 | 必填 |
|------|------|------|
| 工位名称 | 选择工位 | 是 |
| 工位所在位置（坐标） | 填写坐标 | 是 |
| 工位编号 | 自动带出 | 是 |
| 工件/产品名称 | 填写产品 | 是 |
| 机器人数量 | 填写数量 | 是 |
| 班次类型 | 选择班次 | 是 |
| 计价方式 | 计时/计件 | 是 |
| 保底工时/保底计件 | 填写保底值 | 是 |
| 未税价 | 填写价格 | 是 |
| 含税价 | 填写价格 | 是 |
| 备注 | 选填 | 否 |

**操作：** 新增（添加工位行）、删除行

### 【操作步骤】
1. 进入作业证页面
2. 点击"编辑"
3. 确认甲乙方信息
4. 点击"新增"添加工位计价行
5. 填写工位名称、坐标、产品、数量、班次、计价方式、价格等
6. 点击"保存"
7. 提交审批流程
8. 审批通过后可"打印"作业证

### 【校验规则】
- 工位名称、坐标、编号、产品名称、机器人数量、班次类型：必填
- 计价方式、保底值、未税价、含税价：必填
- 审批流程状态值：1-5

### 【状态说明】
作业证审批状态流转：
- 草稿 → 待审批 → 审批中 → 已通过 / 已驳回
- 已通过的作业证可反审核（backAudit）退回

### 【常见问题】
- **Q：打印按钮不可点击？**
  A：打印功能在审批通过后（非编辑状态）才可用。
- **Q：如何修改已审批的作业证？**
  A：需先"反审核"退回草稿状态，再编辑修改。
