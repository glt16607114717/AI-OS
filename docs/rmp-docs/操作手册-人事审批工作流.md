# RMP 平台操作手册 - 人事、审批与工作流

> 适用角色：HR、部门主管、审批人、普通员工  
> 本文档为业务操作指南，不涉及数据库表结构、字段类型、SQL 等技术细节。

---

## 一、员工信息

### 【用途】
管理公司全体员工的个人档案信息，包括基本信息、紧急联系人、教育经历、工资卡、证件照片等。支持新增、编辑、查看、导入、导出。

### 【页面路径】
- 列表页：侧边菜单 → 人事管理 → 员工信息
- 详情页：点击列表行或"查看"按钮
- 新增页：点击列表页"新增"按钮
- 编辑页：点击列表行"编辑"按钮

### 【主要功能】

#### 1. 员工信息列表页
**页面元素：**
| 元素 | 说明 |
|------|------|
| 新增按钮 | 跳转到新增员工页面（需权限 `hrManageEmployeeAdd`） |
| 导入按钮 | 上传 Excel 批量导入员工信息（需权限 `hrManageEmployeeImport`） |
| 导出人员明细按钮 | 导出选中或全部员工数据为 Excel（需权限 `hrManageEmployeeExport`） |
| 刷新按钮 | 刷新列表数据 |
| 表格列 | 职工姓名、公司、部门、职位、入职时间、离职时间、联系方式、员工状态、直属领导、目前住址、备注 |
| 操作列 | 查看、编辑 |
| 表头筛选 | 可按职工姓名、公司、部门、职位、入职时间、离职时间、联系方式、员工状态进行筛选和排序 |

**操作步骤：**
1. 进入"员工信息"页面，系统自动加载员工列表
2. 点击表头筛选图标可按条件过滤（如按"在职状态"筛选在职/离职/试用）
3. 点击入职时间/离职时间列筛选可选择日期范围
4. 勾选行前方的复选框可选择多条记录
5. 点击"导出人员明细"：勾选则导出选中行，未勾选则导出全部查询结果
6. 点击"导入"：弹出上传窗口，支持 .xlsx/.xls 格式，文件不超过 10M

#### 2. 新增/编辑员工信息页
**页面分区：**

**（1）职工信息明细**
| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 员工姓名 | 文本输入 | 是 | 最多50字符 |
| 出生日期 | 日期选择 | 是 | |
| 籍贯 | 下拉选择 | 是 | 省/直辖市列表 |
| 性别 | 下拉选择 | 是 | 男/女 |
| 民族 | 下拉选择 | 是 | 56个民族列表 |
| 婚姻状况 | 下拉选择 | 是 | 已婚/未婚/离异/其他 |
| 手机号 | 文本输入 | 是 | 11位手机号，格式 `1[3-9]xxxxxxxxx` |
| 所属公司 | 下拉选择 | 是 | 选择后联动加载部门树 |
| 职位 | 文本输入 | 是 | |
| 所属部门 | 级联选择 | 是 | 根据公司联动加载 |
| 直属领导 | 下拉选择 | 是 | 根据部门联动加载该部门员工 |
| 个人邮箱 | 文本输入 | 是 | 标准邮箱格式 |
| 身份证号 | 文本输入 | 是 | 18位身份证号，需校验格式 |
| 户口类型 | 下拉选择 | 是 | 本地城镇/本地农村/外地城镇(省内)/外地农村(省内)/外地城镇(省外)/外地农村(省外) |
| 入职日期 | 日期选择 | 是 | |
| 公司邮箱 | 文本输入 | 是 | 标准邮箱格式 |
| 兴趣特长 | 文本输入 | 否 | |
| 住址 | 文本输入 | 否 | |
| 备注 | 文本输入 | 否 | |

**（2）紧急联系人信息**
- 默认提供3个紧急联系人空行
- 每条包含：姓名、电话（11位手机号）、与本人关系
- 至少保留1个，最多5个
- 点击 `+` 按钮新增行，点击 `-` 按钮删除行

**（3）教育经历**
- 每条包含：学历（小学~博士）、毕业院校、专业、入学时间、毕业时间、学位
- 至少保留1条
- 入学时间不能晚于毕业时间
- 点击"添加教育经历"新增，点击删除按钮移除

**（4）工资卡信息**（仅新增模式显示）
| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 开户行 | 文本输入 | 是 | |
| 银行卡号 | 文本输入 | 是 | 16-19位数字 |
| 使用状态 | 下拉选择 | 是 | 正常使用/停止使用 |

**（5）照片上传**：上传员工照片  
**（6）证书上传**：上传学历证书等  
**（7）简历上传**：支持 .pdf/.png/.jpg/.jpeg/.gif/.docx/.doc  
**（8）上传身份证**：必填，需上传正反两面（2张）

**操作步骤（新增）：**
1. 点击列表页"新增"按钮
2. 逐项填写职工信息明细（带红色星号 `*` 的为必填）
3. 填写紧急联系人（至少1条）
4. 填写教育经历（至少1条）
5. 填写工资卡信息
6. 上传照片、证书、简历、身份证（正反面）
7. 点击右上角"保存"按钮
8. 系统校验通过后保存成功，自动返回列表页

**操作步骤（编辑）：**
1. 在列表页点击某行的"编辑"按钮
2. 系统加载该员工的已有数据
3. 修改需要变更的字段
4. 点击"保存"按钮
5. 编辑模式下还可点击"工资卡信息"按钮单独编辑工资卡

**操作步骤（查看）：**
1. 点击列表行或"查看"按钮
2. 所有字段为只读状态，不可修改
3. 可查看工资卡信息、下级部门、操作记录

### 【校验规则】
| 字段 | 规则 |
|------|------|
| 员工姓名 | 必填，最多50字符 |
| 手机号 | 必填，正则 `/^1[3-9]\d{9}$/` |
| 身份证号 | 必填，18位身份证校验 |
| 个人邮箱 | 必填，标准邮箱格式 |
| 公司邮箱 | 必填，标准邮箱格式 |
| 银行卡号 | 必填（新增），16-19位数字 |
| 身份证照片 | 必填，需上传正反两面共2张 |
| 入学时间 | 不能晚于毕业时间 |
| 紧急联系人 | 至少保留1条，电话需为11位手机号 |
| 教育经历 | 至少保留1条，学历/毕业院校/专业/入学时间/毕业时间均为必填 |

### 【状态说明】
- 员工在职状态：在职(1)、离职(2)、试用(3)
- 用工类型：正式工(1)、劳务派遣(2)、实习生(3)
- 婚姻状况：已婚(1)、未婚(2)、离异(3)、其他(4)
- 户口类型：本地城镇(1)、本地农村(2)、外地城镇省内(3)、外地农村省内(4)、外地城镇省外(5)、外地农村省外(6)
- 学历：小学(1)~博士(8)、其他(9)
- 企业微信状态：已关联(1)、未关联(0)

## 二、打卡统计

### 【用途】
管理员工考勤数据，包括打卡数据导入、出勤统计汇总、剔除地点配置、客户场地打卡配置、计算方法配置。

### 【页面路径】
侧边菜单 → 人事管理 → 打卡统计

### 【主要功能】

页面顶部有5个标签页切换：

#### 1. 打卡数据导入
- 上传打卡原始数据文件（Excel）
- 支持预览导入数据
- 确认后导入系统

#### 2. 出勤统计汇总
**页面元素：**
| 元素 | 说明 |
|------|------|
| 月份选择器 | 选择统计月份（YYYY-MM），默认当月 |
| 导出Excel按钮 | 导出当前统计结果为 Excel |
| 重置按钮 | 重置筛选条件 |
| 刷新按钮 | 刷新统计数据 |
| 统计表格 | 按员工展示出勤统计（出勤天数、迟到、早退、旷工、加班等） |
| 出勤明细弹窗 | 点击员工行可查看该员工当月的每日打卡明细 |

**操作步骤：**
1. 切换到"出勤统计汇总"标签
2. 选择要查看的月份
3. 系统自动加载该月考勤统计数据
4. 点击某员工行，弹出"出勤明细"窗口，显示每日打卡记录
5. 点击"导出Excel"导出统计数据

#### 3. 剔除地点配置
- 配置不需要计入考勤的打卡地点（如公司以外的临时办公点）

#### 4. 客户场地打卡配置
- 配置客户现场的打卡规则
- 支持添加/编辑/删除客户场地打卡配置

#### 5. 计算方法配置
- 配置考勤算法参数
- 参数包括：计算字段名称、最少天数、满额时长、触发天数、放宽下限、放宽上限
- 支持加班计算配置

### 【校验规则】
| 字段 | 规则 |
|------|------|
| 考勤日期 | 必填 |
| 计算字段名称 | 必填，最多100字符 |
| 最少天数 | 必填，浮点数，≥0 |
| 满额时长 | 必填，浮点数，≥0 |
| 触发天数 | 必填，浮点数，≥0 |
| 放宽下限 | 必填，浮点数，≥0 |
| 放宽上限 | 必填，浮点数，≥0 |

## 三、人事部门

### 【用途】
管理公司的人事部门结构，支持部门的新增、编辑、查看、启用/停用、批量操作、导入导出。

### 【页面路径】
侧边菜单 → 人事管理 → 人事部门

### 【主要功能】

#### 1. 部门列表页
**页面元素：**
| 元素 | 说明 |
|------|------|
| 状态标签 | 全部/正常/停用，显示各状态数量 |
| 公司筛选 | 下拉树选择所属公司 |
| 新增部门按钮 | 跳转到新增页面（需权限 `addHrDepartment`） |
| 导入按钮 | 上传 Excel 批量导入部门（需权限 `hrDepartmentImport`） |
| 导出按钮 | 导出部门数据（需权限 `hrDepartmentExport`） |
| 刷新按钮 | 刷新列表 |
| 重置按钮 | 重置筛选条件 |
| 表格列 | 部门名称、所属公司、部门层级、部门状态、上级部门、部门负责人、创建时间 |
| 操作列 | 查看、编辑、停用/启用 |
| 批量操作 | 勾选后显示：批量启用、批量停用、批量删除、取消选择 |

**操作步骤：**
1. 选择公司筛选部门
2. 点击状态标签切换查看不同状态的部门
3. 点击"新增部门"进入新增页面
4. 勾选部门后可进行批量启用/停用/删除
5. 点击"导入"上传 Excel 模板批量导入

#### 2. 新增/编辑部门页
**页面元素：**
| 字段 | 类型 | 是否必填 | 说明 |
|------|------|----------|------|
| 部门名称 | 文本输入 | 是 | 2-50字符，同一公司内唯一 |
| 上级部门 | 树形选择 | 否 | 不选则为顶级部门；变更时提示"当前部门及下级将移动" |
| 部门状态 | 下拉选择 | 是 | 正常/停用；停用时提示"该部门下所有用户将无法登录" |
| 部门负责人 | 下拉搜索 | 否 | 从公司员工列表选择，支持滚动加载和搜索 |
| 排序号 | 数字输入 | 否 | 0-9999，数值越小越靠前 |
| 部门描述 | 文本域 | 否 | 最多500字符 |

**操作步骤：**
1. 点击"新增部门"或某行的"编辑"按钮
2. 填写部门名称（必填，2-50字符）
3. 选择上级部门（可选）
4. 选择部门状态（正常/停用）
5. 选择部门负责人（可选）
6. 设置排序号
7. 填写部门描述
8. 点击"保存"

#### 3. 部门详情页
- 显示部门基本信息：部门名称、状态标签、所属公司、上级部门、部门负责人、排序号、部门描述、创建时间、更新时间
- 下级部门列表：显示该部门的所有直接下级部门
- 操作记录：显示该部门的操作日志（操作时间、操作人、操作类型、操作描述）

### 【校验规则】
| 字段 | 规则 |
|------|------|
| 部门名称 | 必填，2-50字符 |
| 部门状态 | 必填 |

### 【状态说明】
- 部门状态：正常(1)、停用(2)
- 停用部门后，该部门下所有用户将无法登录系统
- 上级部门变更后，当前部门及其所有下级部门将移动到新上级部门下

## 四、组织架构

### 【用途】
管理公司的组织架构，包括公司管理、部门管理、员工管理、分公司管理员管理。

### 【页面路径】
侧边菜单 → 组织架构

### 【主要功能】

#### 1. 公司管理
**页面元素：**
| 元素 | 说明 |
|------|------|
| 状态筛选 | 全部公司/已启用/已停用 |
| 添加公司按钮 | 弹出公司表单（需权限 `addCompany`） |
| 树形表格 | 公司名称、简称、状态、创建时间等 |
| 操作 | 编辑、停用/启用 |

**操作步骤：**
1. 通过状态筛选查看公司
2. 点击"添加公司"填写公司信息
3. 在树形表格中展开查看子公司
4. 点击操作按钮进行编辑或启停

#### 2. 部门管理
**页面元素：**
| 元素 | 说明 |
|------|------|
| 新增按钮 | 弹出部门表单（需权限 `addDepartment`） |
| 重置按钮 | 重置筛选条件 |
| 部门级联选择器 | 按部门层级筛选 |
| 树形表格 | 部门名称、负责人、状态等 |

**操作步骤：**
1. 通过级联选择器筛选部门
2. 点击"新增"添加部门
3. 在树形表格中查看部门层级

#### 3. 员工管理
**页面元素：**
| 元素 | 说明 |
|------|------|
| 左侧部门树 | 按部门筛选员工 |
| 新增按钮 | 新增员工（需权限 `addStaff`） |
| 导出按钮 | 导出员工数据（需权限 `staffExport`） |
| 刷新按钮 | 刷新列表 |
| 搜索筛选 | 员工姓名/账号搜索、入职日期范围、员工状态、账号状态 |
| 表格列 | 员工姓名、账号、部门、角色、状态、入职时间等 |
| 操作 | 编辑、查看详情、修改密码、数据交接、登录日志 |

**后端校验规则（新增员工）：**
| 字段 | 规则 |
|------|------|
| 部门ID | 必填 |
| 角色ID | 必填 |
| 用户昵称 | 必填，同公司内不能重名 |
| 用户账号 | 必填 |
| 登录密码 | 必填 |
| 身份证号 | 必填，唯一 |
| 入职时间 | 必填 |
| 性别 | 必填，0/1/2 |
| 企微邮箱 | 必填，邮箱格式 |
| 手机号 | 手机号格式 |
| 职位 | 最多20字符 |
| 离职日期 | 当员工状态为离职时必填 |

#### 4. 分公司管理员
- 查看某公司下的管理员账号列表
- 支持修改管理员密码

## 五、个人工作台

### 【用途】
个人工作台是员工的首页仪表盘，以微前端方式嵌入图表项目，展示个人相关的数据概览、待办提醒、快捷入口等。

### 【页面路径】
侧边菜单 → 个人事务 → 个人工作台

### 【主要功能】
- 嵌入外部图表页面（通过无界微前端加载）
- 展示个人工作数据概览
- 支持全屏查看
- 支持发起异常结案/退机报告（通过图表项目触发事件）

### 【操作步骤】
1. 进入个人工作台，系统自动加载图表数据
2. 页面中的图表和快捷入口由外部图表项目提供
3. 从图表项目触发"发起异常报告"时，弹出报告填写窗口

## 六、我提交的

### 【用途】
查看当前用户提交的所有审批流程记录，跟踪审批进度。

### 【页面路径】
侧边菜单 → 个人事务 → 我提交的

### 【主要功能】
**页面元素：**
| 元素 | 说明 |
|------|------|
| 表单筛选 | 下拉选择表单类型（如请假、报销等） |
| 任务状态筛选 | 下拉选择流程状态 |
| 审批项筛选 | 下拉搜索审批项 |
| 创建时间筛选 | 日期范围选择 |
| 重置按钮 | 重置所有筛选条件 |
| 表格列 | 表单、审批项、状态、当前进度、当前办理人、创建时间 |

**操作步骤：**
1. 进入"我提交的"页面，自动加载提交记录
2. 通过表单筛选查看特定类型的审批
3. 通过状态筛选查看进行中/已完成/已撤销的记录
4. 点击某条记录的"审批项"列，跳转到对应的详情页面
5. 可通过创建时间范围筛选

### 【状态说明】
- 流程状态：进行中(1)、已完成(2)、审批不通过(3)、已撤销(4)、已终止(5)

## 七、我审批的

### 【用途】
查看当前用户需要审批的待办事项，以及已处理的历史审批记录。

### 【页面路径】
侧边菜单 → 个人事务 → 我审批的

### 【主要功能】
**页面元素：**
| 元素 | 说明 |
|------|------|

## 常见问题

### 员工信息
**Q：导入员工信息失败怎么办？**
A：请检查 Excel 文件格式是否正确（.xlsx/.xls），文件大小不超过 10M。导入模板需从企业微信导出。

**Q：为什么编辑员工时看不到"所属公司"选择？**
A：编辑模式下所属公司不可修改。如需变更公司，请联系管理员。

**Q：身份证照片上传有什么要求？**
A：必须上传正反两面共2张照片，缺一不可。

### 人事部门
**Q：停用部门会有什么影响？**
A：停用部门后，该部门下的所有用户将无法登录系统，请谨慎操作。

**Q：变更上级部门会有什么影响？**
A：当前部门及其所有下级部门将移动到新上级部门下。

### 审批流程
**Q：我提交的审批在哪里查看进度？**
A：进入"个人事务 → 我提交的"页面，可查看所有提交的审批及其当前状态。

**Q：如何审批待办事项？**
A：进入"个人事务 → 我审批的"页面，点击审批项跳转到处理页面进行审批。

**Q：有流程和无流程有什么区别？**
A：有流程的事项通过工作流引擎驱动，有明确的审批节点和状态流转；无流程的事项是直接的任务待办（如异常报告评审），不经过工作流引擎。

### 工作流配置
**Q：模板、工作流、任务之间的关系是什么？**
A：任务是工作流的最小单元（如"经理审批"），模板是多个任务的有序组合，工作流是多个模板的有序组合。配置顺序：先建任务 → 再建模板（关联任务） → 最后建工作流（关联模板）。

**Q：为什么添加模板/任务时找不到想要的？**
A：请检查公司类型是否匹配。模板和任务都有公司类型属性，只有相同公司类型的才能关联。

**Q：草稿状态的工作流/模板/任务可以删除吗？**
A：可以。启用后的不能直接删除，需要先停用。

**Q：任务分配规则不生效怎么办？**
A：如果分配规则未匹配到合适的处理人，任务会自动降级为"待分配"状态，管理员可在"工作流 → 待分配任务"中手动分配。
