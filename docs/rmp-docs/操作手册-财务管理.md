# RMP 平台操作手册 — 财务管理

> 本手册面向业务人员（财务、运维、销售），介绍 RMP 平台「财务管理」模块的页面用途、操作步骤、校验规则和状态流转。
> 不涉及任何数据库结构、字段类型、SQL 等技术细节。

---

## 模块总览

财务管理模块覆盖了从「机器人日结数据核签」到「客户对账与收款」再到「付款审批」的完整财务流转链路：

```
机器人日结数据
   ↓（运维 日结核签）
日结审核（财务）
   ↓
月结核签（运维）
   ↓
月结审核（财务）→ 月对账单打印
   ↓
客户对账单生成 → 上传对账凭证 → 生成收款单 → 完成
   ↓
销售订单 / 付款单（独立流转）
```

模块包含以下 7 个子模块：

| 序号 | 子模块 | 主要使用角色 | 路径前缀 |
|------|--------|--------------|----------|
| 1 | 客户对账单 | 财务 / 销售 | `/financialManage/customerStatement` |
| 2 | 日结财务运维 | 运维人员 | `/financialManage/dailyFinancialDevOps` |
| 3 | 日结财务审核 | 财务 | `/financialManage/dailyFinancialReview` |
| 4 | 月结核签运维 | 运维人员 | `/financialManage/monthlySettlementDevOps` |
| 5 | 月结核签审核 | 财务 | `/financialManage/monthlyClosingReview` |
| 6 | 付款管理 | 财务 | `/financialManage/payment` |
| 7 | 销售订单 | 销售 / 财务 | `/financialManage/salesOrder` |

进入方式：登录 RMP 平台 → 左侧菜单「财务管理」→ 选择对应子菜单。

## 一、客户对账单（customerStatement）

### 【用途】
面向客户的月度结算单据管理。用于把机器人服务产生的工时/件数按客户汇总为正式对账单，并上传凭证、跟进回款状态。同时提供对账时间段、费率、页尾内容的配置能力。

### 【页面路径】
- 列表入口：`财务管理 → 客户对账单`
- 详情入口：列表行操作「查看」

页面顶部通过 5 个页签切换功能：
1. **未生成对账单** — 展示尚未生成对账单的工位数据
2. **已生成对账单** — 展示已生成对账单列表
3. **对账时间段配置** — 配置客户对账起止日
4. **费率配置** — 配置设备租赁费/技术服务费比例与税率
5. **页尾内容配置** — 配置对账单页尾备注

### 【主要功能】

#### 1. 未生成对账单
- **表格列**：客户名称、对账周期、对账时间段、工位编码、工位名称、销售代表、实际工时(H)、月保底工时(H)、结算工时(H)、未税单价、含税单价、未税金额、含税设备租赁费（比例15%-税率13%）、含税技术服务费（比例85%-税率6%）、含税总金额（结算金额）
- **按钮**：生成对账单（黄色）、刷新、重置
- **支持搜索**：客户名称、客户编号、工位编码、工位名称、销售代表

#### 2. 已生成对账单
- **表格列**：对账单编号、客户名称、对账周期、对账时间段、销售代表、工位编码、工位名称、实际工时、月保底工时、结算工时、未税单价、含税单价、未税金额、含税设备租赁费、含税技术服务费、含税总金额、查看工位明细、状态、创建人、创建时间
- **按钮**：刷新、重置
- **行操作**（根据状态动态显示）：
  - 「查看上传文件」— 查看已上传的对账凭证（状态为已上传/已生成收款单/已完成时显示）
  - 「重新打印」— 重新生成对账单 PDF（任意状态均显示）
  - 「撤回」— 撤回已生成的对账单，退回未生成状态（仅状态为「已生成」时显示）
  - 「查看优惠」— 查看优惠金额历史记录（状态为已上传/已生成收款单/已完成时显示）
  - 「上传」— 上传对账凭证文件（png/jpg/pdf，最多 10 个；仅状态为「已生成」时显示）

#### 3. 对账时间段配置
- **表格列**：客户编码、客户名称、月对账开始日、月对账截止日、创建人、创建时间、最后修改人、最后修改时间、备注
- **按钮**：新建配置、刷新、重置
- **行操作**：查看（日志）、编辑、删除

#### 4. 费率配置
- 顶部「全局默认费率配置」区块：
  - 含税设备租赁费比例(%) — 默认 15%
  - 含税技术服务费比例(%) — 默认 85%（两者之和必须等于 100%）
  - 设备租赁费税率(%) — 默认 13%
  - 技术服务费税率(%) — 默认 6%
  - 显示最后修改人、最后修改时间
  - 按钮：保存配置、恢复默认
- 客户费率列表：
  - **表格列**：客户名称、含税设备租赁费比例(%)、含税技术服务费比例(%)、设备租赁费税率(%)、技术服务费税率(%)、最后修改人、最后修改时间
  - **按钮**：新建费率配置、刷新
  - **行操作**：编辑、查看日志、删除
- 说明：未单独配置的客户使用全局默认费率

#### 5. 页尾内容配置
- **表格列**：客户名称、页尾备注内容、状态（启用/禁用）、创建时间、更新时间
- **按钮**：新增配置、刷新、重置
- **行操作**：编辑、删除

### 【操作步骤】

#### 生成对账单
1. 进入「未生成对账单」页签
2. 在列表中**勾选**需要生成对账单的工位数据
3. 注意：每次只能选择**同一客户、同一对账周期**的工位（否则系统会提示「每次只能选择一个客户且相同账期的生成对账单」）
4. 点击右上角「生成对账单」按钮
5. 系统跳转到对账单编辑页，确认金额后提交，对账单生成成功，状态变为「已生成」

#### 上传对账凭证
1. 进入「已生成对账单」页签
2. 找到状态为「已生成」的对账单，点击「上传」
3. 在弹窗中选择文件（支持 `.png`、`.jpg`、`.pdf`，最多 10 个）
4. 可填写备注（选填，最长 500 字）
5. 点击确认上传，状态变为「已上传」

#### 撤回对账单
1. 在「已生成对账单」列表中，找到状态为「已生成」的记录
2. 点击「撤回」
3. 确认弹窗提示：撤回后对账单退回未生成状态，工位数据保留但对账单记录将被删除
4. 点击「确定」完成撤回

### 【校验规则】
- 生成对账单：必须勾选数据，且所选行必须为同一客户、同一对账周期
- 上传对账凭证：文件类型限 png/jpg/pdf，最多 10 个
- 费率配置：设备租赁费比例 + 技术服务费比例之和必须 = 100%
- 费率各项范围：0-100%，精度 0.01
- 页尾备注、备注说明等文本字段一般最长 255-500 字
- 撤回操作仅对状态为「已生成」的对账单可用

### 【状态说明】
| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| 已生成（1） | 对账单已生成，等待上传凭证 | 上传、撤回、重新打印 |
| 已上传（20） | 已上传对账凭证文件 | 查看文件、查看优惠、重新打印 |
| 已生成收款单（30） | 已关联生成收款单据 | 查看文件、查看优惠、重新打印 |
| 已完成（40） | 对账流程完成 | 查看文件、查看优惠、重新打印 |

### 【常见问题】
- **Q: 为什么找不到「生成对账单」按钮？**
  A: 检查是否拥有 `generateStatement` 权限，且必须先在列表中勾选数据。

- **Q: 费率修改后对历史对账单是否生效？**
  A: 费率修改仅对**新生成**的对账单生效，已生成的对账单金额不变。

- **Q: 撤回对账单后数据会丢失吗？**
  A: 不会。工位的工时/件数等数据保留，仅删除对账单记录本身，可重新生成。

## 二、日结财务运维（dailyFinancialDevOps）

### 【用途】
运维人员每日对机器人运行数据进行核签（确认工时或件数），是日结数据进入审核流程的入口。系统自动统计机器人运行工时/产能，运维人员核对后填写实际核签值并上传凭证，提交进入审核流程。

### 【页面路径】
- 列表入口：`财务管理 → 日结财务运维`
- 明细入口：列表行操作「明细」

### 【主要功能】
- **顶部信息**：显示「日结核签(运维)」标题及当前核签时间段（核签日期 + 系统配置时间点 ~ 次日同时段）
- **筛选按钮**：设置（自定义表格列）、批量录入、批量核签、工时确认单打印、导出、重置
- **核签日期选择**：默认为前一天，可切换
- **表格列**：客户编号、场地、工位编号、工位名称、工件/产品、机器人编号、计费模式、系统工时/件数、核签工时/件数、对比状态（自动比对系统值与核签值的差异，红/绿标识）、场地负责人、运维经理、状态
- **行操作**：明细（查看该工位的核签历史明细）

### 【操作步骤】

#### 批量核签
1. 选择核签日期（默认为前一天）
2. 在列表中**勾选**需要核签的数据行
3. 注意：
   - 必须勾选数据才能核签
   - 只能核签**未核签**的数据（状态为空）
   - 必须勾选**同一客户**的数据
4. 点击「批量核签」按钮，弹出核签对话框
5. 在对话框表格中的「核签」列，逐行输入核签值（数字）
6. 点击「上传」按钮上传核签文件（png/jpg/jpeg/pdf，限 1 个）
7. 点击「提交」
8. 系统提示「数据提交审核中，请稍后」，数据进入审核流程

#### 批量录入
1. 勾选数据后点击「批量录入」
2. 确认弹窗后，系统将勾选数据录入为草稿状态（不直接提审）

#### 工时确认单打印
1. 在列表中勾选数据（自动触发打印数据准备）
2. 点击「工时确认单打印」按钮
3. 系统调用浏览器打印

#### 导出
1. 设置好筛选条件后点击「导出」
2. 系统生成导出任务，在导出弹窗中查看进度并下载

### 【校验规则】
- 核签值必须为数字，非数字会被清空并提示「请输入数字」
- 批量核签时必须上传核签文件（否则提示「请上传核签文件」）
- 核签值不能为空（提示「请填写必填项」）
- 同一工位/机器人/产品/计费模式/核签日期的组合，如已存在已审核/审核中数据，不允许重复核签（提示「已审核核签数据无需重复核签」）
- 只有该工位对应场地的**运维人员**或**运维经理**，或拥有管理员权限的用户才能核签

### 【状态说明】
| 状态 | 说明 |
|------|------|
| 空（未核签） | 数据尚未核签，可执行核签操作 |
| 草稿 | 已录入但未提交审核 |
| 客户经理审核 | 已提交，等待客户经理审核 |
| 财务审核 | 客户经理已通过，等待财务审核 |
| 已完成 | 审核流程全部通过 |
| 文员审核 | （特殊场景）文员审核节点 |

### 【常见问题】
- **Q: 点击「批量核签」提示「只能核签未核签的数据」？**
  A: 列表中已核签的数据（状态非空）不能再次核签，请只勾选状态为空的数据。

- **Q: 提示「请勾选同一客户」？**
  A: 批量核签暂不支持多客户，请分客户分批核签。

- **Q: 提示「您没有权限核签」？**
  A: 只有配置在该工位场地的「运维人员」或「运维经理」字段中的用户才能核签，请联系管理员配置。

## 三、日结财务审核（dailyFinancialReview）

### 【用途】
财务人员对运维提交的日结核签数据进行审核。可查看核签明细、核签文件，执行审核通过或退回操作。支持按时间段筛选和导出。

### 【页面路径】
- 列表入口：`财务管理 → 日结财务审核`
- 明细入口：列表行操作「查看」

### 【主要功能】
- **页签切换**：未审核（默认）、已审核、全部（页签状态会缓存，刷新页面后保留）
- **筛选按钮**：刷新、导出（需选择日期范围）、重置
- **时间筛选**：核签时间范围（开始时间 ~ 结束时间）
- **表格列**：核签时间、客户编号、场地、工位编号、工位名称、工件/产品、机器人编号、流程状态、计费模式、系统工时/件数、核签工时/件数、对比状态、核签文件（可点击预览）、签核人、状态
- **行操作**：查看（进入明细页）

### 【操作步骤】

#### 审核日结数据
1. 进入「日结财务审核」，默认显示「未审核」页签
2. 可通过时间范围、客户、工位等条件筛选
3. 点击列表行的「查看」按钮，进入审核明细页
4. 明细页显示该工位的所有核签记录列表（核签时间、系统工时/件数、核签工时/件数、核签文件、核签人、状态）
5. 对状态为「待审核」的记录，可执行：
   - **审核**：点击「审核」按钮 → 系统会先检查数据是否存在遗漏（如存在遗漏会二次确认「此日结数据存在数据遗漏，请选择是否继续审核」）→ 确认后审核通过
   - **退回**：点击「退回」按钮 → 确认后退回给运维人员修改
6. 审核成功后状态变为「已审核」

#### 导出数据
1. 点击「导出」按钮，弹出日期选择器
2. 选择开始和结束日期
3. 点击「导出」快捷按钮执行导出，或点击「取消」关闭
4. 导出文件自动下载为 Excel

### 【校验规则】
- 审核和退回操作仅对状态为「待审核（status=3）」的记录可用（按钮自动禁用其他状态）
- 审核时系统会检查数据完整性，发现遗漏会提示确认

### 【状态说明】
| 状态值 | 说明 | 可执行操作 |
|--------|------|------------|
| 1 | 待核签 | — |
| 2 | 已核签 | — |
| 3 | 待审核 | 审核、退回 |
| 4 | 已审核 | 仅查看 |
| 5 | 被退回 | 退回后运维需重新核签 |

**流程状态（current_flow_node）**：草稿 → 客户经理审核 → 财务审核 → 已完成 / 文员审核

### 【常见问题】
- **Q: 审核时提示「此日结数据存在数据遗漏」？**
  A: 系统检测到该工位在该时间段内可能存在缺失的核签数据。确认无误后可选择「继续审核」，或先退回让运维补齐。

- **Q: 为什么看不到「审核」和「退回」按钮？**
  A: 这两个按钮仅对状态为「待审核」的记录启用，其他状态会自动置灰。

## 四、月结核签运维（monthlySettlementDevOps）

### 【用途】
运维人员按月对机器人运行数据进行核签，生成月度结算数据。月结数据基于日结数据汇总，运维人员核对后填写月度核签值并上传月核签文件。

### 【页面路径】
- 列表入口：`财务管理 → 月结核签运维`
- 明细入口：列表行操作「明细」

### 【主要功能】
- **顶部筛选**：年份选择、月份选择（默认当前年月）、重置、导出
- **表格列**：工位名称、工位编号、工件/产品、机器人编号、计费模式、系统工时/件数、核签工时/件数（自动与保底值比较取大值）、月保底工时/件数、场地负责人、运维经理、核签状态、月核签文件（可预览）、流程状态
- **行操作**（根据状态动态显示）：
  - 「明细」— 查看该月结的日结明细数据
  - 「变更」— 修改已核签的月结数据（状态为待核签时显示）
  - 「核签」— 首次月结核签（状态为空时显示）

### 【操作步骤】

#### 月结核签
1. 选择年份和月份
2. 在列表中找到状态为「待核签」的工位
3. 点击「核签」按钮，弹出核签对话框
4. 对话框显示：核签月份、客户、场地、机器人、工位名称/编号、结算模式、工件/产品、系统工时（或系统件数）
5. 在「核签工时(H)」或「核签件数(PCS)」输入框中填写核签值（必填）
6. 点击「上传」按钮上传月核签文件（png/jpg/jpeg/mp4）
7. 点击确认提交
8. 系统自动发起审批流程（form_key: month_settlement）

#### 变更月结数据
1. 找到已核签但尚未进入审核流程的数据
2. 点击「变更」按钮，弹出与核签相同的对话框
3. 修改核签值或重新上传文件后提交
4. 系统提示「变更成功」

#### 查看明细
1. 点击「明细」按钮，跳转到月结明细页
2. 明细页展示该月结对应的日结数据列表

### 【校验规则】
- 核签工时/件数为必填项
- 月核签文件为必填项（至少上传 1 个）
- 若当前月结中存在日结数据处于「待审核」状态，系统会提示「当前月结有 N 条日结数据待审核，无法进行月结核签操作」
- 月结数据提交后自动进入审批流程

### 【状态说明】
| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| null（待核签） | 尚未月结核签 | 核签、明细 |
| 草稿（2） | 录入未提交 | 变更、明细 |
| 待审核（3） | 已提交等待审核 | 明细 |
| 已审核（4） | 审核通过 | 明细 |
| 被退回（5） | 审核退回 | 变更、明细 |

### 【常见问题】
- **Q: 为什么不能月结核签，提示有日结数据待审核？**
  A: 月结依赖日结数据，必须先完成所有日结的审核流程。请到「日结财务审核」处理待审核数据后再做月结。

- **Q: 月结的核签工时和保底工时是什么关系？**
  A: 系统会自动比较核签值与保底值，取较大值作为结算工时（绿色显示），保证不低于保底。

## 五、月结核签审核（monthlyClosingReview）

### 【用途】
财务人员对运维提交的月结核签数据进行审核、打印月对账单。支持按「无工位组」和「有工位组」两种视图查看。

### 【页面路径】
- 列表入口：`财务管理 → 月结核签审核`

### 【主要功能】
- **视图页签**：
  - 「无工位组」— 按单个工位展示月结数据
  - 「有工位组」— 按工位分组汇总展示（适用于多工位合并结算场景）
- **筛选按钮**：导出、打印、刷新、重置
- **顶部筛选**：年份、月份选择
- **表格列**（无工位组视图）：客户编号、工位编号、工位名称、工件/产品、机器人编号、月核签文件（可预览）、计费模式、系统工时/件数、核签工时/件数、月保底工时/件数、设备租赁费、技术服务费、结算总金额、计费备注、状态、流程状态
- **行操作**：详情（查看月结明细）

### 【操作步骤】

#### 查看月结详情
1. 选择年份和月份
2. 在列表中点击「详情」按钮
3. 跳转到月结审核详情页，查看明细数据

#### 打印月对账单
1. 设置好筛选条件（年份、月份、客户等）
2. 点击「打印」按钮，弹出打印设置对话框
3. 选择「是否打印系统工时/件数」（是/否）
4. 点击「确定打印」
5. 系统调用打印模板，生成包含以下内容的月对账单：
   - 公司名称、客户名称、结算月份
   - 表格：序号、工位名称、机器人编号、计费模式、（可选）系统工时/件数、核签工时/件数、月保底工时/件数、结算工时/件数、含税单价、含税设备租赁费、含税技术服务费、含税结算总金额、未税结算总金额
   - 制表人、日期、客户签名（盖章）位

#### 导出
1. 设置筛选条件后点击「导出」
2. 在导出弹窗中下载文件

### 【校验规则】
- 年份和月份为必选（接口要求 `year` 和 `month` 必填）
- 打印模板中费用计算规则：
  - 计时/计件模式：取核签工时与保底工时的较大值作为结算工时
  - 含税设备租赁费 = 结算工时 × 含税单价 × 40%（打印模板内置比例，实际以系统配置为准）
  - 含税技术服务费 = 结算工时 × 含税单价 × 60%
  - 未税结算总金额 = 含税设备租赁费 ÷ 1.13 + 含税技术服务费 ÷ 1.06

### 【状态说明】
| 状态 | 说明 |
|------|------|
| 待审核（3） | 已提交等待财务审核 |
| 已审核（4） | 审核通过 |
| 被退回（5） | 审核退回，需运维修改后重新提交 |

### 【常见问题】
- **Q: 无工位组和有工位组有什么区别？**
  A: 无工位组按单个工位逐行展示；有工位组将多个工位按预设的工位组合并展示汇总数据，适用于客户按工位组结算的场景。

## 六、付款管理（payment / paymentDetails）

### 【用途】
管理公司对外付款单据。新增付款申请后，通过审批流程完成付款，支持附件上传和单据打印。

### 【页面路径】
- 列表入口：`财务管理 → 付款管理`（即 payment 页面）
- 详情/新增入口：列表「新增」按钮或行操作「查看」

### 【主要功能】

#### 付款单列表
- **表格列**：付款单号、单据日期、申请人、所属公司、状态
- **按钮**：新增、重置
- **筛选**：付款单号、申请人、审核状态（下拉）、单据日期范围
- **行操作**：查看（点击行或「查看」按钮进入详情）

#### 付款单详情/新增表单
- **表单字段**：
  - 付款单号（系统自动生成，不可编辑）
  - 所属公司（自动带入当前用户公司，不可编辑）
  - 付款类型（必填，下拉：货款、服务款、工程款、水电费、租金、设备款、往来款、押金、其他）
  - 场地面积（仅当付款类型为「水电费」或「租金」时显示且必填）
  - 付款金额（必填，数字输入，最小 0）
  - 付款方式（必填，下拉：银行卡、现金、汇票、电汇、货记、支票、其他）
  - 付款日期（必填，日期选择）
  - 收款人全称（必填）
  - 银行账号（必填）
  - 开户行（必填）
  - 备注说明（选填）
  - 附件（可上传多个，支持 doc/xls/ppt/png/jpg 等，最多 80 个）
- **按钮**（根据状态显示）：保存、取消、打印（仅审批通过后可打印）

### 【操作步骤】

#### 新增付款单
1. 在付款单列表点击「新增」按钮
2. 系统自动生成付款单号并带入所属公司
3. 填写付款类型、付款金额、付款方式、付款日期、收款人信息等必填项
4. 如需上传发票等附件，点击附件区域的「+」按钮上传
5. 点击「保存」按钮保存为草稿
6. 保存成功后可在顶部流程区域点击「提交审批」发起审批流程
7. 流程通过后状态变为「审批通过」，可点击「打印」生成付款单 PDF

#### 查看付款单
1. 在列表中点击行或「查看」按钮
2. 进入详情页，表单字段变为只读（除草稿状态外）
3. 草稿状态下（状态=1 且为创建人），可继续编辑保存

### 【校验规则】
- 付款类型：必填，最长 20 字符
- 付款金额：必填，格式为数字（整数最多 7 位，小数最多 3 位，即最大 9999999.999）
- 付款方式：必填，最长 20 字符
- 付款日期：必填，日期格式
- 收款人全称：必填，最长 100 字符
- 银行账号：必填，最长 50 字符
- 开户行：必填，最长 100 字符
- 备注说明：最长 255 字符
- 附件：最多 80 个

### 【状态说明】
| 状态值 | 说明 | 可执行操作 |
|--------|------|------------|
| 1 | 草稿 | 编辑、保存、提交审批 |
| 2 | 待审批 | 等待审批人处理 |
| 3 | 审批中 | 审批流程进行中 |
| 4 | 审批通过 | 打印、查看 |
| 5 | （其他流程状态） | 根据流程节点决定 |

### 【常见问题】
- **Q: 为什么表单字段不能编辑？**
  A: 只有草稿状态（状态=1）且当前用户为创建人时才能编辑。其他状态下表单为只读。

- **Q: 付款单号怎么来的？**
  A: 系统在新增时自动调用接口生成最新编号，无需手动填写。

## 七、销售订单（salesOrder / salesOrderDetails）

### 【用途】
管理销售订单数据，可查看订单明细、生成出库单、发起退货申请。财务可通过此模块跟进订单的物料数量和金额。

### 【页面路径】
- 列表入口：`财务管理 → 销售订单`
- 详情入口：点击列表中「销售订单编号」链接

### 【主要功能】
- **表格列**：订单名称、客户编号、销售订单编号（可点击进入详情）、订单编号、所属公司、销售日期、销售人员、数量、总金额
- **按钮**：导出、发起退货（需勾选数据）
- **筛选**：客户编号、联系人、销售订单编号、销售日期范围
- **行操作**：生成出库单（仅当 `is_outbound = 0` 即未生成出库单时可用）

### 【操作步骤】

#### 查看订单详情
1. 在列表中点击「销售订单编号」列的链接
2. 跳转到销售订单详情页，查看订单的物料明细、批次、库存等信息

#### 生成出库单
1. 在列表中找到未生成出库单的订单（按钮可用状态）
2. 点击「生成出库单」按钮
3. 跳转到销售订单详情页（类型为「生成出库单」）
4. 选择物料批次、确认出库数量后提交

#### 发起退货
1. 在列表中**勾选**一个销售订单（只能勾选一个）
2. 点击「发起退货」按钮
3. 跳转到销售退货表单页（`/storehouseManage/salesReturnForm`）
4. 填写退货原因（必填，最长 200 字符）、选择退货商品明细后提交

#### 导出
1. 设置筛选条件后点击「导出」按钮（图标为下载箭头）
2. 在导出弹窗中下载文件

### 【校验规则】
- 列表分页参数：页码和每页条数必填且为正整数
- 发起退货：必须勾选且只能勾选 1 个订单
- 退货原因：必填，最长 200 字符
- 退货商品明细：必填，至少 1 条
- 退货备注：最长 200 字符
- 价格查看权限：仅「财务」或「销售总监」角色，或单据创建者本人可查看价格信息

### 【状态说明】
销售订单本身的状态流转：
| 状态 | 说明 |
|------|------|
| 未生成出库单（is_outbound=0） | 可生成出库单 |
| 已生成出库单（is_outbound≠0） | 不可重复生成 |

销售退货单的状态流转：
| 状态值 | 说明 |
|--------|------|
| 1 | 草稿 |
| 2 | 待审批 |
| 3 | 审批中 |
| 4 | 审批通过 |

### 【常见问题】
- **Q: 为什么看不到价格信息？**
  A: 价格信息仅对「财务」、「销售总监」角色，或单据创建者本人可见。其他角色看不到金额字段。

- **Q: 「生成出库单」按钮为什么是灰色的？**
  A: 该订单已生成过出库单（`is_outbound ≠ 0`），不可重复生成。

- **Q: 发起退货时提示「只能勾选一个订单」？**
  A: 退货功能一次只支持对单个销售订单发起退货申请，请取消多余的勾选。

## 附录：通用操作说明

### A1. 表格自定义列
大部分列表页支持通过「设置」按钮（齿轮图标）自定义表格显示的列，配置会保存在当前用户本地。

### A2. 导出功能
- 导出操作会先创建导出任务日志
- 导出文件生成后，在弹出的导出任务列表中下载
- 部分模块的导出需要先选择日期范围

### A3. 权限控制
- 所有按钮和操作均受权限控制（`v-auth` / `v-permission` 指令）
- 如果看不到某个按钮，请联系系统管理员检查角色权限配置
- 价格类敏感数据额外受角色控制（财务/销售总监）

### A4. 审批流程
- 日结核签、月结核签、付款单均走系统审批流程（流程引擎）
- 流程节点包括：草稿 → 提交 → 各级审核 → 完成/退回
- 流程状态可在列表的「流程状态」列查看
- 退回的数据需修改后重新提交

### A5. 文件上传通用规则
| 场景 | 允许类型 | 数量限制 |
|------|----------|----------|
| 日结核签文件 | png/jpg/jpeg/pdf | 1 个 |
| 月结核签文件 | png/jpg/jpeg/mp4 | 多个 |
| 对账单凭证 | png/jpg/pdf | 10 个 |
| 付款单附件 | doc/xls/ppt/png/jpg 等 | 80 个 |
