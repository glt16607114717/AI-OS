# RMP 平台用户操作手册：工位与方案管理

> 版本：v1.0 | 适用对象：业务人员（销售、方案工程师、交付/运维人员、计划员）
> 本手册面向业务人员，介绍 RMP 平台"工位与方案管理"模块的用途、页面入口、操作步骤、校验规则、状态流转及常见问题。

---

## 一、模块概述：这个模块是干什么的？

"工位与方案管理"是 RMP 机器人管理平台的核心业务模块，负责管理从客户提出需求 → 方案设计 → 工位部署 → 上线收费的全生命周期。

它解决了以下业务问题：

1. **客户需求怎么管**：客户提出机器人替代某个工位的需求，需要记录产品、工艺、UPH、场地等信息。
2. **方案怎么设计**：方案工程师根据需求设计工位方案（含设备清单、夹治具、布局图、视频等）。
3. **通用方案怎么复用**：把成熟方案沉淀为"通用方案"，新客户可以直接复用，避免重复设计。
4. **工位怎么落地**：方案审核通过后绑定到具体工位，进入排产、备料、部署、收费流程。
5. **夹治具怎么采购**：工位需要的夹治具通过订单流程采购、确认、验收。

本模块覆盖以下 12 个子模块（即本手册的二级标题）：

| 子模块 | 一句话用途 |
|--------|------------|
| 工位需求管理 | 录入和管理客户对某个工位的自动化改造需求 |
| 工位列表/管理 | 管理所有工位及其设备部署、状态流转 |
| 方案检索 | 按行业/工艺全文检索已有方案，快速复用 |
| 方案编辑 | 方案工程师设计/编辑客户工位方案 |
| 方案查看 | 只读查看方案详情，支持导出 PDF |
| 工位方案列表 | 管理所有客户工位方案（草稿/待审/已审） |
| 通用方案 | 管理可复用的标准方案库 |
| 技术方案 | 管理 2D/3D 技术方案（视觉、定位等） |
| 已审核工位 | 查看已审核的需求并分配方案工程师 |
| 计划需求 | 查看所有工位需求（计划员视角） |
| 作业证编辑/查看 | 编辑和查看上岗单（订单）详情 |
| 夹治具订单 | 创建和管理夹治具采购订单及验收 |

## 二、工位需求管理（demand）

### 【用途】
记录客户对某个工位的自动化改造需求，包括产品信息、工艺类型、产能要求、场地要求等。是后续方案设计的输入依据。

### 【页面路径】
- 菜单路径：需求管理 → 工位需求（demand 模块）
- 进入方式：从客户详情页点击"工位需求"或在需求管理菜单直接进入

### 【主要功能】

页面左侧是"物料/设备产品列表"（可按产品类别 Tab 切换、按产品型号搜索），右侧是"已选设备需求清单"。顶部有产品类别 Tab、库存范围切换、搜索框。

| 区域 | 元素 | 说明 |
|------|------|------|
| 顶部 Tab | 产品类别切换 | 如"全部""机器人""末端工具"等 |
| 顶部单选 | 库存范围 | "当前公司库存" / "所有公司库存" |
| 搜索框 | 产品型号搜索 | 输入产品型号关键词搜索 |
| 按钮 | 新建开发需求 | 针对库内没有的产品，新建一条开发需求 |
| 按钮 | 保存设备需求 | 把已选设备清单保存到工位 |
| 左侧列表 | 产品卡片 | 显示产品图片、名称、型号、库存；可点击 +/- 调整数量 |
| 右侧清单 | 已选设备列表 | 显示已添加的设备（含开发中的） |

#### 新建开发需求弹窗字段

| 字段 | 是否必填 | 说明 |
|------|----------|------|
| 产品类别 | 必填 | 下拉选择，来自系统配置 |
| 需求数量 | 必填 | 数字 |
| 产品名称 | 必填 | 文本 |
| 产品要求 | 必填 | 多行文本，描述技术要求 |
| 备注 | 选填 | 多行文本 |

### 【操作步骤】

**场景一：从库内选择已有设备添加到需求**
1. 进入工位需求页面（通常带工位 ID 参数进入）
2. 在左侧产品列表中找到需要的设备
3. 点击产品卡片上的"+/-"按钮调整需求数量
4. 已选设备会出现在右侧清单
5. 点击"保存设备需求"按钮保存

**场景二：新建一个库内没有的开发需求**
1. 点击"新建开发需求"按钮，弹出表单
2. 选择"产品类别"（必填）
3. 输入"需求数量"（必填）
4. 输入"产品名称"（必填）
5. 输入"产品要求"（必填，描述技术规格）
6. 可选填写"备注"
7. 点击确定，需求会加入右侧清单
8. 点击"保存设备需求"按钮保存

### 【校验规则】
- 新建开发需求：产品类别、需求数量、产品名称、产品要求均为必填
- 保存设备需求：必须至少选择一条设备，否则提示"未选择设备，不允许保存"

### 【状态说明】
设备需求清单中的设备有两种状态：
- **已开发（develop_status=1）**：库内已有的标准产品
- **开发中（develop_status=2）**：需要新开发的产品

## 三、工位列表/管理（stationManagement）

### 【用途】
管理所有工位的完整生命周期：从创建工位、绑定方案、排产、备料、部署、到上线收费、暂停、退机。是交付和运维人员的核心工作台。

### 【页面路径】
- 菜单路径：客户管理 → 工位管理（stationManagement 模块）
- 页面顶部有两个 Tab 切换：**工位管理** / **产能数据**

### 【主要功能】

页面包含顶部数据看板、操作按钮区、筛选区、工位表格。

| 按钮 | 功能 | 权限 |
|------|------|------|
| 设置 | 配置表格列显示 | - |
| 预览设备清单 | 查看选中工位的设备清单 | orderPurchasingList |
| 导出 | 导出工位列表 Excel | orderPurchasingExport |
| 部署清单 | 查看部署清单 | deploymentList |
| 刷新 | 刷新列表 | - |
| 重置 | 重置筛选条件 | - |

#### 筛选项
- 时间范围：日期范围选择器
- 可通过表格列自定义筛选（客户、工艺、方案、状态等）

#### 工位表格主要列
工位编号、工位名称、工位别名、客户名称、工艺、方案编号、方案名称、产品名称、机器人数量、工位状态、设备状态、部署时间等（可通过"设置"自定义列）。

#### 行操作（点击工位行/操作列）
- **编辑工位**：修改工位名称、别名、场地、方案绑定等
- **关联方案**：为工位绑定/更换工位方案
- **部署设备**：为工位部署机器人、工控机等设备
- **状态日志**：查看工位状态变更历史
- **交付人员维护**：维护交付技术团队人员
- **运维人员维护**：维护运维团队人员
- **释放工控机/机器人**：解除工位与设备的绑定
- **上传客户签收单**：上传客户运维签收单图片

### 【操作步骤】

**场景一：为工位绑定方案**
1. 在工位列表找到目标工位
2. 点击"关联方案"按钮
3. 在弹窗中选择要绑定的工位方案
4. 确认后方案绑定到工位，工位状态可流转

**场景二：部署设备到工位**
1. 点击工位的"部署设备"按钮
2. 在弹窗中选择可部署的设备（机器人、工控机等）
3. 设置部署数量
4. 提交后设备部署到工位仓位
5. 注意：部署前需确保交付工单已完成；收费工位至少保留一台机器人

**场景三：修改工位状态**
1. 点击工位操作中的状态变更入口
2. 选择目标状态（需符合状态流转规则）
3. 填写说明（最多 200 字）、计划完成日期
4. 提交后工位状态变更，并记录日志

### 【校验规则】
- 工位名称：最多 50 字符，新增时必填
- 工位别名：最多 30 字符
- 工艺：最多 50 字符
- 班次：只能选 1 或 2
- 新增工位必须关联上岗单（post_statement_id）
- 部署设备：必须先有工单且工单任务全部完成
- 部署数量不能为 0
- 收费状态工位删除最后一台机器人会被拦截

### 【状态说明】

工位分三个阶段（节点），共 21 种状态：

**① 计划排产阶段**
| 状态 | 含义 |
|------|------|
| 方案未绑定 | 工位刚创建，尚未绑定方案 |
| 未签上岗单（方案已绑） | 已绑方案但未签上岗单 |
| 待排产 | 已具备排产条件 |
| 暂停 | 计划阶段暂停 |
| 作废 | 计划阶段作废 |

**② 交付阶段**
| 状态 | 含义 |
|------|------|
| 备料 | 正在准备物料 |
| 内部模拟 | 内部模拟测试中 |
| 模拟暂停 | 内部模拟暂停 |
| 模拟已退库 | 模拟后退库 |
| 等待出货 | 模拟通过，等待出货 |
| 等待部署 | 到达客户现场待部署 |
| 现场部署中 | 正在现场部署 |
| 现场部署暂停 | 部署暂停 |
| 部署异常已退机 | 部署出问题退机 |
| 非稳定运行 | 交付期非稳定运行 |

**③ 运维阶段**
| 状态 | 含义 |
|------|------|
| 稳定运行收费 | 正常收费运行 |
| 非稳定运行收费 | 非稳定但仍在收费 |
| 正常暂停 | 正常原因暂停 |
| 异常暂停 | 异常原因暂停 |
| 正常已退机 | 正常退机下线 |
| 异常已退机 | 异常退机下线 |

> 状态流转规则：只能按阶段顺序流转，不能跳跃。例如不能从"方案未绑定"直接到"现场部署中"。

## 四、方案检索（programmeRetrieval）

### 【用途】
按行业、工艺、关键词全文检索所有已审核的工位方案（含通用方案和客户定制方案），帮助快速找到可复用的方案。

### 【页面路径】
- 菜单路径：方案检索（programmeRetrieval 模块）
- 主菜单独立入口

### 【主要功能】

页面分为左侧行业分类、右侧工艺筛选、底部搜索结果列表。

| 区域 | 元素 | 说明 |
|------|------|------|
| 搜索框 | 全文检索输入框 | 输入关键词进行全文检索 |
| 按钮 | 全文检索 | 执行搜索 |
| 按钮 | 重置 | 清空所有筛选条件 |
| 左侧 | 行业分类树 | 按大行业→小行业展开，可勾选 |
| 右侧 | 工艺标签 | 按工艺类型勾选筛选 |
| 底部 | 方案结果列表 | 展示匹配的方案卡片 |

### 【操作步骤】
1. 在搜索框输入关键词（如产品名称、工艺名）
2. 或在左侧勾选行业分类、右侧勾选工艺类型
3. 点击"全文检索"按钮
4. 查看底部匹配的方案列表
5. 点击某个方案可进入方案详情查看

### 【校验规则】
- 无强制校验，可空条件检索

### 【状态说明】
检索结果只展示已审核（可对外展示）的方案。

## 五、方案编辑（editScheme）

### 【用途】
方案工程师设计和编辑客户工位方案的核心工作台。包含方案基础信息、设备清单、夹治具、布局图、工艺流程、视频资料等完整内容。

### 【页面路径】
- 入口1：工位方案列表 → 点击方案"修改"按钮
- 入口2：通用方案 → "复制为客户方案"后进入编辑
- 入口3：已审核需求 → 分配方案工程师后进入

### 【主要功能】

页面顶部为操作按钮区，下方为方案详情表单，包含多个信息区块（折叠面板）。

#### 顶部按钮（根据状态和权限显示）

| 按钮 | 显示条件 | 功能 |
|------|----------|------|
| 保存 | 状态为草稿/驳回，且有编辑权限 | 保存方案 |
| 修改 | 状态为草稿或驳回 | 进入编辑模式 |
| 导入已有方案 | 状态为已审核 | 导入其他方案信息 |
| 方案导出为 PDF | 状态为已审核或草稿 | 导出 PDF 文件 |
| 资料清单 | 有权限 | 管理方案的资料文件清单 |
| 提交审核/审核/驳回 | 流程按钮 | 走审批流程 |

#### 方案信息区块

方案编辑页包含以下主要信息模块（折叠面板形式）：

1. **基础信息**：方案名称、客户、关联工位、行业、工艺、产品、机型、方案概述、详情
2. **适用生产设备**：适用设备图片+附件+备注
3. **产品信息**：产品图片+附件+备注
4. **工位参数**：参数图+附件+备注
5. **工位布局图**：布局图+附件+备注
6. **场地布局**：场地布局图+附件+备注
7. **工位部署流程及说明**：图+附件+备注
8. **机构组装说明**：图+附件+备注
9. **电气操作说明**：图+附件+备注
10. **视觉布局及操作说明**：图+附件+备注
11. **上位机操作说明**：图+附件+备注
12. **工艺流程及运控时序**：图+附件+备注
13. **工位品质验收测试操作说明**：图+附件+备注
14. **设备清单**：设备图+附件+备注
15. **夹治具清单**：清单图+附件+备注
16. **自定义设备清单**：自定义设备+附件+备注
17. **自购设备**：自购设备+附件+备注
18. **可扩展手爪及功能**：图+附件+备注
19. **易损件**：图片+附件+备注
20. **模拟运行资源需求**：图片+附件+备注
21. **工位运行视频**：视频+附件+备注
22. **风险评估**：图片+附件+备注
23. **原 SOP**：视频+附件+备注
24. **自定义模块**：可新增自定义内容区块
25. **示意图**：方案示意图
26. **关键参数备注**
27. **操作说明/部署视频/操作视频/运行视频**

### 【操作步骤】

**场景一：新建方案**
1. 从工位方案列表点击"新增"或从需求分配进入
2. 填写基础信息：方案名称（必填，≤30字）、客户、关联工位、行业、工艺、产品、机型
3. 填写方案概述（必填，≤100字）、详情（必填）
4. 上传示意图（必填）
5. 逐个完善各信息区块（上传图片/附件，填写备注）
6. 维护设备清单（选择设备、数量）
7. 点击"保存"
8. 确认无误后点击"提交审核"

**场景二：修改已有方案**
1. 进入方案详情页
2. 状态为草稿或驳回时显示"修改"按钮
3. 点击"修改"进入编辑模式
4. 修改需要变更的内容
5. 点击"保存"

**场景三：导入已有方案内容**
1. 在已审核状态的方案详情页
2. 点击"导入已有方案"
3. 选择源方案
4. 系统将源方案信息复制到当前方案

**场景四：复制为新版本（ECN 变更）**
1. 在方案详情页点击"复制新版本"
2. 选择复制方式（完全复制/ECN 变更）
3. 填写变更原因
4. 系统生成新版本方案

### 【校验规则】

提交审核时（is_check_param=1）必须满足：
- 方案名称：必填，最多 30 字
- 关联工位：必填
- 大行业、小行业：必填
- 方案概述：必填，最多 100 字
- 详情：必填
- 示意图：必填
- 自定义表格：必填
- 客户 ID：必填
- 工位需求 ID：必填
- 方案工程师：必填
- 各备注字段：最多 255 字
- 各媒体路径字段：最多 300 字
- 修改原因：最多 300 字

### 【状态说明】

| 状态码 | 状态名 | 说明 |
|--------|--------|------|
| 1 | 草稿 | 可编辑、可保存、可提交审核 |
| 2 | 待审核 | 等待审批，不可编辑 |
| 3 | 已审核 | 不可编辑，可导出 PDF、可复制新版本、可导入 |
| -1 | 驳回 | 可修改后重新提交 |
| -2 | 作废 | 不可再操作 |

> 版本管理：每个方案支持多版本，新版本继承旧版本内容，可对比版本物料差异。

## 六、方案查看（readScheme）

### 【用途】
只读查看工位方案详情，适用于非方案工程师（如销售、交付人员）查看方案内容，支持导出 PDF。

### 【页面路径】
- 入口：工位方案列表 → 点击"查看"按钮
- 入口：方案检索 → 点击方案卡片

### 【主要功能】

页面结构与"方案编辑"基本一致，但大部分字段为只读。

| 按钮 | 显示条件 | 功能 |
|------|----------|------|
| 方案导出为 PDF | 状态为已审核或草稿 | 导出 PDF |
| 资料清单 | 有权限 | 查看资料文件 |
| 修改 | 状态为草稿/驳回且有权限 | 跳转到编辑页 |

### 二、常见问题（FAQ）

**Q1：方案保存时提示"请填写完整信息"怎么办？**
A：检查必填项是否都已填写。提交审核时，方案名称、关联工位、行业、工艺、产品、方案概述、详情、示意图、自定义表格均为必填。

**Q2：工位无法部署设备，提示"工单任务未全部完成"？**
A：部署设备前，该工位关联的交付工单必须所有任务完成。请先到交付工单模块完成相关任务。

**Q3：收费工位无法删除最后一台机器人？**
A：系统规定收费状态（稳定运行收费/非稳定运行收费/暂停等）的工位必须至少保留一台机器人。

**Q4：通用方案无法复制为客户方案？**
A：只有"已审核(4)"状态的通用方案才能复制。请确认方案已通过审核并正式发布。

**Q5：夹治具订单提示"该工位未绑定方案"？**
A：夹治具物料关联的工位必须已绑定工位方案。请先到工位管理中为该工位绑定方案。

**Q6：方案想修改但找不到"修改"按钮？**
A：只有状态为"草稿(1)"或"驳回(-1)"的方案才能修改。"待审核(2)"和"已审核(3)"状态不可直接修改。已审核方案可通过"复制新版本"创建可编辑的新版本。

**Q7：工位状态如何变更？**
A：在工位管理列表，点击对应工位的状态变更入口，选择目标状态（需符合流转规则），填写说明和计划完成日期后提交。

**Q8：导出的 Excel/PDF 在哪里下载？**
A：导出操作会生成下载任务，完成后可在系统的"下载中心"或浏览器下载列表中找到文件。

**Q9：方案版本之间如何对比差异？**
A：在方案详情页点击"版本历史"可查看所有版本；点击"版本物料差异"可选择两个版本对比设备清单差异。

**Q10：新建工位时提示"无公司信息"？**
A：当前登录账号未关联公司信息。请联系管理员为你的账号配置公司归属。
