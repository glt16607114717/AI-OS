## 一、基础物料管理

基础物料管理模块负责物料库的维护，包括物料类别树管理、物料 CRUD、编码生成、条形码、版本管理、GitLab 版本关联及保养记录等功能。前端页面位于 `baseDataManage/supplies/` 目录，控制器为 `MaterialController`。

### 物料编码规则

物料编码（`number`）由系统根据物料类别自动生成。调用 `/api/admin/material/new-no` 接口传入 `material_group_id` 获取最新编码，也可通过 `/api/admin/material/generate-number` 自动生成条形码。编码规则基于类别层级串联，量产设备的三级类别编码非必填（需求 ID-1004063）。

### 物料类别树（r_material_group）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 主键 |
| number | varchar(50) | 类别编码 |
| name | varchar(50) | 类别名称 |
| parent_id | int | 上级类别 ID |
| level_one / level_two | int | 一/二级类别 ID |
| level | int | 层级 |
| type | varchar(30) | 类型：common=默认，fixture=夹治具 |
| deployable | tinyint | 是否可部署 |
| is_auto_fill | tinyint | 是否自动填充编码 |
| relation_chain | varchar(2000) | 关系链 |

索引：`idx_number`, `idx_name`, `idx_parent_id`。当前约 62 条记录。

类别树支持多级嵌套，通过 `parent_id` 形成树形结构。API 提供 `getMaterialGroupList`（分页列表）、`getMaterialTree`（树形结构）、`saveMaterialGroup`（保存/编辑）、`deleteMaterialGroup`（删除）等接口。删除时量产类别受保护，禁止删除。

## 八、领料单

领料单模块管理生产领料和普通领料流程。控制器为 `MaterialRequestOrderController`，前端页面位于 `storehouseManage/producePicking/`。

### 领料流程

```
创建领料单（草稿） → 提交审批 → 审批通过 → 扣减库存
                    ↓
                 反审批（库存回退）
```

状态机：`1=草稿 → 2=待审批 → 3=审批通过 → 4=反审批`

领料类型：`1=生产领料`，`2=普通领料`。领料作用细分：`1=交付领料`，`2=运维领料`，`3=办公领料`，`4=其它领料`。

### 领料单主表（r_material_request_order）

约 1031 条记录。核心字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| order_no | varchar(50) | 单号 |
| type | tinyint | 类型：1=生产领料，2=普通领料 |
| user_id | int | 领料人 ID |
| depart_id | int | 领料部门 ID |
| purpose | varchar(100) | 用途 |
| work_station_id | int | 工位 ID |
| status | tinyint | 状态：1=草稿，2=待审批，3=审批通过，4=反审批 |
| flow_id | varchar(32) | 流程 ID |
| material_use | int | 领料作用 |
| maintenance_serial_no | varchar(255) | 保养识别码 |

### 退料单明细表（r_material_return_order_detail）
