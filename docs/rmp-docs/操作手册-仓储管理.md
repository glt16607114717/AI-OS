# 仓储管理 - 用户操作手册

> 适用对象：业务人员（仓管、采购、财务、生产管理人员）  
> 最后更新：2026-06-19

---

## 一、模块概述

仓储管理模块是 RMP 平台的核心模块之一，用于统一管理企业的仓库、仓位、库存、出入库、调拨、盘点等业务。涵盖从仓库基础数据维护到日常出入库操作、库存盘点、物料调拨的完整流程。

**核心业务流程：**
```
仓库/仓位设置 → 物料入库 → 库存管理 → 物料出库/调拨 → 库存盘点 → 盈亏处理
```

## 二、仓库/仓位管理

### 2.1 仓库列表

**【用途】** 管理公司所有仓库信息，包括仓库的新增、编辑、启用/禁用、查看详情。

**【页面路径】** 仓储管理 → 仓库列表

**【主要功能】**

| 区域 | 元素 | 说明 |
|------|------|------|
| 左侧 | 公司树 | 按公司筛选仓库，点击切换公司 |
| 顶部按钮 | 设置 | 自定义表格显示列 |
| 顶部按钮 | 新增 | 跳转到仓库详情页新增仓库 |
| 顶部按钮 | 刷新 | 刷新列表数据 |
| 筛选区 | 仓库编码 | 下拉搜索筛选 |
| 筛选区 | 仓库名称 | 下拉搜索筛选 |
| 筛选区 | 是否启用仓位 | 下拉选择（启用/不启用） |
| 筛选区 | 仓管 | 下拉选择仓管人员 |
| 表格列 | 仓库编号、仓库名称、仓库类型、上级仓库、联系电话、省/市/区、详细地址、仓管、是否启用仓位、备注、状态 | 可自定义显示列 |
| 操作列 | 启用/禁用 | 切换仓库启用状态 |
| 操作列 | 查看 | 跳转到仓库详情页 |

**【操作步骤】**

**新增仓库：**
1. 点击"新增"按钮
2. 进入仓库详情页，填写仓库名称（必填）、选择上级仓库、填写联系电话
3. 选择省/市/区，填写详细地址（必填）
4. 设置"可用库存"开关（是/否）
5. 如需启用仓位管理，可点击"新增仓位"添加仓位
6. 点击"保存"

**启用/禁用仓库：**
1. 在操作列点击"启用"或"禁用"
2. 系统自动切换状态，无需确认

**【校验规则】**

| 字段 | 规则 |
|------|------|
| 仓库名称 | 必填，最多50个字符 |
| 联系电话 | 最多20个字符 |
| 是否仓位 | 必填，只能填0（仓库）或1（仓位） |
| 省/市 | 当是仓库（非仓位）时必填，最多32个字符 |
| 详细地址 | 当是仓库（非仓位）时必填，最多64个字符 |
| 备注 | 最多128个字符 |
| 仓位名称 | 同一仓库下不能重复 |

**【状态说明】**

| 状态 | 说明 |
|------|------|
| 启用 | 仓库正常使用中 |
| 禁用 | 仓库已停用，不可进行出入库操作 |

### 2.2 仓库详情

**【用途】** 查看和编辑单个仓库的详细信息，管理该仓库下的仓位。

**【页面路径】** 仓库列表 → 点击"查看"或"新增"

**【主要功能】**

| 区域 | 元素 | 说明 |
|------|------|------|
| 表单区 | 仓库编号 | 系统自动生成，不可编辑 |
| 表单区 | 仓库名称 | 必填，输入仓库名称 |
| 表单区 | 仓管 | 下拉选择仓管人员 |
| 表单区 | 电话 | 输入联系电话 |
| 表单区 | 上级仓库 | 级联选择上级仓库（编辑时不可修改） |
| 表单区 | 仓库地址 | 省市区选择 + 详细地址输入 |
| 表单区 | 可用库存 | 开关切换（是/否），设为"否"时需选择子类型 |
| 表单区 | 备注 | 输入备注信息 |
| 底部按钮 | 保存 | 保存仓库信息和仓位数据 |
| 仓位表格 | 新增仓位 | 弹出仓位编辑弹窗 |
| 仓位表格 | 序号、仓位编号、仓位名称、备注 | 仓位列表 |

**【操作步骤】**

**新增仓位：**
1. 先填写并保存仓库基本信息
2. 点击"新增仓位"按钮
3. 在弹窗中输入仓位名称、备注
4. 点击确认，仓位自动添加到表格中
5. 点击"保存"提交所有数据

**编辑仓位：**
1. 点击仓位表格中的行
2. 在弹窗中修改仓位名称或备注
3. 点击确认

## 三、库存统计/详情

### 3.1 库存统计

**【主要功能】**

| 区域 | 元素 | 说明 |
|------|------|------|
| 顶部按钮 | 设置 | 自定义表格显示列 |
| 顶部按钮 | 导出 | 导出库存数据 |
| 顶部按钮 | 刷新 | 刷新列表 |
| 筛选区 | 汇总依据 | 切换汇总维度：按仓库 / 按物料 / 按产品类别 |
| 筛选区 | 物料类别 | 弹出类别选择弹窗，支持多选 |
| 筛选区 | 物料型号 | 下拉搜索筛选 |
| 筛选区 | 物料名称 | 下拉搜索筛选 |
| 筛选区 | 所属公司 | 下拉筛选 |
| 展开筛选 | 仓库编号/名称 | 下拉搜索筛选 |
| 展开筛选 | 是否辅料 | 下拉选择（是/否） |
| 展开筛选 | 可用库存 | 输入数量范围 |
| 展开筛选 | 在库时长 | 输入天数范围 |
| 展开筛选 | 显示仓位 | 开关控制是否显示仓位列 |
| 表格列 | 仓库编号、仓库名称、仓位编号、仓位名称、所属公司、物料类别、物料型号、物料名称、规格型号、库存单位、是否辅料、库存数量、在途数量、可用数量 | 按汇总依据变化 |

**【操作步骤】**

**按仓库查看库存：**
1. 汇总依据选择"按仓库"
2. 表格按仓库-仓位-物料展示库存明细
3. 点击库存数量/在途数量/可用数量可查看详细出入库记录

**按物料查看库存：**
1. 汇总依据选择"按物料"
2. 表格按物料型号汇总展示各仓库库存

**按产品类别查看库存：**
1. 汇总依据选择"按产品类别"
2. 选择一级或二级类别
3. 表格按类别汇总展示库存

## 四、盘点管理

### 4.1 盘点任务

**【用途】** 创建和管理盘点任务，对仓库库存进行盘点核对。

**【页面路径】** 仓储管理 → 盘点任务

**【主要功能】**

| 区域 | 元素 | 说明 |
|------|------|------|
| 顶部按钮 | 设置 | 自定义表格显示列 |
| 顶部按钮 | 新增 | 创建盘点任务 |
| 顶部按钮 | 导出 | 导出盘点数据 |
| 顶部按钮 | 审核 | 批量审核选中的盘点单 |
| 顶部按钮 | 反审核 | 批量反审核选中的盘点单 |
| 顶部按钮 | 刷新 | 刷新列表 |
| 筛选区 | 日期范围 | 按创建时间筛选 |
| 筛选区 | 重置 | 清空所有筛选条件 |
| 表格列 | 任务编号、盘点任务名称、盘点仓库、盘点人、盘点日期、盘点备注、锁库、盘点状态、单据状态、所属公司 | 可自定义显示列 |
| 操作列 | 执行盘点 | 开始执行盘点（仅待盘点状态可用） |
| 操作列 | 删除 | 删除盘点单（仅待盘点状态且为创建人） |
| 操作列 | 查看 | 查看盘点详情 |

**【操作步骤】**

**创建盘点任务：**
1. 点击"新增"按钮
2. 填写盘点任务名称（必填，最多50个字符）
3. 选择盘点仓库（必填）
4. 选择盘点人（必填）
5. 设置盘点模式、盘点产品类型、盘点范围
6. 设置是否锁盘（锁盘后盘点期间仓库不可出入库）
7. 点击确认创建

**执行盘点：**
1. 在待盘点状态的任务行点击"执行盘点"
2. 确认弹窗后进入盘点流程
3. 逐项核对物料实际数量与系统数量
4. 完成后提交盘点结果

**审核盘点单：**
1. 勾选需要审核的盘点单
2. 点击"审核"按钮
3. 确认后完成审核

**【校验规则】**

| 字段 | 规则 |
|------|------|
| 盘点任务名称 | 必填，最多50个字符 |
| 盘点仓库 | 必填 |
| 盘点人 | 必填 |
| 库存日期 | 必填 |

**【状态说明】**

| 盘点状态 | 说明 | 可执行操作 |
|----------|------|------------|
| 待盘点（1） | 盘点任务已创建，尚未开始 | 执行盘点、删除 |
| 盘点中（3） | 盘点正在进行 | 继续盘点 |
| 待盈亏处理（2） | 盘点完成，存在差异 | 盈亏处理 |
| 盘点完成（4） | 盘点已完成且无差异 | 查看 |
| 盈亏处理中（5） | 正在处理盈亏 | 查看 |

| 单据状态 | 说明 |
|----------|------|
| 未审核 | 盘点单尚未审核 |
| 审核通过 | 盘点单已审核通过 |
| 反审核 | 盘点单已被反审核 |

## 五、调拨管理

### 5.1 调拨单

**【用途】** 创建和管理仓库之间的物料调拨申请，将物料从一个仓库调拨到另一个仓库。

**【页面路径】** 仓储管理 → 调拨单

**【主要功能】**

| 区域 | 元素 | 说明 |
|------|------|------|
| 顶部按钮 | 设置 | 自定义表格显示列 |
| 顶部按钮 | 新增 | 创建调拨单 |
| 顶部按钮 | 导出 | 导出数据 |
| 顶部按钮 | 刷新 | 刷新列表 |
| 筛选区 | 日期范围 | 按调拨日期筛选 |
| 筛选区 | 重置 | 清空筛选条件 |
| 表格列 | 调拨单号、调拨人、调出仓库、调入仓库、订单编号、状态、备注等 | 可自定义显示列 |
| 操作列 | 删除 | 删除调拨单（仅草稿状态且为创建人） |
| 操作列 | 查看 | 查看调拨单详情 |

**【操作步骤】**

**新增调拨单：**
1. 点击"新增"按钮
2. 选择调入仓库（必填）
3. 选择要调拨的物料，填写调拨数量（必填，必须大于0）
4. 选择调拨人
5. 填写备注
6. 保存提交

**【校验规则】**

| 字段 | 规则 |

| 调入仓库 | 必填 |
| 调拨明细 | 必填 |

**【状态说明】**

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| 草稿（-1） | 调拨单草稿 | 编辑、删除 |
| 未审核（1） | 待审核 | 审核 |

## 十二、常见问题 FAQ

### Q1：仓库和仓位有什么区别？
**A：** 仓库是顶层存储单位（如"原材料仓"、"成品仓"），仓位是仓库下的细分存储位置（如"A区-01货架"）。一个仓库可以有多个仓位。

### Q2：为什么无法删除盘点单？
**A：** 只有盘点状态为"待盘点"且您是创建人的盘点单才能删除。已开始盘点或已完成的盘点单不可删除。

### Q3：调拨单审核后发生了什么？
**A：** 调拨单审核通过后，系统会自动生成调拨出库单（从调出仓库扣减库存）和调拨入库单（向调入仓库增加库存）。

### Q4：锁盘是什么意思？
**A：** 锁盘是指在盘点期间锁定仓库，禁止该仓库进行出入库操作，确保盘点数据准确。盘点完成后解锁。

### Q5：盘点出库和盘点入库是什么？
**A：** 盘点完成后，如果实际库存大于系统库存（盘盈），系统生成盘点入库单增加库存；如果实际库存小于系统库存（盘亏），系统生成盘点出库单减少库存。

### Q6：为什么有些按钮是灰色的？
**A：** 按钮的可用性由两个因素控制：①当前单据的状态（如草稿状态才能编辑）；②您的操作权限（由管理员在角色权限中配置）。

### Q7：如何导出数据？
**A：** 大部分列表页都有"导出"按钮（下载图标），点击后系统后台生成导出文件，可在"导出管理"中下载。

### Q8：库存统计中的"在途数量"是什么？
**A：** 在途数量是指已出库但尚未到达目标仓库的调拨中物料数量。

### Q9：可用库存和总库存有什么区别？
**A：** 总库存 = 可用库存 + 不可用库存。可用库存是可以正常出库的数量，不可用库存包括已锁定、待检等状态的物料。

### Q10：模拟领料和生产领料有什么区别？
**A：** 生产领料会实际扣减仓库库存，用于真实生产场景。模拟领料不扣减真实库存，用于方案模拟和预估场景。
