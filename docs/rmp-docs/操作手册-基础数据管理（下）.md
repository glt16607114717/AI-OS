# 操作手册-基础数据管理（下）

> 适用对象：业务人员、新员工  
> 本文档介绍 RMP 平台基础数据管理模块（下）的操作方法，涵盖字典管理、生命周期状态、审批人、知识库标签、配置管理、系统日志、浏览器管理、执行SQL、版本更新、错误定义、菜单权限、角色管理、附件类别、缓存管理和消息盒子等子模块。

## 字典管理

### 用途
字典管理用于维护系统中各类下拉选项的键值对数据（如状态、类型、级别等），确保各模块引用统一的数据字典。

### 页面路径
- 字典管理：`基础数据管理 → 字典管理`
- 字典标签管理：`基础数据管理 → 字典标签管理`（从字典管理页面点击"字典类型"列进入）

### 主要功能

**字典管理页面元素：**

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 字典名称 | 字典的中文名称 |
| 字典值类型 | 文本/数字/布尔 |
| 字典类型 | 字典的唯一标识（点击可跳转至标签管理） |
| 状态 | 正常 / 停用 |
| 备注 | 字典的备注说明 |
| 创建时间 | 字典创建时间 |

**字典标签管理页面元素：**

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 字典标签 | 标签显示名称 |
| 字典值类型 | 文本/数字/布尔 |
| 字典键值 | 标签对应的存储值 |
| 字典排序 | 排序序号 |
| 状态 | 正常 / 停用 |
| 备注 | 备注说明 |
| 创建时间 | 创建时间 |
| 是否默认 | 是 / 否 |

### 操作步骤

**新增字典：**
1. 进入"字典管理"页面
2. 点击左上角 **添加字典** 按钮
3. 在弹出的表单中填写：
   - **字典名称**：必填，不超过50字
   - **字典类型**：必填，唯一标识，不超过50字
   - **字典值类型**：选择文本/数字/布尔
   - **状态**：选择正常或停用
   - **备注**：选填，不超过255字
4. 点击确认保存

**编辑字典：**
1. 在字典列表中，点击操作列的 **编辑** 按钮
2. 修改需要变更的字段
3. 点击确认保存

**删除字典：**
1. 在字典列表中，点击操作列的 **删除** 按钮
2. 确认删除操作

**管理字典标签：**
1. 在字典列表中，点击某个字典的"字典类型"列（蓝色可点击）
2. 进入该字典的标签管理页面
3. 可进行添加标签、编辑标签、删除标签、设为默认/取消默认操作

**搜索字典：**
- 可按"字典名称""字典类型""状态""创建时间"进行筛选搜索

**搜索标签：**
- 可按"字典名称"下拉选择、"字典标签"文本搜索、"状态"筛选

### 校验规则
- 字典名称：必填，最长50字
- 字典类型：必填，最长50字
- 状态：必选，只能选正常(1)或停用(-1)
- 字典值类型：可选文本(0)/数字(1)/布尔(2)
- 字典标签：必填，最长50字
- 字典键值：必填
- 排序：整数
- 是否默认：必选，是(1)或否(0)

### 状态说明
- **正常**：字典/标签可正常使用
- **停用**：字典/标签不可使用，不会出现在下拉选项中

## 全生命周期状态

### 用途
管理各业务板块在不同阶段的生命周期状态，可配置周期天数、预警天数等参数，用于跟踪业务流转进度。

### 页面路径
`基础数据管理 → 全生命周期状态`

### 主要功能

| 列名 | 说明 |
|------|------|
| 板块 | 所属业务板块 |
| 阶段 | 所处阶段 |
| 生命周期状态 | 当前状态名称 |
| 描述 | 状态描述 |
| 是否显示 | 是 / 否 |
| 周期（天） | 该状态的周期天数 |
| 提前预警（天） | 提前多少天预警 |
| 备注 | 备注说明 |

### 操作步骤

**查看列表：**
1. 进入"全生命周期状态"页面
2. 系统自动加载所有生命周期状态数据
3. 可通过列头筛选：板块、阶段、生命周期状态、是否显示

**编辑状态：**
1. 在列表中，点击操作列的 **编辑** 按钮
2. 在弹出的表单中修改：
   - **是否显示**：是(1)或否(2)
   - **周期（天）**：整数
   - **预警天数**：整数
   - **描述**：最长255字
   - **备注**：最长255字
3. 点击确认保存

**刷新：** 点击 **刷新** 按钮重新加载数据

**重置：** 点击 **重置** 按钮清空所有筛选条件

### 校验规则
- 是否显示：必选，只能选是(1)或否(2)
- 周期天数：必填，整数
- 预警天数：必填，整数
- 描述：最长255字
- 备注：最长255字

### 状态说明
- **是否显示**：控制该生命周期状态在前端页面是否可见
- **周期天数**：该状态的标准持续时间
- **预警天数**：距离到期提前多少天发出预警提醒

## 审批人管理

### 用途
配置各审批环节的必选审批人和可选审批人，确保审批流程中每个环节都有对应的人员负责。

### 页面路径
`基础数据管理 → 审批人管理`

### 主要功能

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 审批环节 | 审批环节名称 |
| 审批人 | 已配置的审批人列表 |

### 操作步骤

**筛选审批环节：**
1. 进入"审批人管理"页面
2. 在顶部下拉框中选择要查看的审批环节
3. 列表自动刷新显示该环节的审批人配置

**编辑审批人：**
1. 在列表中，点击操作列的 **编辑** 按钮
2. 在弹出的"选择审批人"窗口中：
   - 选择**必选审批人**（至少选1人）
   - 选择**可选审批人**（至少选1人）
3. 点击确认保存

### 校验规则
- 审批环节ID：必填，整数，大于0
- 必选审批人用户ID：必填，最长255字
- 可选审批人用户ID：必填，最长255字

### 状态说明
- **必选审批人**：该环节必须由这些人审批，不可跳过
- **可选审批人**：该环节可由这些人中的任意一位审批

## 配置管理

### 用途
管理系统全局配置参数，包括系统关键字、配置显示值、配置值等，用于控制系统的各种开关和参数。

### 页面路径
- 参数配置：`基础数据管理 → 配置管理（configList）`
- 模块配置：`基础数据管理 → 配置管理（configurationManagement）`

### 主要功能

**参数配置（configList）页面元素：**

| 列名 | 说明 |
|------|------|
| 关键字标识 | 配置的唯一标识 |
| 系统关键字 | 系统内部使用的关键字 |
| 配置显示 | 在前端显示的配置名称 |
| 配置值 | 配置的具体值 |
| 是否多选 | 单选 / 多选 |
| 参数描述 | 配置的描述说明 |
| 创建时间 | 创建时间 |
| 修改时间 | 最后修改时间 |

**模块配置（configurationManagement）页面元素：**

| 列名 | 说明 |
|------|------|
| 模块名称 | 所属模块 |
| 配置名称 | 配置项名称 |
| 配置标识 | 配置的唯一标识码 |
| 配置值 | 配置的具体值 |
| 备注 | 备注说明 |
| 创建时间 | 创建时间 |
| 修改时间 | 最后修改时间 |

### 操作步骤

**参数配置：**
1. 进入"配置管理（参数配置）"页面
2. 点击 **添加参数** 按钮新增配置
3. 可通过列头输入框筛选：关键字标识、系统关键字、配置显示、配置值、参数描述
4. 点击操作列的 **编辑** 按钮修改配置
5. 点击 **刷新** 重新加载，点击 **重置** 清空筛选

**模块配置：**
1. 进入"配置管理（模块配置）"页面
2. 点击 **模块管理** 按钮管理模块分类
3. 点击 **新增配置** 按钮添加新配置项
4. 可通过列头筛选：模块名称、配置名称、配置标识
5. 点击操作列的 **编辑** 按钮修改配置
6. 点击 **刷新** 重新加载，点击 **重置** 清空筛选

### 校验规则
（参数配置由后端 configList 接口处理，具体校验规则参见表单提示）

### 状态说明
- **单选**：该配置项只能选择一个值
- **多选**：该配置项可以选择多个值

## 系统登录日志

### 用途
记录和查看所有用户的登录行为，包括登录时间、登录方式、IP地址、浏览器信息、二次验证结果、异常检测结果等，用于安全审计。

### 页面路径
`基础数据管理 → 系统登录日志`

### 主要功能

| 列名 | 说明 |
|------|------|
| 用户名 | 登录账号 |
| 员工姓名 | 用户真实姓名 |
| 登录时间 | 登录发生时间 |
| 登录方式 | 账密/企微扫码/邮箱验证码/微信/小程序 |
| 登录地址 | 登录时的地理位置 |
| IP地址 | 登录IP |
| 操作系统 | 用户操作系统 |
| 浏览器 | 用户浏览器 |
| 浏览器已信任 | 是 / 否 |
| 二次验证 | 未触发/通过/失败 |
| 异常检测 | 是 / 否 |
| 通知 | 是 / 否 |

**展开行可查看：** 浏览器指纹、登录状态、所属公司、异常类型、通知方式

### 操作步骤

**查看日志：**
1. 进入"系统登录日志"页面
2. 系统默认显示近7天的登录日志
3. 可通过顶部时间选择器调整查询时间范围
4. 可通过列头筛选：用户名、员工姓名、登录方式、浏览器已信任、二次验证、异常检测、通知、操作系统、IP地址、登录地址

**排序：** 点击"用户名""登录时间""IP地址"列头可排序

**刷新：** 点击 **刷新** 按钮重新加载数据

**重置：** 点击 **重置** 按钮恢复默认近7天查询

### 校验规则
- 时间范围选择器：不可为空，默认近7天

### 状态说明
- **登录方式**：账密（密码登录）、企微扫码（企业微信扫码）、邮箱验证码、微信、小程序
- **二次验证**：未触发（未开启二次验证）、通过（验证通过）、失败（验证失败）
- **异常检测**：是（检测到异常登录行为）、否（正常登录）
- **浏览器已信任**：是（该浏览器已被信任）、否（未信任）
- **通知**：是（已发送通知）、否（未发送通知）

## 访问日志

### 用途
记录用户对客户信息的访问行为，包括进入时间、退出时间、持续时间、IP地址、使用设备等，用于追踪客户信息的查看记录。

### 页面路径
`基础数据管理 → 访问日志`

### 主要功能

| 列名 | 说明 |
|------|------|
| 日志序号 | 唯一标识 |
| 用户 | 访问用户 |
| 进入时间 | 进入页面的时间 |
| 退出时间 | 离开页面的时间 |
| 持续时间(min) | 停留时长 |
| IP地址 | 访问IP |
| 归属地 | IP归属地（省市） |
| 使用设备 | 使用的设备类型 |
| 页签 | 访问的具体页面/页签 |

### 操作步骤

**查看日志：**
1. 进入"访问日志"页面
2. 系统默认显示近30天的访问日志
3. 可通过顶部筛选：
   - **客户**：下拉选择客户
   - **时间范围**：选择进入时间和结束时间（不超过一年）
4. 可通过列头筛选：日志序号、用户、持续时间、IP地址、归属地、页签

**排序：** 点击"用户""进入时间""退出时间""持续时间"列头可排序

**导出：** 点击 **导出** 按钮，导出当前筛选条件下的访问日志

**刷新：** 点击 **刷新** 按钮重新加载数据

**重置：** 点击 **重置** 按钮恢复默认查询条件

### 校验规则
- 时间范围：选择的时间段不能超过一年
- 客户选择：可选，支持模糊搜索

### 状态说明
- **页签**：记录用户访问的具体页面，如客户信息、客户联系人、工位需求、工位方案、机器人列表等

## 操作日志

### 用途
记录系统中所有API请求的操作日志，包括请求参数、请求结果、请求用时、操作人等信息，用于问题排查和操作审计。

### 页面路径
- 操作日志列表：`基础数据管理 → 操作日志`
- 操作日志详情：`基础数据管理 → 操作日志详情`（从列表点击"详情"进入）

### 主要功能

**操作日志列表页面元素：**

| 列名 | 说明 |
|------|------|
| 引用平台 | rmp/财务/流程/图表 |
| 来源 | 小程序/pc/h5 |
| 操作人 | 执行操作的用户 |
| 菜单链 | 操作的菜单路径 |
| 动作 | 操作动作描述 |
| 请求方法 | GET/POST/PUT/DELETE |
| 页面路由 | 前端路由路径 |
| 后端路由 | 后端路由地址 |
| 控制器/方法 | 后端控制器和方法 |
| 请求状态 | 成功(绿色) / 失败(红色) |
| 请求用时(ms) | 接口响应时间 |
| 请求时间 | 请求发生时间 |
| 请求ip | 请求来源IP |
| 后端负责人 | 后端开发负责人 |
| 前端负责人 | 前端开发负责人 |
| 产品负责人 | 产品负责人 |
| 测试负责人 | 测试负责人 |

**操作日志详情页面：**
- 左侧显示基本信息（引用平台、来源、菜单链、动作、请求方法、请求状态、页面路由、控制器/方法、后端路由、请求用时、请求时间、IP地址、操作人、各负责人）
- 左侧下方显示请求参数（支持参数列表视图和原生参数视图切换，可复制）
- 右侧显示请求结果（以树形结构展示，可复制）

### 操作步骤

**查看操作日志：**
1. 进入"操作日志"页面
2. 系统默认显示近30分钟的操作日志
3. 可通过顶部筛选：
   - **时间范围**：选择开始和结束时间（不允许跨月份查询）
   - **列表ID**：输入日志ID搜索
   - **引用平台**：下拉选择rmp/财务/流程/图表
   - **操作人**：输入操作人搜索
   - **页面路由**：输入前端路由搜索
   - **后端路由**：输入后端路由搜索
   - **控制器/方法**：输入控制器和方法搜索
4. 点击 **展开** 可显示更多筛选条件：请求参数、请求结果、错误信息、请求状态、请求用时、后端负责人、前端负责人、产品负责人、测试负责人

**查看详情：**
1. 在列表中，点击操作列的 **详情** 按钮
2. 进入详情页面查看请求参数和请求结果的完整信息
3. 可复制页面路由、控制器/方法、后端路由、IP地址
4. 可勾选请求参数并复制
5. 可复制请求结果

**刷新：** 点击 **刷新** 按钮重新加载数据

**重置：** 点击 **重置** 按钮恢复默认近30分钟查询

### 校验规则
- 时间范围：不允许跨月份查询
- 请求用时搜索：必须输入数字

### 状态说明
- **请求状态**：成功（绿色显示）、失败（红色显示）
- **请求用时**：≤1000ms 绿色显示，>1000ms 红色显示
- **引用平台**：rmp（蓝色标签）、财务（黄色标签）、流程（橙色标签）、图表（绿色标签）

### 用途

### 主要功能

| 列名 | 说明 |
|------|------|

| 所属公司 | 用户所属公司 |
| 浏览器 | 浏览器名称和版本 |
| 操作系统 | 操作系统信息 |

1. 在档案或支出管理页面，进入分类管理
2. 选择目标模块
3. 点击添加分类按钮
4. 填写：
   - **模块**：必填，最长32字
   - **类别名称**：必填，最长32字
   - **上级分类**：可选，选择父级分类
   - **排序**：整数，不小于0
   - **状态**：正常(1)或停用(-1)
   - **是否系统类别**：是(1)或否(2)
5. 点击确认保存

**编辑分类：**
1. 在分类树中选择目标分类
2. 修改分类信息
3. 保存

**删除分类：**
1. 选择目标分类
2. 点击删除
3. 确认删除

### 校验规则
- 模块：必填，最长32字
- 类别名称：必填，最长32字
- 上级分类ID：整数，不小于0
- 排序：整数，不小于0
- 状态：只能选正常(1)或停用(-1)
- 是否系统类别：只能选是(1)或否(2)

### 状态说明
- **正常**：分类可正常使用
- **停用**：分类不可使用
- **系统类别**：系统预置的分类，不可删除
- **自定义类别**：用户自行创建的分类

## 缓存管理

### 用途
管理系统的一级缓存，支持查看缓存列表、清除缓存和预热缓存，用于系统性能优化和缓存维护。

### 页面路径
`基础数据管理 → 缓存管理`

### 主要功能

| 列名 | 说明 |
|------|------|
| 缓存名称 | 缓存的名称标识 |
| 缓存关键字 | 缓存的唯一键值 |

### 操作步骤

**查看缓存列表：**
1. 进入"缓存管理"页面
2. 系统自动加载所有一级缓存数据
3. 支持分页浏览（每页10/50/200/500/1000条）

**清除单个缓存：**
1. 在列表中，点击操作列的 **清除** 按钮
2. 系统立即清除该缓存

**预热单个缓存：**
1. 在列表中，点击操作列的 **预热** 按钮
2. 系统立即重新加载该缓存数据

**批量清除：**
1. 勾选要清除的缓存记录（可多选）
2. 点击 **批量清除** 按钮
3. 系统清除所有选中的缓存

**批量预热：**
1. 勾选要预热的缓存记录（可多选）
2. 点击 **批量预热** 按钮
3. 系统重新加载所有选中的缓存数据

**刷新：** 点击 **刷新** 按钮重新加载缓存列表

### 校验规则
- 批量清除：必须先勾选缓存记录
- 批量预热：必须先勾选缓存记录

### 状态说明
- **清除**：删除缓存数据，下次访问时重新生成
- **预热**：主动加载缓存数据，提升首次访问速度

## 消息盒子

### 用途
接收和查看系统推送的消息通知，支持标记已读和查看未读消息数量。

### 页面路径
消息盒子通常以顶部通知图标形式展示，点击可查看消息列表。

### 主要功能

- 消息列表：分页展示当前用户的所有消息
- 未读消息提醒：显示未读消息数量
- 消息已读标记：支持单条或批量标记已读
- 消息筛选：可按已读/未读状态筛选

### 操作步骤

**查看消息：**
1. 点击页面顶部的消息通知图标
2. 系统显示消息列表，包含消息类型、标题、内容、发送时间等
3. 可按已读/未读状态筛选消息

**标记已读：**
1. 在消息列表中，选择要标记的消息
2. 点击标记已读
3. 系统更新消息状态

**查看未读数量：**
- 顶部消息图标旁显示未读消息数量角标

### 校验规则
- 标记已读：必须提供消息ID

### 状态说明
- **未读**：消息尚未被查看
- **已读**：消息已被查看
