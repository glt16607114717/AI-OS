# 操作手册 - 设备与产品管理

> 适用对象：业务人员（非开发）  
> 本手册涵盖设备库浏览、产品详情查看、识别码管理、摄像头管理等模块的操作指南。

---

## 一、产品管理（设备库）

### 【用途】

以卡片形式浏览所有设备（物料），支持全文检索、按设备类型/公司/时间筛选，快速查看库存数量、ECN 版本、产品码数量等关键信息，并导出设备数据。

### 【页面路径】

左侧菜单 → 设备与产品管理 → 设备库

### 【主要功能】

| 区域 | 功能说明 |
|------|---------|
| 顶部搜索栏 | 全文检索、新增时间范围筛选、库存范围筛选（当前公司/全部/指定公司） |
| 展开搜索栏 | 按设备类型筛选、按设备名称/设备编号模糊搜索 |
| 卡片列表 | 以卡片形式展示设备，每张卡片显示封面图、产品类别、设备名称、设备型号、版本号、库存数量、ECN 信息、产品码数量、可用库存、安全库存、最高库存、设备概述 |
| 导出按钮 | 导出设备列表（Excel）或设备使用频次表 |
| 库存明细弹窗 | 点击库存数量打开库存明细，可按机器人编号/识别码、所属公司、仓库、仓位、状态筛选 |
| 设备编号列表弹窗 | 点击产品码数量打开设备编号列表，支持批量导出 |
| ECN 版本记录弹窗 | 点击 ECN 信息查看版本变更记录 |

### 【操作步骤】

#### 浏览设备
1. 进入设备库页面，系统自动加载设备卡片列表
2. 在搜索框中输入关键词（设备名称/型号/编号），按回车或点击搜索按钮进行全文检索
3. 展开搜索栏，可按设备类型下拉筛选，或按设备名称/编号模糊搜索
4. 点击"重置"按钮清空所有筛选条件

#### 查看库存明细
1. 在设备卡片上点击"库存数量"数字
2. 弹出库存明细弹窗，显示该设备在各仓库/仓位的库存情况
3. 可通过机器人编号/识别码、所属公司、仓库名称/编号、仓位名称/编号、状态（在途/在库）筛选
4. 对于需要保养的设备，还会显示质检人员、开始使用时间、距下次保养天数

#### 查看设备编号
1. 在设备卡片上点击"产品码数量"数字
2. 弹出设备编号列表弹窗，显示每个设备的编号、识别码、所在仓库/仓位/工位
3. 点击"批量导出"按钮可将列表导出为 Excel
4. 点击"设备信息详情"可跳转到产品详情页

#### 查看 ECN 版本记录
1. 在设备卡片上点击"ECN 信息"区域
2. 弹出 ECN 版本记录弹窗，显示该设备所有版本号和备注

#### 导出数据
1. 点击顶部"导出"按钮（下载图标），导出当前筛选条件下的设备列表
2. 点击"频次导出"按钮（第二个下载图标），导出设备使用频次表

#### 查看产品详情
1. 点击设备卡片上的封面图或设备型号
2. 跳转到产品详情页

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 日期范围 | 不能超过 3 个月，否则提示"日期范围不能超过三个月，请重新选择" |
| 全文检索 | 支持模糊匹配设备名称、型号、编号等 |

### 【状态说明】

- 设备卡片上显示"停产"标签表示该设备已停产（`is_stop_product = 1`）
- 库存明细中状态列显示"在途"或"在库"

## 二、产品详情（含 ECN 变更）

### 【用途】

查看单个设备的完整信息，包括设备图片轮播、基本信息、技术资料（PDF/文件）、品质资料、库存明细、周边设备、版本与 GitLab 管理、ECN 变更记录。

### 【页面路径】

从设备库点击设备卡片 → 产品详情页  
路径：`/devicesManage/productsDetaile?id=设备ID`

### 【主要功能】

| 区域 | 功能说明 |
|------|---------|
| 左侧图片轮播 | 展示设备封面图和照片，支持点击放大预览 |
| 右侧基本信息 | 设备型号、设备名称、版本号（可编辑）、GitLab 链接（可编辑）、规格/主要参数、属性、用途、单位、设备概述、金蝶对应物料编码、ECN 信息 |
| 技术资料标签页 | 按类型（如使用手册、维护手册等）切换，展示 PDF 文件或下载链接 |
| 库存数量 | 显示库存总数，点击打开库存明细弹窗 |
| 资料清单按钮 | 跳转到方案资料清单页 |
| 品质资料 | 上传/查看/删除品质相关文件（PDF、Word、压缩包） |
| 右侧周边设备 | 显示相关周边设备列表，点击可跳转 |
| 版本管理 | 编辑版本号和 GitLab 链接，查看历史版本 |
| ECN 变更 | 新增 ECN 版本或绑定识别码到 ECN 版本 |

### 【操作步骤】

#### 查看设备信息
1. 进入产品详情页，自动加载设备图片、基本信息和第一个技术资料标签页
2. 点击技术资料标签页切换查看不同类型的文档
3. PDF 文件直接在页面内预览，非 PDF 文件显示为可下载标签

#### 编辑版本信息
1. 在"版本号"或"GITLAB"行点击"编辑"按钮
2. 输入新的版本号（最长 15 个字符）和 GitLab 链接（最长 500 个字符）
3. 点击"保存"提交，点击"取消"恢复原值
4. 点击 GitLab 链接可直接跳转到 GitLab 页面

#### 查看历史版本
1. 点击"查看历史版本"链接
2. 弹出历史版本弹窗，显示所有版本号及对应的 GitLab 链接
3. 点击某条记录可复制 GitLab 链接

#### 管理品质资料
1. 点击"品质资料"按钮，打开文件上传弹窗
2. 支持上传 PDF、Word、压缩包文件，单次最多 50 个
3. 上传后文件显示在品质资料列表中，点击可下载
4. 点击文件旁的删除图标可删除品质资料

#### 新增 ECN
1. 在"ECN 信息"行点击"新增ECN"
2. 弹出新增 ECN 弹窗，设备型号自动回填（不可修改）
3. 版本号自动生成（无需手动输入）
4. 输入备注（必填，最长 200 字）
5. 点击"确认"提交

#### 绑定识别码
1. 在"ECN 信息"行点击"绑定识别码"
2. 弹出绑定识别码弹窗，左侧显示 ECN 版本列表
3. 点击某个版本选中，右侧自动回填该版本的备注和已绑定的识别码
4. 在"绑定ECN"下拉框中搜索并选择要绑定的识别码（支持多选）
5. 点击"确认"提交

#### 查看库存明细
1. 点击"库存数量"数字
2. 弹出库存明细弹窗（同设备库中的库存明细）

#### 查看资料清单
1. 点击"资料清单"按钮
2. 跳转到方案资料清单页

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 版本号 | 必填，最长 15 个字符 |
| GitLab 链接 | 必填，最长 500 个字符，必须以 `http://` 或 `https://` 开头 |
| ECN 备注 | 必填，最长 200 字 |
| 绑定识别码 | 必选，至少选择一个识别码 |
| ECN 版本（绑定时） | 必须先选择左侧的 ECN 版本 |

### 【状态说明】

- 设备左上角显示"停产"标签表示该设备已停产

## 三、产品列表（方案资料清单）

### 【用途】

管理每个设备方案开发过程中需要交付的文档清单，按开发节点（设备初始版开发设计、设备设计评审、设备功能样机评审、设备开发设计、设备量产样机评审）组织，支持填写 Git 路径和跳转。

### 【页面路径】

从产品详情页点击"资料清单"按钮进入  
路径：`/devicesManage/productsList?id=设备ID`

### 【主要功能】

| 区域 | 功能说明 |
|------|---------|
| 标题栏 | 显示"方案资料清单"，右侧有编辑/保存按钮 |
| 表格 | 按节点分组的文档清单，包含节点名称、文件名称、GIT 路径三列 |
| 操作列 | 自定义添加的行可删除；填写了 HTTP/HTTPS 链接的行可跳转 |
| 底部按钮 | 编辑模式下显示"添加一行"按钮 |

### 【操作步骤】

#### 查看资料清单
1. 进入页面后自动加载该设备的资料清单
2. 表格按"节点"列合并单元格，同一节点的文件归为一组

#### 编辑资料清单
1. 点击右上角"编辑"按钮，进入编辑模式
2. GIT 路径列变为可编辑状态
3. 在 GIT 路径输入框中填写文档的 Git 仓库链接

#### 添加自定义行
1. 在编辑模式下，点击底部"添加一行"按钮
2. 新增一行空白记录，可填写节点名称、文件名称、GIT 路径
3. 自定义添加的行会显示"删除"按钮

#### 删除自定义行
1. 点击自定义行操作列的"删除"按钮
2. 确认删除弹窗，点击"确定"删除

#### 跳转到 Git 仓库
1. 如果 GIT 路径以 `http://` 或 `https://` 开头，操作列会显示"跳转"按钮
2. 点击"跳转"按钮，在新标签页打开该链接

#### 保存
1. 编辑完成后点击右上角"保存"按钮
2. 系统保存所有修改，GIT 路径列恢复为只读状态

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 文件清单数据 | 必填，至少一条记录 |
| 设备 ID | 必填 |

### 【状态说明】

- 系统预设了 5 个节点的文档模板（约 40+ 个预设文档项）
- 自定义添加的行 `is_custom = 1`，可删除；预设行 `is_custom = 2`，不可删除

## 四、识别码生成

### 【用途】

生成机器人编号（适用于 A 类设备）和识别码（适用于 B/C 类设备），支持导出生成的编号/识别码清单。

### 【页面路径】

左侧菜单 → 设备与产品管理 → 识别码生成

### 【主要功能】

| 标签页 | 功能说明 |
|--------|---------|
| 机器人编号生成 | 选择机器人型号 → 输入需求数量 → 系统自动生成机器人编号并导出 |
| 识别码生成（适用 B/C 类） | 输入所需识别码数量 → 系统生成识别码并导出，同时显示系统已有最新识别码 |

### 【操作步骤】

#### 生成机器人编号
1. 切换到"机器人编号生成"标签页
2. 在"机器人型号"下拉框中搜索并选择目标型号（必选）
3. 在"机器人需求数量"输入框中输入数量（1~2000）
4. 系统自动显示"最新机器人编号"
5. 点击"生成并导出"按钮
6. 系统生成机器人编号并触发导出

#### 生成识别码
1. 切换到"识别码生成（适用 B/C 类）"标签页
2. 在"识别码需求数量"输入框中输入数量（只允许数字）
3. 点击"生成并导出"按钮
4. 系统生成识别码并触发导出
5. 页面自动更新显示"系统已有识别码"最新值

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 机器人型号 | 必选 |
| 机器人需求数量 | 必填，范围 1~2000 |
| 识别码需求数量 | 必填，范围 1~2000，只允许输入数字；单次最大 2000 |

## 五、识别码查询

### 【用途】

通过序列号或型号查询设备信息，包括设备基本信息、所在公司/仓库/仓位/工位，以及同工位下的其他设备。

### 【页面路径】

左侧菜单 → 设备与产品管理 → 识别码查询

### 【主要功能】

| 标签页 | 功能说明 |
|--------|---------|
| 序列号查询 | 输入序列号，查询该设备详细信息及同工位其他设备 |
| 型号查询 | 输入型号关键词，模糊搜索匹配的设备列表 |

### 【操作步骤】

#### 序列号查询
1. 切换到"序列号查询"标签页
2. 在搜索框中输入完整的序列号（如 `NC-A-0001-0000001`）
3. 点击搜索按钮
4. 查询结果显示：
   - 设备详情表单：公司名称、所在仓库、所在仓位、工位名称、工位编号、序列号、设备名称、设备型号、设备类别
   - 下方表格：当前工位其他设备列表（序列号、设备名称、设备型号、设备类别、部署/调拨时间、操作人）

#### 型号查询
1. 切换到"型号查询"标签页
2. 在搜索框中输入型号关键词
3. 点击搜索按钮
4. 查询结果显示匹配的设备列表（序列号、设备名称、设备型号、设备类别、所在仓库、绑定时间、最新变动时间、操作人）
5. 支持分页浏览

## 六、绑定识别码

### 【用途】

将识别码范围批量绑定到产品型号，或解除已绑定的识别码。支持识别码范围校验、自动检测绑定状态、产品图片预览。

### 【页面路径】

左侧菜单 → 设备与产品管理 → 绑定识别码

### 【主要功能】

| 区域 | 功能说明 |
|------|---------|
| 识别码范围 | 输入起始识别码和结束识别码，自动计算数量 |
| 类型/型号选择 | 选择产品类型（量产/打样）和产品型号 |
| 预计绑定产品编号 | 自动显示最新产品编号 |
| 绑定/解绑按钮 | 执行绑定或解绑操作 |
| 产品图片轮播 | 选中型号后展示产品图片 |

### 【操作步骤】

#### 绑定识别码
1. 在"识别码"区域输入起始识别码和结束识别码（只允许数字）
2. 系统自动计算并显示数量（结束 - 起始 + 1）
3. 失去焦点后，系统自动检测该范围内的识别码是否已绑定
4. 在"类型"下拉框中选择产品类型（量产产品 / 打样产品）
5. 在"型号"下拉框中搜索并选择产品型号
6. 系统自动显示"预计绑定产品编号"
7. 右侧展示该型号的产品图片
8. 点击"绑定"按钮执行绑定

#### 解绑识别码
1. 输入已绑定的识别码范围
2. 失去焦点后系统自动回填已绑定的产品信息（类型、型号、名称、产品编号）
3. 点击"解绑"按钮
4. 弹出确认对话框，显示起始识别码、结束识别码、产品名称、产品编码
5. 点击"确定解绑"执行解绑

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 识别码起始 | 必填，只允许数字，不能超出系统范围 |
| 识别码结束 | 必填，只允许数字，不能超出系统范围 |
| 类型 | 必选 |
| 型号 | 必选（需先选择类型） |
| 识别码范围 | 必须为连续的识别码，且范围内的识别码全部为未绑定设备的有效识别码 |

### 【状态说明】

- 输入识别码范围后，系统自动检测绑定状态：
  - 未绑定：显示"绑定"按钮可用，"解绑"按钮禁用
  - 已绑定：自动回填产品信息，"解绑"按钮可用，"绑定"按钮禁用

## 七、识别码管理

### 【用途】

通过识别码查询产品详细信息，包括产品类别、型号、名称、编号、所在仓库/仓位/工位，以及所在工位的设备明细。

### 【页面路径】

左侧菜单 → 设备与产品管理 → 识别码管理

### 【主要功能】

| 区域 | 功能说明 |
|------|---------|
| 搜索框 | 输入识别码进行查询 |
| 产品信息表单 | 显示产品类别、产品型号、产品名称、产品编号、所在仓库、所在仓位、所在工位编号、所在工位名称 |
| 设备明细表格 | 显示所在工位的设备明细（序号、识别码、产品类别、产品型号、产品名称、产品编号、生产时间、入库时间、出库时间、部署时间、撤回时间） |

### 【操作步骤】

1. 在搜索框中输入识别码
2. 点击搜索按钮
3. 如果识别码存在且已绑定产品，显示产品信息表单和所在工位的设备明细
4. 如果识别码不存在，显示"产品不存在"提示
5. 如果识别码未绑定任何内容，显示"此识别码未绑定任何内容"提示

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 识别码 | 必填，不能为空 |

## 八、摄像头管理

### 【用途】

维护摄像头基础信息，包括编号、名称、品牌、序列号、IP 地址、播放地址、安装日期，支持新增、编辑、删除操作。

### 【页面路径】

左侧菜单 → 设备与产品管理 → 摄像头管理

### 【主要功能】

| 区域 | 功能说明 |
|------|---------|
| 表格 | 展示所有摄像头列表，列：序号、摄像头编号、摄像头名称、品牌、序列号、IP 地址、播放地址、状态、安装日期 |
| 添加按钮 | 打开添加摄像头弹窗 |
| 操作列 | 编辑、删除按钮 |
| 表头筛选 | 支持按各列排序和筛选 |

### 【操作步骤】

#### 添加摄像头
1. 点击"添加摄像头"按钮
2. 弹出添加摄像头弹窗，填写以下信息：
   - **摄像头编号**（必填，最长 32 个字符）
   - **摄像头名称**（必填，最长 50 个字符）
   - 品牌（选填）
   - 序列号（选填）
   - IP 地址（选填）
   - 播放地址（选填）
   - 安装日期（选填，日期选择器）
3. 点击"确认"保存

#### 编辑摄像头
1. 在表格操作列点击"编辑"按钮
2. 弹出编辑摄像头弹窗，表单自动回填当前数据
3. 修改需要变更的字段
4. 点击"确认"保存

#### 删除摄像头
1. 在表格操作列点击"删除"按钮
2. 弹出确认对话框，提示删除后无法恢复
3. 如果该摄像头已绑定模拟卡位，需先到"摄像头关联卡位"页面解除关联
4. 点击"确认删除"执行删除

#### 刷新/重置
- 点击"刷新"按钮重新加载列表
- 点击"重置"按钮清空所有筛选条件并重新加载

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 摄像头编号 | 必填，最长 32 个字符 |
| 摄像头名称 | 必填，最长 50 个字符 |

### 【状态说明】

| 状态 | 含义 |
|------|------|
| 正常 | 摄像头工作正常 |
| 故障 | 摄像头出现故障 |

## 九、摄像头绑定位置（关联摄像头）

### 【用途】

管理摄像头与模拟卡位的关联关系，支持绑定、更换、解绑摄像头，以及查看更换日志。

### 【页面路径】

左侧菜单 → 设备与产品管理 → 关联摄像头

### 【主要功能】

| 区域 | 功能说明 |
|------|---------|
| 公司筛选 | 级联选择器，按所属公司筛选 |
| 绑定摄像头按钮 | 打开绑定摄像头弹窗 |
| 表格 | 展示关联关系列表，列：序号、关联模拟卡位、摄像头编号、摄像头名称、摄像头状态、绑定状态、安装时间 |
| 操作列 | 更换、日志、解绑按钮 |
| 更换弹窗 | 选择新摄像头替换当前绑定的摄像头，需填写更换原因 |
| 日志抽屉 | 查看指定卡位的摄像头更换历史记录 |

### 【操作步骤】

#### 绑定摄像头
1. 点击"绑定摄像头"按钮
2. 弹出绑定摄像头弹窗：
   - 选择"模拟卡位"（必选，下拉分页搜索）
   - 选择"摄像头"（必选，可多选，仅显示未绑定的摄像头）
3. 点击"确认绑定"
4. 系统将所选摄像头绑定到指定模拟卡位

#### 更换摄像头
1. 在表格操作列点击"更换"按钮（仅已绑定摄像头的卡位可用）
2. 弹出更换摄像头弹窗：
   - 显示原摄像头编号和名称（不可修改）
   - 选择"新摄像头"（必选，仅显示未绑定的摄像头）
   - 输入"更换原因"（必填，最长 500 字）
3. 点击"确认更换"

#### 解绑摄像头
1. 在表格操作列点击"解绑"按钮（仅已绑定摄像头的卡位可用）
2. 弹出确认对话框，显示摄像头编号和模拟卡位信息
3. 点击"确认解绑"
4. 解绑后该摄像头变为未关联状态，可重新绑定到其他模拟卡位

#### 查看更换日志
1. 在表格操作列点击"日志"按钮
2. 右侧弹出抽屉，显示该卡位的摄像头更换历史
3. 日志列表包含：模拟卡位、原绑定摄像头编号、现绑定摄像头编号、操作类型、操作人、更换原因、操作时间
4. 支持按列排序和筛选

#### 公司筛选
1. 使用顶部级联选择器切换公司
2. 选择"全部"可查看该公司及所有子公司的数据

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 模拟卡位（绑定时） | 必选 |
| 摄像头（绑定时） | 必选，至少选一个 |
| 新摄像头（更换时） | 必选 |
| 更换原因 | 必填，最长 500 字 |
| 摄像头 ID（解绑时） | 必填 |
| 模拟卡位 ID（解绑时） | 必填 |

### 【状态说明】

| 绑定状态 | 含义 |
|----------|------|
| 已绑定 | 该卡位已关联摄像头 |
| 未绑定 | 该卡位未关联摄像头 |

| 摄像头状态 | 含义 |
|------------|------|
| 正常 | 摄像头工作正常 |
| 故障 | 摄像头出现故障 |

## 常见问题

### Q1：为什么设备卡片上点击"ECN 信息"提示"未绑定ECN版本"？
A：该设备尚未创建 ECN 版本记录。请进入产品详情页，点击"新增ECN"创建版本。

### Q2：为什么点击"产品码数量"提示"设备编号数量为0"？
A：该设备尚未生成产品编号/识别码。请先在识别码生成页面生成识别码，然后在绑定识别码页面绑定到该设备。

### Q3：绑定识别码时提示"超出系统范围识别码"？
A：输入的识别码起始值或结束值超过了系统已有识别码的最大值。请确认输入的识别码范围在系统有效范围内。

### Q4：为什么无法删除摄像头？
A：如果该摄像头已绑定到模拟卡位，需要先到"关联摄像头"页面解除关联后才能删除。

### Q5：识别码查询时搜索不到结果？
A：请确认输入的序列号完整正确。序列号查询需要完整序列号，型号查询支持模糊匹配。

### Q6：资料清单中如何跳转到 Git 仓库？
A：只有填写了以 `http://` 或 `https://` 开头的完整链接时，操作列才会显示"跳转"按钮。

### Q7：设备库导出时日期范围有什么限制？
A：日期范围不能超过 3 个月，否则系统会提示重新选择。
