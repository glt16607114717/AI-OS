# RMP 平台用户操作手册 —— 采购管理

> 适用对象：采购员、申请人、部门负责人、审批人等业务人员
> 文档目的：帮助业务人员快速掌握采购管理模块各页面的使用方法

***

## 一、模块概述

采购管理是 RMP 平台的核心业务模块之一，覆盖从**需求提出 → 采购下单 → 验货 → 入库 → 退货 → 付款**的完整采购链路。该模块通过流程审批控制每一笔采购的合规性，同时支持商品明细、供应商管理、金额核算等功能。

采购单据的核心流转路径为：

```
采购申请单 → 采购订单 → 采购验货单 → 采购入库单 → 采购退货单
                                          ↓
                                     付款申请单
```

各单据均采用统一的状态流转：草稿 → 待审批 → 审批中 → 审核通过（可反审批回到草稿）。只有在特定状态下才能对单据进行编辑、删除、提交等操作。

## 二、采购申请（procurePpplyFor）

### 【用途】

记录各部门的物料采购需求，作为后续生成采购订单的依据。可手动新增，也可由工位方案中的非量产物料自动带出。

### 【页面路径】

- **列表页**：左侧菜单 → 采购管理 → 采购申请（路由 `/procureManage/procurePpplyFor`）

### 【主要功能】

**顶部操作按钮：**

| 按钮 | 功能               | 权限                         |
| -- | ---------------- | -------------------------- |
| 设置 | 自定义列表显示的列字段      | 所有用户                       |
| 新增 | 创建一张新的采购申请单      | `addProcure` 权限            |
| 采购 | 选中数据后批量生成采购订单    | 需勾选记录                      |
| 导出 | 将当前筛选结果导出为 Excel | `procurePpplyForExport` 权限 |
| 刷新 | 重新加载列表数据         | 所有用户                       |

**筛选区域：**

- 时间范围（单据日期，跨度不能超过一年）
- 重置按钮

**表格列（可自定义）：** 单据编号、单据日期、所属公司、申请部门、申请类型、需求到货时间、入库日期、申请人、审核状态、入库状态、数量、转单数量、入库数量、品牌、商品名称、工位名称、工位编号、商品编码、规格、单位、备注、申请用途等

**行操作按钮：**

| 按钮 | 显示条件                   |
| -- | ---------------------- |
| 删除 | 状态为"草稿"或"反审批"，且后端允许删除时 |
| 查看 | 所有状态均显示                |

**底部合计：** 显示当前页数量的"数量""转单数量""入库数量"汇总。

### 【操作步骤】

**新增采购申请单：**

1. 点击顶部"新增"按钮 → 跳转到采购详情新增页
2. 在详情页填写基本信息和商品明细后保存
3. 详见"采购详情"章节

**批量采购：**

1. 在列表勾选一条或多条采购申请记录
2. 点击"采购"按钮 → 系统将选中的商品合并生成采购订单
3. 跳转到采购订单详情页进行编辑

**查看/编辑单据：**

- 点击"查看"或直接点击行数据
- 如果状态为"草稿"或"反审批"：进入可编辑的详情页
- 其他状态：进入只读详情页

**导出数据：**

1. 设置好筛选条件
2. 点击导出按钮 → 系统异步生成文件
3. 生成完成后到"导出管理"页面下载

### 【校验规则】

- 时间筛选跨度不能超过一年
- 删除操作仅限"草稿""反审批"状态且后端允许的记录

### 【状态说明】

| 状态值 | 状态名称 | 说明             |
| --- | ---- | -------------- |
| 1   | 草稿   | 可编辑、删除，可提交审批   |
| 2   | 待审批  | 已提交，等待审批人处理    |
| 3   | 审批中  | 审批流程进行中        |
| 4   | 审核通过 | 审批完成，可执行后续采购操作 |
| 5   | 反审批  | 已打回，可重新编辑      |

## 三、采购订单列表（purchaseOrder）

查看和管理所有采购订单。采购订单由采购申请转化而来，记录了具体的供应商、价格、交期等商业信息。

### 【页面路径】是

- **列表页**：左侧菜单 → 采购管理 → 采购订单（路由 `/procureManage/purchaseOrder`）

### 【主要功能】

**顶部操作按钮：**

| 按钮 | 功能          | 权限                       |
| -- | ----------- | ------------------------ |
| 设置 | 自定义列表显示的列字段 | 所有用户                     |
| 导出 | 导出当前筛选结果    | `purchaseOrderExport` 权限 |
| 刷新 | 重新加载列表数据    | 所有用户                     |

**筛选区域：**

- 时间范围（跨度不能超过一年）
- 重置按钮

**表格列（可自定义）：** 采购订单编号、采购申请单编号、所属公司、状态、供应商名称、单位、结算方式、入库日期、送货方式、创建人、工位名称、替代品、规格、品牌、单据类型、工位编号、部门、商品名称、商品编码、入库状态、采购数量、入库数量、含税单价、价税合计等

**行操作按钮：**

| 按钮 | 显示条件               |
| -- | ------------------ |
| 删除 | 状态为"草稿"或"反审批"且后端允许 |
| 查看 | 所有状态均显示            |

**底部合计：** 显示"数量"和"价税合计"汇总值。

### 【操作步骤】

**查看采购订单详情：**

- 点击"查看"或直接点击行数据
- 状态为"草稿"或"反审批"：进入可编辑详情页（purchaseOrderDet）
- 其他状态：进入只读详情页（purchaseOrderDetRead）

**导出数据：**

1. 设置筛选条件 → 点击导出按钮
2. 到"导出管理"页面下载

### 【校验规则】

- 删除操作仅限"草稿""反审批"状态且后端允许的记录

### 【状态说明】

与采购申请一致：草稿、待审批、审批中、审核通过、反审批。

## 四、采购订单详情（purchaseOrderDet / purchaseOrderDetRead）

### 【用途】

编辑或查看采购订单的完整信息，包含基本信息、商品明细、附件等。在审核通过状态可执行入库、生成预付单、关闭明细等操作。

### 【页面路径】

- **编辑页**（purchaseOrderDet）：从采购订单列表点击进入，状态为草稿/反审批时
- **只读页**（purchaseOrderDetRead）：状态非草稿/反审批时

### 【主要功能】

**顶部流程按钮：**

- 保存：保存当前编辑内容（需 `purchaseOrderDetSave` 权限）
- 提交审批 / 撤回 / 反审批：通过流程引擎控制
- 打印：状态为审核通过时可打印订单

**基本信息区域字段：**

| 字段    | 是否必填   | 说明                     |
| ----- | ------ | ---------------------- |
| 采购订单号 | 自动生成   | 系统自动分配                 |
| 单据日期  | 自动生成   | 默认当天                   |
| 所属公司  | 自动带出   | 当前登录用户所属公司             |
| 单据类型  | 必填     | 从下拉选择（多选）              |
| 采购员   | 自动带出   | 当前登录用户                 |
| 部门    | 自动带出   | 当前用户所属部门               |
| 收货地址  | **必填** | 默认公司收货地址，可修改           |
| 收货人   | **必填** | 从下拉列表选择（仓管/收货员角色）      |
| 联系方式  | 自动带出   | 选择收货人后自动填充             |
| 付款账号  | 选填     | 最多 30 字符               |
| 申请用途  | **必填** | 从字典中选择                 |
| 供应商名称 | **必填** | 从下拉列表选择已审核通过的供应商       |
| 结算方式  | **必填** | 选择供应商后显示，从下拉选择         |
| 送货方式  | 选填     | 手动输入                   |
| 预付定金  | 选填     | 只能输入数字，最多两位小数，不能大于成交金额 |
| 备注    | 选填     | 最多 500 字符              |

**附件区域：**

- 上传按钮：支持 PDF/图片/Excel，最多 5 个文件
- 可删除附件（需在可编辑状态）

**商品信息表格列：**
商品编码、商品名称、品牌、规格、材质、表面处理、单位、数量、税率(%)、含税单价、未税单价、价税合计、交货日期、采购申请单号、工位名称、工位编号、替代品、关闭状态、可关闭性、供应商名称、备注

**商品行操作按钮（详情页模式）：**

| 按钮    | 显示条件       |
| ----- | ---------- |
| 删除    | 可编辑状态      |
| 生成预付单 | 审核通过状态且有权限 |
| 入库    | 后端判断允许入库时  |
| 关闭    | 可关闭的商品明细   |
| 取消关闭  | 已关闭的商品明细   |

**特殊功能（只读详情页）：**

- 更新交期：批量修改商品明细的交货日期
- 修改备注：批量修改商品明细的备注

### 【操作步骤】

**保存采购订单：**

1. 填写所有必填项（收货地址、收货人、申请用途、供应商、结算方式等）
2. 确认商品明细信息完整（商品名称、含税单价为必填）
3. 点击"保存"按钮
4. 系统校验通过后提示"保存成功"

**提交审批：**

1. 确保订单已保存
2. 点击流程按钮中的"提交" → 系统先自动保存再发起审批
3. 选择审批人并确认

**生成预付单（审核通过后）：**

1. 在子订单区域点击"生成预付单"按钮
2. 跳转到付款申请详情页，自动带出关联信息

**执行入库：**

1. 当后端判断该订单可入库时，"入库"按钮可点击
2. 点击后跳转到采购入库详情页

**关闭商品明细：**

1. 勾选要关闭的商品行
2. 点击"关闭"按钮 → 系统校验勾选行状态一致且满足关闭条件
3. 确认后该行状态变为"已关闭"
4. 如需恢复，选中后点击"取消关闭"

### 【校验规则】

| 校验项  | 规则                                 |
| ---- | ---------------------------------- |
| 收货地址 | 必填，最多 100 字符                       |
| 收货人  | 必填                                 |
| 申请用途 | 必填，取值范围 1-9                        |
| 供应商  | 必填（整数 ID 大于 0）                     |
| 结算方式 | 必填，取值 1-4                          |
| 单据类型 | 必填                                 |
| 商品名称 | 每条明细必填，最多 30 字符                    |
| 数量   | 每条明细必填，正整数大于 0                     |
| 含税单价 | 每条明细必填，浮点数                         |
| 商品编码 | 最多 30 字符                           |
| 备注   | 最多 500 字符                          |
| 预付定金 | 不能大于价税合计总额                         |
| 交货日期 | 不能选择今天之前的日期                        |
| 关闭操作 | 不可同时勾选"已关闭"和"未关闭"的商品；已有入库记录的商品不可关闭 |

### 【状态说明】

- **草稿(1)/反审批(5)**：表单可编辑，商品行可编辑
- **审核通过(4)**：表单只读，但可执行生成预付单、入库、关闭等业务操作；可打印

## 五、采购详情（procureDetails / procureDetailsRead）

### 【用途】

编辑或查看采购申请单的详细信息。新增采购申请、编辑草稿或反审批单据时进入编辑页，其他状态进入只读页。

### 【页面路径】

- **编辑页**（procureDetails）：新增或草稿/反审批状态，路由 `/procureManage/procureDetails`
- **只读页**（procureDetailsRead）：其他状态查看，路由 `/procureManage/procureDetailsRead`

### 【主要功能】

**顶部流程按钮：**

- 保存：保存采购申请单（需 `procureDetailsSave` / `procureDetailsViewSave` 权限）
- 打印：审核通过状态可打印采购申请单
- 采购：审核通过状态，且后端判断可采购时，点击后跳转到采购订单详情页生成订单
- 编辑（只读页）：反审批或草稿状态可切换到编辑模式
- 提交审批 / 撤回 / 反审批：通过流程引擎控制

**基本信息区域字段：**

| 字段     | 是否必填   | 说明              |
| ------ | ------ | --------------- |
| 单据编号   | 自动生成   | 系统自动分配          |
| 单据日期   | 自动生成   | 默认当天            |
| 申请人    | 自动带出   | 当前登录用户          |
| 所属公司   | 自动带出   | 当前用户所属公司        |
| 申请部门   | 自动带出   | 当前用户所属部门        |
| 申请类型   | **必填** | 从下拉多选（排除"打样"类型） |
| 需求到货日期 | **必填** | 不能选择今天之前的日期     |
| 申请用途   | **必填** | 从字典选择           |
| 备注     | 选填     | 最多 500 字符       |
| 工单编号   | 自动带出   | 从工单发起采购时自动填充    |

**附件区域：**

- 上传按钮：支持 PDF/图片/Excel/ZIP，最多 5 个文件
- 可删除附件（需在可编辑状态）

**商品信息表格列：**
工位名称、工位编号、商品编码、商品名称、品牌、规格、材质、表面处理、数量、关闭状态、可关闭性、已转单数量、单位、备注

**商品区域操作按钮：**

| 按钮   | 功能         |
| ---- | ---------- |
| 新增   | 添加一行商品明细   |
| 删除   | 勾选后删除选中的行  |
| 关闭   | 关闭选中的商品明细  |
| 取消关闭 | 恢复已关闭的商品明细 |

### 【操作步骤】

**新增采购申请：**

1. 在采购申请列表点击"新增" → 进入新增页
2. 选择"申请类型"
3. 设置"需求到货日期"
4. 选择"申请用途"
5. 在商品信息区域点击"新增"添加商品行
6. 在每行选择商品编码（支持搜索）→ 系统自动带出商品名称、规格、材质、单位等
7. 填写工位名称、工位编号、数量等
8. 可选：上传附件、填写备注
9. 点击"保存"

**从工位方案自动带入物料：**

- 从工位管理页面发起采购申请时，系统会自动带出该工位方案中的非量产物料

**提交审批：**

1. 确保信息已保存
2. 点击流程"提交"按钮 → 系统先自动保存再发起审批

**执行采购（审核通过后）：**

1. 点击"采购"按钮
2. 跳转到采购订单详情页，系统自动带出未采购完的商品明细

### 【校验规则】

| 校验项    | 规则                |
| ------ | ----------------- |
| 申请类型   | 必填                |
| 需求到货日期 | 必填，不能早于今天         |
| 申请用途   | 必填，取值范围 1-9       |
| 商品明细   | 至少一条              |
| 工位名称   | 非日用类型时必填，最多 50 字符 |
| 商品编码   | 非日用类型时必填，最多 30 字符 |
| 商品名称   | 每条明细必填，最多 120 字符  |
| 数量     | 每条明细必填，正整数大于 0    |
| 备注     | 最多 500 字符         |

### 【状态说明】

- **草稿(1)**：创建人可编辑
- **审核通过(4)**：可打印、可执行采购
- **反审批(5)**：可重新编辑

## 六、采购验货（purchaseInspectionForm / purchaseInspectionDetails）

### 【用途】

对供应商交付的物料进行质量检验，记录合格品、次品、特采数量。验货结果是入库的依据。

### 【页面路径】

- **列表页**（purchaseInspectionForm）：左侧菜单 → 采购管理 → 采购验货单（路由 `/procureManage/purchaseInspectionForm`）
- **详情页**（purchaseInspectionDetails）：路由 `/procureManage/purchaseInspectionDetails`
- **只读详情页**（purchaseInspectionDetailsRead）：查看已保存的验货单

### 【主要功能】

**列表页按钮：**

| 按钮 | 功能      | 权限                                |
| -- | ------- | --------------------------------- |
| 设置 | 自定义列表列  | 所有用户                              |
| 导出 | 导出验货数据  | `purchaseInspectionFormExport` 权限 |
| 刷新 | 重新加载    | 所有用户                              |
| 查看 | 查看验货单详情 | `purchaseInspectionFormView` 权限   |

**列表筛选：** 时间范围、验货单号、采购订单编号、供应商、商品编号、商品名称、数量区间等

**详情页基本信息字段：**

| 字段    | 是否必填   | 说明      |
| ----- | ------ | ------- |
| 验货单号  | 自动生成   | 系统分配    |
| 单据日期  | 自动生成   | 默认当天    |
| 所属公司  | 自动带出   | <br />  |
| 验货日期  | **必填** | 手动选择    |
| 采购订单号 | 自动带出   | 关联的采购订单 |
| 采购子单号 | 自动带出   | <br />  |
| 供应商编码 | 自动带出   | <br />  |
| 供应商名称 | 自动带出   | <br />  |
| 验货人   | 自动带出   | 当前登录用户  |
| 到货时间  | **必填** | 手动选择    |

**详情页按钮：**

| 按钮   | 显示条件                              |
| ---- | --------------------------------- |

## 附录：常见问题

### Q1：采购申请单无法删除？

**A：** 只有"草稿"或"反审批"状态的申请单才能删除，且后端需允许删除（`able_delete = 1`）。已提交审批的单据需先反审批。

### Q2：采购订单中商品行无法关闭？

**A：** 关闭操作需满足以下条件：

- 不能同时勾选"已关闭"和"未关闭"的商品
- 已有入库记录的商品不可关闭
- 已关联付款申请单的商品不可关闭

### Q3：含税单价、未税单价、价税合计如何联动？

**A：**

- 修改"含税单价" → 自动计算"价税合计 = 含税单价 × 数量"
- 修改"数量" → 自动计算"价税合计 = 含税单价 × 数量"
- 修改"价税合计" → 自动反算"含税单价 = 价税合计 ÷ 数量"
- 若填写了"税率" → 自动计算"未税单价 = 含税单价 ÷ (1 + 税率÷100)"
- 税率未填时，未税单价 = 含税单价
- 支持 F6 快捷键批量填充同行数据

### Q4：预付定金填写后无法保存？

**A：** 预付定金不能大于所有商品明细的价税合计总额。请检查总金额是否正确。

### Q5：无法看到金额信息？

**A：** 金额信息受权限控制（`orderSum` 权限）。没有权限的用户看到的税率、单价、金额会显示为"\*\*\*\*"。请联系管理员开通权限。

### Q6：导出文件一直显示"生成中"？

**A：** 大量数据导出需要时间，请耐心等待。如果长时间未完成，可能是任务异常，可到导出管理页面点击"重新生成"。

### Q7：采购验货和入库的关系是什么？

**A：** 正常流程为：先验货再入库。入库详情页如果未关联验货单且状态为审核通过，可点击"验货"按钮创建验货单。验货结果（良品/次品/特采数量）将影响入库类型的选择。

### Q8：需求到货日期/交货日期不能选择过去的日期？

**A：** 这是系统设定的规则，需求到货日期和交货日期均不能早于当天，确保采购计划的合理性。
