# 操作手册-系统与权限管理

> 面向业务人员的操作指南，涵盖用户账户、角色权限、菜单配置、日志审计、系统配置等 16 个子模块。

---

## 用户账户管理

### 用途
管理系统中的所有用户账户，支持添加、编辑、删除账号，并关联角色和公司层级。

### 页面路径
- 左侧菜单 → 权限管理 → 账号管理

### 主要功能

| 功能 | 说明 |
|------|------|
| 左侧公司树 | 按公司层级筛选账号，点击公司节点查看该公司下的所有账号 |
| 搜索 | 支持按昵称、账号、手机号、邮箱、微信、企业微信搜索 |
| 添加账号 | 点击"添加账号"按钮，弹出表单 |
| 编辑账号 | 点击行操作中的"编辑"按钮 |
| 删除账号 | 点击行操作中的"删除"按钮，确认后删除 |

### 操作步骤

**添加账号：**
1. 在左侧公司树中选择目标公司
2. 点击搜索栏右侧的"添加账号"按钮
3. 填写表单：
   - **公司层级**：级联选择器，选择账号所属公司（新增时必填）
   - **昵称**：用户显示名称（必填）
   - **账号**：登录用户名（必填）
   - **密码**：登录密码（必填）
   - **角色**：下拉选择角色类型（必填，角色列表根据所选公司层级动态加载）
   - **备注**：附加说明（选填）
4. 点击"确定"保存

**编辑账号：**
1. 在列表中找到目标账号，点击"编辑"按钮
2. 修改昵称、密码、备注等信息
3. 编辑时公司层级不可修改，账号不可修改
4. 点击"确定"保存

**删除账号：**
1. 点击行操作中的"删除"按钮
2. 在确认弹窗中点击"保存草稿"确认删除

### 校验规则

| 字段 | 规则 |
|------|------|
| 公司层级 | 必选 |
| 昵称 | 必填 |
| 账号 | 必填 |
| 密码 | 必填 |
| 角色 | 必选 |

### 状态说明
- 列表展示：昵称、账号、角色类型、登录类型、备注

## 角色管理

### 用途
管理角色分组和角色，支持按公司（研发中心/服务中心）查看，可新建角色、新建分组、编辑角色、删除角色/分组。

### 页面路径
- 左侧菜单 → 基础数据管理 → 角色管理

### 主要功能

| 功能 | 说明 |
|------|------|
| 公司切换 | 研发中心用户可切换查看"研发中心"或"服务中心"的角色数据 |
| 左侧角色树 | 按分组展示角色列表，点击角色查看其成员 |
| 新建分组 | 在左侧树上方点击"新建分组"按钮 |
| 新建角色 | 在左侧树上方点击"新建角色"按钮 |
| 编辑/删除 | 鼠标悬停在角色或分组上，显示编辑和删除图标 |
| 角色成员 | 点击角色后右侧显示该角色的成员列表 |
| 添加成员 | 点击"添加成员"按钮，从员工列表中选择 |
| 批量移除 | 勾选成员后点击"批量移除"按钮 |

### 操作步骤

**新建分组：**
1. 点击左侧"新建分组"按钮
2. 填写：
   - **分组名称**（必填）
   - **分组排序**：数字，0-1000（必填）
   - **备注**（选填）
3. 点击"确定"

**新建角色：**
1. 点击左侧"新建角色"按钮
2. 填写：
   - **角色名称**（必填）
   - **角色标识**（必填）：命名规则为 `role_公司简称首拼_部门英文首拼_岗位英文`，统一小写，不能包含汉字。例如 IT 部总监角色：`role_ca_it_director`
   - **角色排序**：数字，0-1000（必填）
   - **选择分组**（必填）
   - **角色类型**：下拉选择（必填）
   - **状态**：正常/停用
   - **角色描述**（选填）
3. 点击"确定"

**编辑角色/分组：**
1. 鼠标悬停在角色或分组名称上
2. 点击出现的编辑图标
3. 修改信息后点击"确定"

**删除角色/分组：**
1. 鼠标悬停在角色或分组名称上
2. 点击出现的删除图标
3. 确认删除（注意：系统默认数据不可删除）

**添加角色成员：**
1. 点击左侧角色名称
2. 右侧显示角色成员列表
3. 点击"添加成员"按钮
4. 在弹出的员工列表中勾选员工（可按部门筛选、按姓名/手机号搜索）
5. 点击"确定"

**批量移除成员：**
1. 在成员列表中勾选要移除的成员
2. 点击"批量移除"按钮
3. 确认移除

### 校验规则

| 字段 | 规则 |
|------|------|
| 分组名称 | 必填 |
| 分组排序 | 必填，数字 0-1000 |
| 角色名称 | 必填 |
| 角色标识 | 必填，不能包含汉字，格式：`role_公司_部门_岗位` |
| 角色排序 | 必填，数字 0-1000 |
| 选择分组 | 必选 |
| 角色类型 | 必选 |

### 状态说明
- 系统默认角色（is_system=1）不可编辑和删除
- 角色状态：正常（1）/ 停用（0）
- 角色类型从字典 `role_role_type` 中获取

## 角色权限

### 用途
管理角色的菜单权限分配，通过树形结构勾选菜单和按钮来设置角色的访问权限。

### 页面路径
- 左侧菜单 → 权限管理 → 角色权限

### 主要功能

| 功能 | 说明 |
|------|------|
| 角色列表 | 展示所有角色：角色名称、角色描述、角色类型 |
| 搜索 | 按角色名称搜索 |
| 添加角色 | 点击"添加角色"按钮 |
| 编辑信息 | 修改角色的名称、类型、描述 |
| 编辑权限 | 打开菜单权限树，勾选分配权限 |
| 删除角色 | 删除指定角色 |

### 操作步骤

**添加角色：**
1. 点击"添加角色"按钮
2. 填写：
   - **角色名称**（必填）
   - **角色类型**：下拉选择（必填，编辑时不可修改）
   - **角色描述**（必填）
3. 点击"确定"

**编辑权限：**
1. 在角色列表中点击目标角色的"编辑权限"按钮
2. 在弹出的菜单树中勾选该角色需要访问的菜单和按钮
3. 支持半选（父节点部分子节点被选中）和全选
4. 点击"确定"保存

### 校验规则

| 字段 | 规则 |
|------|------|
| 角色名称 | 必填 |
| 角色类型 | 必选 |
| 角色描述 | 必填 |

### 状态说明
- 角色类型在新增时可选择，编辑时不可修改
- 权限树默认展开第一个菜单节点

## 菜单和按钮

### 用途
管理系统的菜单树和按钮配置，支持菜单/按钮/权限三种类型的节点，可设置路由、负责人、平台等属性。

### 页面路径
- 左侧菜单 → 基础数据管理 → 菜单和按钮

### 主要功能

| 功能 | 说明 |
|------|------|
| 菜单与按钮 Tab | 管理 RMP 平台的菜单树和按钮 |
| 工作台 Tab | 管理工作台按钮（需 `workbenchBtn` 权限） |
| 添加菜单/按钮 | 点击"添加菜单/按钮"按钮 |
| 添加下级 | 在树节点上点击添加下级菜单 |
| 编辑 | 点击树节点上的编辑按钮 |
| 删除 | 点击树节点上的删除按钮 |
| 刷新 | 重新加载菜单树 |
| 重置 | 重置树状态 |

### 操作步骤

**添加菜单/按钮：**
1. 点击"添加菜单/按钮"按钮
2. 填写：
   - **父级菜单/按钮**：级联选择器选择上级节点
   - **类型**：菜单（1）/ 按钮（2）/ 权限（3）
   - **菜单/按钮名称**（必填）
   - **唯一 code**（必填）：字母、数字、下划线、横线组合
   - **路径**：菜单类型时必填，前端路由路径
   - **后台路由**：后端 API 路由（选填）
   - **后端负责人**：下拉选择员工（选填）
   - **前端负责人**：下拉选择员工（选填）
   - **测试负责人**：下拉选择员工（选填）
   - **产品负责人**：下拉选择员工（选填）
   - **操作行为**：
     - 菜单类型：页面（page）
     - 按钮类型：增（add）/ 改（edit）/ 查（show）/ 删（delete）/ 个性化（other）
     - 权限类型：增（add）/ 改（edit）/ 查（show）/ 删（delete）/ 自定义（other）
   - **平台**：PC / APP / IPC（多选，必填）
   - **描述**（选填）
   - **排序**（选填）
   - **状态**：显示（1）/ 隐藏（0）
3. 点击"确定"

**删除菜单/按钮：**
1. 点击树节点上的删除按钮
2. 确认弹窗中会提示节点类型（菜单/按钮）和名称
3. 点击"确认"删除

### 校验规则

| 字段 | 规则 |
|------|------|
| 名称 | 必填 |
| 唯一 code | 必填，字母数字下划线横线，全局唯一 |
| 路径 | 菜单类型时必填 |
| 类型 | 必选（1=菜单, 2=按钮, 3=权限） |
| 操作行为 | 必选 |
| 平台 | 必选（多选） |

### 状态说明
- 状态：显示（1）/ 隐藏（0）
- 类型：菜单（1）需要填写路径；按钮（2）和权限（3）不需要路径

## 菜单权限

### 用途
为角色分配数据范围权限、图表权限、工作台权限和上位机权限，是精细化权限控制的核心页面。

### 页面路径
- 左侧菜单 → 基础数据管理 → 菜单权限

### 主要功能

| 功能 | 说明 |
|------|------|
| 角色分组选择 | 顶部按分组筛选角色，点击角色加载其权限配置 |
| 数据范围 Tab | 配置角色的数据范围权限（按菜单逐项设置） |
| 图表 Tab | 配置角色可查看的图表权限 |
| 工作台 Tab | 配置角色的工作台面板和按钮权限 |
| 上位机 Tab | 配置上位机相关权限 |
| 数据范围选择 | 自身（self）/ 所在公司（company）/ 子公司（subcompany） |
| 保存 | 保存当前角色的权限配置 |
| 重置 | 重置为上次保存的状态 |

### 操作步骤

**配置数据范围权限：**
1. 在顶部角色分组中选择目标角色
2. 切换到"数据范围"Tab
3. 在权限表格中逐项勾选该角色在各菜单下的数据范围
4. 选择数据范围：自身 / 所在公司 / 子公司
5. 点击"保存"按钮

**配置图表权限：**
1. 选择角色后切换到"图表"Tab
2. 勾选该角色可查看的图表
3. 点击"保存"

**配置工作台权限：**
1. 选择角色后切换到"工作台"Tab
2. 勾选该角色可访问的工作台面板和按钮
3. 点击"保存"

**配置上位机权限：**
1. 选择角色后切换到"上位机"Tab
2. 配置上位机相关权限
3. 点击"保存"

### 校验规则
- 保存前必须选择角色
- 切换 Tab 时如有未保存内容会提示确认

### 状态说明
- 数据范围：自身（只能看自己的数据）/ 所在公司（看本公司数据）/ 子公司（看本公司及子公司数据）
- 上位机权限保存独立于其他 Tab

## 权限接口

### 用途
管理后端 API 接口的权限定义，将接口与菜单/按钮 code 关联，实现前后端权限统一。

### 页面路径
- 左侧菜单 → 基础数据管理 → 权限接口

### 主要功能

| 功能 | 说明 |
|------|------|
| 菜单筛选 | 通过级联选择器按菜单树筛选接口列表 |
| 添加权限接口 | 点击"添加权限接口"按钮（需先选择菜单） |
| 编辑 | 点击行操作中的"编辑"按钮 |
| 删除 | 点击行操作中的"删除"按钮 |

### 操作步骤

**添加权限接口：**
1. 在顶部菜单筛选器中选择目标菜单节点
2. 点击"添加权限接口"按钮（未选择菜单时提示"请选择右侧菜单页面进行添加"）
3. 填写：
   - **关联菜单/按钮 code**：自动带入，不可修改
   - **权限名称**（必填）
   - **访问 controller**（必填）：后端控制器名称
   - **访问 action**（必填）：后端方法名称
   - **权限描述**（选填）
   - **操作行为**（必选）：list / add / edit / show / delete / import / export / download
   - **访问 module**（必填）
4. 点击"确定"

### 校验规则

| 字段 | 规则 |
|------|------|
| 权限名称 | 必填 |
| 访问 controller | 必填 |
| 访问 action | 必填 |
| 操作行为 | 必选 |
| 访问 module | 必填 |

### 状态说明
- 列表展示：权限名称、访问 controller、访问 action、权限描述、关联菜单/按钮 code、操作行为、访问 module

## 配置管理

### 用途
管理系统全局配置参数，包括系统参数配置（configList）和模块化配置（configurationManagement）。

### 页面路径
- 左侧菜单 → 基础数据管理 → 配置列表（configList）
- 左侧菜单 → 基础数据管理 → 配置管理（configurationManagement）

### 主要功能

**配置列表（configList）：**

| 功能 | 说明 |
|------|------|
| 添加参数 | 点击"添加参数"按钮 |
| 编辑 | 点击行操作中的"编辑"按钮 |
| 刷新 | 重新加载列表 |
| 重置 | 清空筛选条件 |
| 列头筛选 | 支持按关键字标识、系统关键字、配置显示、配置值、参数描述筛选 |

**配置管理（configurationManagement）：**

| 功能 | 说明 |
|------|------|
| 模块管理 | 管理配置的模块分类 |
| 新增配置 | 添加新的配置项 |
| 编辑 | 修改配置项 |
| 刷新/重置 | 刷新列表或重置筛选条件 |

### 操作步骤

**添加配置参数（configList）：**
1. 点击"添加参数"按钮
2. 填写：
   - **配置名/系统关键字**（必填）
   - **配置值**（必填）
   - **类型**：单选（0）/ 多选（1）（必填）
   - **显示的名称**（必填）
   - **配置标识/关键字标识**（必填）
   - **参数描述**（选填，最多 100 字）
3. 点击"确定"

**编辑配置参数：**
1. 点击行操作中的"编辑"按钮
2. 可修改：显示名称、配置值、参数描述
3. 点击"确定"

**新增模块配置（configurationManagement）：**
1. 点击"新增配置"按钮
2. 填写模块名称、配置名称、配置标识、配置值、备注
3. 点击"确定"

### 校验规则

| 字段 | 规则 |
|------|------|
| 配置名 | 必填 |
| 配置值 | 必填 |
| 类型 | 必选，单选(0)或多选(1) |
| 显示名称 | 必填 |
| 配置标识 | 必填 |
| 参数描述 | 最多 100 字 |

### 状态说明
- 配置类型：单选（0）表示该配置项只能选一个值，多选（1）表示可选多个值

## 系统登录日志

### 用途
查看所有用户的登录记录，包括登录时间、登录方式、IP 地址、浏览器指纹、二次验证结果、异常检测等信息。

### 页面路径
- 左侧菜单 → 基础数据管理 → 系统登录日志

### 主要功能

| 功能 | 说明 |
|------|------|
| 时间筛选 | 顶部时间范围选择器，默认近 7 天 |
| 列头筛选 | 支持按用户名、员工姓名、登录方式、IP、操作系统、浏览器已信任、二次验证、异常检测、通知等筛选 |
| 列头排序 | 支持按用户名、登录时间、IP 地址排序 |
| 展开行 | 点击行首展开图标查看浏览器指纹、登录状态、所属公司、异常类型、通知方式等详情 |
| 刷新 | 重新加载数据 |
| 重置 | 恢复默认查询条件（近 7 天） |

### 操作步骤

**查看登录日志：**
1. 进入页面后自动加载近 7 天的登录日志
2. 可通过顶部时间选择器调整时间范围
3. 使用列头筛选器按条件过滤

**查看登录详情：**
1. 点击行首的展开箭头
2. 展开区域显示：浏览器指纹、登录状态、所属公司、异常类型、通知方式

### 校验规则
- 时间范围选择器不可清空，始终有时间范围

### 状态说明

| 字段 | 可能的值 |
|------|----------|
| 登录方式 | 账密 / 企微扫码 / 邮箱验证码 / 微信 / 小程序 |
| 浏览器已信任 | 是 / 否 |
| 二次验证 | 未触发 / 通过 / 失败 |
| 异常检测 | 是 / 否 |
| 通知 | 是 / 否 |

## 访问日志

### 用途
记录用户访问客户页面的行为日志，包括进入/退出时间、持续时间、IP 地址、归属地、使用设备、访问页签等。

### 页面路径
- 左侧菜单 → 基础数据管理 → 访问日志

### 主要功能

| 功能 | 说明 |
|------|------|
| 客户筛选 | 下拉选择客户，支持模糊搜索和分页加载 |
| 时间筛选 | 日期范围选择器，限制不超过一年 |
| 列头筛选 | 支持按日志序号、用户、持续时间、IP、归属地、页签筛选 |
| 列头排序 | 支持按用户、进入时间、退出时间、持续时间排序 |
| 导出 | 点击"导出"按钮导出访问日志（需 `viewLogExport` 权限） |
| 刷新 | 重新加载数据 |
| 重置 | 恢复默认查询条件 |

### 操作步骤

**查看访问日志：**
1. 进入页面后默认加载近 30 天的数据
2. 通过客户下拉框选择特定客户
3. 通过时间选择器调整时间范围
4. 使用列头筛选器按条件过滤

**导出访问日志：**
1. 设置好筛选条件
2. 点击"导出"按钮
3. 在导出引导弹窗中确认导出

### 校验规则
- 时间范围不能超过一年

### 状态说明
- 持续时间单位为分钟
- 页签包括：客户信息、客户联系人、工位需求、已审核需求、工位方案、工位列表、计费设置、机器人列表、档案资料、夹治具订单、订单列表等

## 操作日志

### 用途
记录系统中所有 API 请求的操作日志，包括请求参数、请求结果、错误信息、请求耗时等，支持查看详情。

### 页面路径
- 左侧菜单 → 基础数据管理 → 操作日志（列表页）
- 点击"详情"按钮进入 → 操作日志详情页

### 主要功能

**操作日志列表：**

| 功能 | 说明 |
|------|------|
| 时间筛选 | 日期时间范围选择器，不允许跨月查询 |
| 多条件搜索 | 支持按列表 ID、引用平台、操作人、页面路由、后端路由、控制器/方法搜索 |
| 展开搜索 | 展开更多搜索条件：请求参数、请求结果、错误信息、请求状态、请求用时、各负责人 |
| 详情 | 点击行操作中的"详情"按钮查看请求详情 |
| 刷新/重置 | 刷新列表或重置搜索条件 |

**操作日志详情：**

| 功能 | 说明 |
|------|------|
| 基本信息 | 展示引用平台、来源、菜单链、动作、请求方法、请求状态、页面路由、控制器/方法、后端路由、请求用时、请求时间、IP 地址、操作人、各负责人 |
| 请求参数 | 以表格形式展示参数 key-value，支持勾选复制；也可切换为原生参数视图 |
| 请求结果 | 以树形结构展示返回结果，支持展开/折叠，支持复制 |
| 复制功能 | 页面路由、控制器/方法、后端路由、IP 地址均可点击复制 |

### 操作步骤

**查看操作日志列表：**
1. 进入页面后默认加载近 30 分钟的数据
2. 设置时间范围（注意不能跨月）
3. 使用搜索框按条件筛选
4. 点击"展开"查看更多搜索条件

**查看操作日志详情：**
1. 在列表中找到目标记录
2. 点击"详情"按钮
3. 详情页左侧展示基本信息和请求参数，右侧展示请求结果树

**复制请求参数：**
1. 在参数列表中勾选需要复制的参数行
2. 点击"复制"按钮
3. 或切换到"原生参数"视图，直接复制原始 JSON

### 校验规则
- 时间范围不允许跨月份查询
- 请求用时搜索必须输入数字

### 状态说明

| 字段 | 说明 |
|------|------|
| 引用平台 | rmp / 财务 / 流程 / 图表 |
| 请求状态 | 成功（绿色）/ 失败（红色） |
| 请求用时 | ≤1000ms 显示绿色，>1000ms 显示红色 |
| 来源 | 小程序 / pc / h5 |

## 浏览器管理

### 用途
管理用户登录的浏览器信任状态，支持移除信任浏览器和强制踢出在线浏览器。

### 页面路径
- 左侧菜单 → 基础数据管理 → 浏览器管理

### 主要功能

| 功能 | 说明 |
|------|------|
| 浏览器列表 | 展示所属用户、所属公司、浏览器、操作系统、在线状态、信任状态、首次信任时间、最近登录时间 |
| 列头筛选 | 支持按用户、公司、浏览器、信任状态、在线状态、首次/最近登录时间筛选 |
| 列头排序 | 支持按首次信任时间、最近登录时间排序 |
| 移除 | 移除浏览器的信任状态，下次登录需重新验证 |
| 踢出 | 强制踢出在线浏览器，登录态立即失效并移除信任 |
| 刷新/重置 | 刷新列表或重置筛选条件 |

### 操作步骤

**移除浏览器：**
1. 在列表中找到目标浏览器（信任状态为"已信任"或"预警"的才能移除）
2. 点击"移除"按钮
3. 确认弹窗中显示用户名和浏览器信息
4. 如果是移除自己当前使用的浏览器，会有额外警告提示
5. 点击"确认移除"

**强制踢出：**
1. 在列表中找到目标浏览器（在线状态为"在线"的才能踢出）
2. 点击"踢出"按钮
3. 确认弹窗提示踢出后登录态立即失效
4. 点击"确认踢出"

### 校验规则
- 移除操作仅对"已信任"或"预警"状态的浏览器可用
- 踢出操作仅对"在线"状态的浏览器可用

### 状态说明

| 字段 | 可能的值 |
|------|----------|
| 信任状态 | 已移除（0）/ 已信任（1）/ 未信任（2）/ 预警（3） |
| 在线状态 | 离线（0）/ 在线（1） |
| 预警状态 | 信任状态为"预警"时行内显示红色标记 |

## 版本更新

### 用途
管理 RMP 平台和上位机的版本发布，支持新增版本、发布版本通知、删除版本。

### 页面路径
- 左侧菜单 → 基础数据管理 → 版本更新

### 主要功能

| 功能 | 说明 |
|------|------|
| 平台切换 | 顶部 Tab 切换 RMP 平台和上位机 |
| 索引 | 点击"索引"按钮查看版本索引 |
| 新增 | 点击"新增"按钮添加新版本 |
| 发布 | 发布版本通知（已发布的版本不可重复发布） |
| 删除 | 删除版本记录 |
| 展开/收起 | 点击版本卡片右下角箭头展开或收起详情 |

### 操作步骤

**新增版本：**
1. 切换到目标平台 Tab（RMP 或上位机）
2. 点击"新增"按钮
3. 填写版本信息（版本号、标题、功能优化、功能新增、附件图片等）
4. 点击"确定"

**发布版本：**
1. 在版本卡片中点击"发布"按钮
2. 确认发布
3. 发布成功后该版本标记为已发布，不可再次发布

**删除版本：**
1. 在版本卡片中点击"删除"按钮
2. 确认删除

### 校验规则
- 已发布的版本（is_send_notice=1）不可再次发布
- 版本卡片展示：版本号、发布日期、标题、作者、功能优化、功能新增、附件图片

### 状态说明
- 版本卡片默认收起，点击右下角箭头展开查看完整描述和附件
- 已发布版本的"发布"按钮置灰不可点击

## 登录与认证

### 用途
用户登录系统，支持多种登录方式：账号密码登录、企业微信扫码登录、微信登录、邮箱验证码登录、小程序登录。

### 页面路径
- 浏览器访问 RMP 系统首页，自动跳转登录页

### 主要功能

| 功能 | 说明 |
|------|------|
| 账号密码登录 | 输入账号和密码登录 |
| 企业微信扫码 | 使用企业微信扫描二维码登录 |
| 微信登录 | 使用微信授权登录 |
| 邮箱验证码 | 输入邮箱获取验证码登录 |
| 小程序登录 | 通过小程序授权登录 |
| 二次验证 | 异地登录或新浏览器登录时触发二次验证 |
| 浏览器指纹 | 自动记录浏览器指纹，信任浏览器可跳过二次验证 |

### 操作步骤

**账号密码登录：**
1. 在登录页输入账号
2. 输入密码
3. 选择登录类型为"账号密码"
4. 点击"登录"按钮
5. 如触发二次验证，输入验证码完成验证

**企业微信扫码登录：**
1. 选择"企业微信"登录方式
2. 使用企业微信扫描页面二维码
3. 确认授权后自动登录

**微信登录：**
1. 选择"微信"登录方式
2. 使用微信扫描二维码或授权
3. 自动登录

### 校验规则

| 字段 | 规则 |
|------|------|
| 账号类型 | 必选，支持：账号密码、企业微信、微信、邮箱验证码、小程序 |
| 账号 | 账号密码登录时必填 |
| 密码 | 账号密码登录时必填 |
| 企业微信授权码 | 企业微信登录时必填 |
| 微信授权码 | 微信登录时必填 |
| 平台 | PC 或 APP |

### 状态说明

| 场景 | 说明 |
|------|------|
| 首次登录 | 需要完整验证 |
| 信任浏览器 | 同一浏览器再次登录可跳过二次验证 |
| 异地登录 | 触发异常检测，可能需要二次验证 |
| 浏览器被移除 | 下次登录需重新验证 |
| 登录失败 | 记录失败原因到登录日志 |
