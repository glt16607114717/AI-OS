# 操作手册-门户与面板

> 适用角色：业务人员、运维人员、所有平台用户  
> 最后更新：2026-06-19

---

## 一、仪表盘

### 用途

仪表盘是登录后的默认首页，以图表形式展示个人 BI 数据中心，帮助您快速了解业务全局。页面内嵌了可视化图表系统，支持全屏查看。

### 页面路径

登录系统后自动进入，或点击左侧菜单"工作台"进入。

- URL 路径：`/dashboard`

### 主要功能

| 功能 | 说明 |
|------|------|
| 图表展示 | 嵌入 BI 图表页面，展示业务数据的可视化图表（如稼动率、收入、工时等） |
| 全屏模式 | 点击全屏按钮可将图表区域切换为全屏查看 |
| 密码修改提醒 | 如果系统检测到您需要修改密码，登录后会弹出提示框，引导您修改账号密码 |
| 版本更新通知 | 当有新的系统消息时，自动弹出更新通知弹窗 |

### 如何查看

1. 登录系统后，默认进入仪表盘页面。
2. 页面会自动加载图表数据，稍等片刻即可看到各类统计图表。
3. 如需全屏查看，点击图表区域的全屏按钮；再次点击或按 `Esc` 键退出全屏。

### 常见问题

**Q：仪表盘页面一直显示加载中？**  
A：请检查网络连接是否正常。如果长时间未加载，可尝试刷新页面或重新登录。

**Q：为什么登录后弹出了"修改账号密码"的提示？**  
A：系统检测到您的密码需要更新，点击"修改账号密码"按钮即可进入个人资料页面修改密码。修改完成后需要重新登录。

**Q：全屏按钮在哪里？**  
A：全屏按钮位于图表区域的右上角，鼠标移入图表区域即可看到。

## 二、工作台

### 用途

工作台是您的个人待办中心，集中展示需要您处理的待办事项数量，方便您快速掌握工作进度并跳转到对应处理页面。

### 页面路径

点击左侧菜单中的"工作台"进入。

- URL 路径：`/workbench`（由权限系统动态加载）

### 主要功能

| 功能 | 说明 |
|------|------|
| 我的待办 | 以卡片形式展示各类待办事项的数量统计 |
| 客户管理 | 显示待审核的客户信息数量，点击可跳转到客户管理页面 |
| 项目管理 | 显示待处理的项目数量 |

### 如何查看

1. 点击左侧菜单"工作台"进入页面。
2. 在"我的待办"卡片中查看各项待办数量。
3. 点击"客户管理"卡片上的数字，可跳转到客户管理页面处理待办事项。

### 常见问题

**Q：为什么"项目管理"显示为 0？**  
A：当前您没有待处理的项目任务。该功能为预留模块，后续版本会完善。

**Q：点击客户管理后跳转到哪里？**  
A：点击后会跳转到"我的客户"页面（`/myAgent`），您可以在此查看和管理分配给您的客户。

## 三、业务面板（客户经理视图）

### 用途

业务面板是客户经理（业务人员）的专属工作视图，用于查看个人基本信息、所管理的机器人列表和客户列表，帮助业务人员一站式掌握名下资产和客户情况。

### 页面路径

点击左侧菜单中的"业务面板"进入。

- URL 路径：`/businessPanel`（由权限系统动态加载）
- 仅"业务员"角色的用户可见

### 主要功能

#### 3.1 个人信息展示

页面顶部展示当前登录用户的基本信息（只读）：

| 字段 | 说明 |
|------|------|
| 昵称 | 当前用户的昵称 |
| 部门 | 所属部门名称 |
| 公司 | 所属公司全称 |
| 简称 | 公司简称 |
| 固话 | 公司固定电话 |
| 地址 | 公司地址 |

#### 3.2 现有机器人

以表格形式展示您所管理的机器人列表，包含以下信息：

| 列名 | 说明 |
|------|------|
| 机器人编号 | 机器人的唯一编号 |
| 工位 | 机器人所在的工位名称 |
| 型号 | 机器人的型号 |
| 状态 | 机器人的当前状态（运行中/空闲/停机/故障等），以彩色圆点标识 |
| 省/市/区/详细地址 | 机器人所在场地的地址信息 |
| 备注 | 补充说明 |

#### 3.3 现有客户

以表格形式展示您所管理的客户列表，包含以下信息：

| 列名 | 说明 |
|------|------|
| 客户名称 | 客户的公司或个人名称 |
| 手机号 | 客户的联系电话 |
| 固话 | 客户的固定电话 |
| 所属业务 | 负责该客户的业务员昵称 |
| 地址 | 客户地址 |
| 备注 | 补充说明 |

### 如何查看

1. 点击左侧菜单"业务面板"进入页面。
2. 顶部查看个人信息（只读，不可修改）。
3. 点击"现有机器人"标签页查看机器人列表。
4. 点击"现有客户"标签页查看客户列表。
5. 列表底部有分页控件，可翻页查看更多数据。

### 筛选条件

- 机器人列表和客户列表均按当前登录的业务员自动筛选，只显示您名下的数据。
- 可通过底部分页控件切换页码和每页显示条数。

### 常见问题

**Q：为什么我看不到"业务面板"菜单？**  
A：业务面板仅对"业务员"角色的用户开放。如果您是其他角色（如运维人员），请使用"DevOps运维面板"。如果角色不正确，请联系管理员调整。

**Q：机器人状态的颜色圆点代表什么？**  
A：绿色表示运行中，灰色表示停机，黄色表示空闲，红色表示故障，蓝色表示调试中。

**Q：为什么客户列表是空的？**  
A：可能您名下暂未分配客户。请联系上级或管理员为您分配客户。

**Q：为什么我看不到"DevOps运维面板"菜单？**

A：现有机器人展示的是您负责的具体机器人设备信息；现有场地展示的是您负责的客户场地信息，一个场地可能部署了多台机器人。

## 五、欢迎页

### 用途

欢迎页是平台的对外展示页面，无需登录即可访问。用于向访客介绍公司业务、提供招工和加盟入口，以及展示公司联系方式和备案信息。

### 页面路径

在浏览器中直接访问平台地址即可看到欢迎页。

- URL 路径：`/welcome`
- 无需登录，公开访问

### 主要功能

| 功能 | 说明 |
|------|------|
| 公司简介 | 展示新佰人机器人公司的介绍信息，包含 PDF 下载链接 |
| 我要招工人 | 点击跳转到客户信息登记页面，供有招工需求的企业填写联系方式 |
| 加入我们 | 点击跳转到加盟信息登记页面，供有意加盟的人才填写信息 |
| 登录 | 点击跳转到系统登录页面 |
| 联系我们 | 展示公司名称、地址、联系电话和微信公众号二维码 |
| 备案信息 | 页面底部展示 ICP 备案号和公安备案号 |

### 如何查看

1. 在浏览器中打开平台网址，即可看到欢迎页。
2. 页面分为三个区域：
   - **顶部横幅区**：展示 WELCOME 标题、公司简介链接和三个操作按钮（我要招工人、加入我们、登录）。
   - **中部卡片区**：三张卡片分别介绍"我要招工人"、"加入我们"和"联系我们"的详细信息。
   - **底部备案区**：展示网站备案信息和版权声明。

### 常见问题

**Q：欢迎页需要登录吗？**  
A：不需要。欢迎页是公开页面，任何访客都可以访问。

**Q：点击"我要招工人"后跳转到哪里？**  
A：跳转到客户信息登记页面（`/customer`），您可以在此填写招工需求，后续会有专人联系您。

**Q：点击"加入我们"后跳转到哪里？**  
A：跳转到加盟信息登记页面（`/franchise`），您可以在此填写个人信息，申请加入平台生态。

**Q：如何查看公司简介 PDF？**  
A：在欢迎页顶部横幅区，点击"公司简介"链接即可下载或在线查看公司介绍 PDF 文件。

**Q：登录后欢迎页还会显示吗？**  
A：登录后系统会自动跳转到仪表盘页面，不再显示欢迎页。如需再次查看欢迎页，需要退出登录。
