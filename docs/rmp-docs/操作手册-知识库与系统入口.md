# 操作手册-知识库与系统入口

> 适用角色：业务人员、新员工  
> 覆盖模块：知识库 / 基础动作 / 登录 / 待入职员工 / 打印 / 外部客户信息登记

---

## 知识库

### 用途

知识库是 RMP 平台的知识沉淀中心，以瀑布流形式展示工艺方案和故障处理两大类知识内容。员工可以在此浏览、搜索、收藏和评论知识条目，方便快速查找和学习。

### 页面路径

- 登录后，在左侧菜单栏点击 **"知识库管理"** → **"知识库"** 进入。

### 主要功能

| 功能区域 | 说明 |
|---------|------|
| 分类标签栏 | 顶部提供四个分类标签：**全部**、**我的收藏**、**工艺方案**、**故障处理**。点击切换可筛选对应类型的知识条目。 |
| 搜索框 | 右侧搜索框支持按 **标题**、**描述**、**标签**、**工艺**、**产品** 五个维度进行搜索。先选择搜索维度，再输入关键词即可。 |
| 瀑布流内容区 | 以卡片瀑布流形式展示知识条目，每张卡片包含封面图和标题。滚动到底部自动加载更多。 |
| 点赞/收藏/评论 | 点击知识条目进入详情页后，可进行 **点赞**、**收藏** 和 **发表评论** 操作。 |
| 分享 | 详情页支持将知识条目 **分享** 给其他同事。 |

### 操作步骤

1. **浏览知识**：进入知识库页面，默认显示"全部"分类，向下滚动浏览知识卡片。
2. **切换分类**：点击顶部标签（工艺方案/故障处理/我的收藏）筛选内容。
3. **搜索知识**：在搜索框下拉选择搜索维度（如"标题"），输入关键词后回车搜索。
4. **查看详情**：点击任意知识卡片进入详情页，查看完整描述、图片和评论。
5. **收藏知识**：在详情页点击"收藏"按钮，该条目将出现在"我的收藏"分类中。
6. **评论互动**：在详情页底部输入评论内容，点击发送即可发表评论。

### 校验规则

- 搜索关键词不能为空。
- 评论内容不能为空。

### 状态说明

- 知识条目无状态流转，以发布即生效的方式展示。

## 基础动作

### 用途

基础动作模块用于管理知识库中的 **工艺方案** 和 **故障处理** 两类知识条目。通过表格列表形式进行新增、编辑和删除操作，是知识库内容的后台管理入口。

### 页面路径

- 登录后，在左侧菜单栏点击 **"知识库管理"** → **"基础动作"** 进入。

### 主要功能

| 功能区域 | 说明 |
|---------|------|
| 新增按钮 | 页面顶部有 **"新增"** 按钮（黄色），点击弹出新增表单。 |
| 列表表格 | 展示所有知识条目，包含以下列：序号、封面、类别、标题、所属工艺、公共标签。 |
| 编辑 | 每行操作列提供 **编辑** 按钮，点击可修改该条目的信息。 |
| 删除 | 每行操作列提供 **删除** 按钮，点击可删除该条目。 |
| 图片预览 | 点击封面图可放大预览。 |

### 操作步骤

#### 新增工艺方案

1. 点击 **"新增"** 按钮，弹出新增对话框。
2. 在"类别"下拉框中选择 **"工艺方案"**。
3. 填写以下必填信息：
   - **标题**：输入方案标题
   - **描述**：输入方案详细描述
   - **公共标签**：选择适用的标签
   - **工艺类型**：选择所属工艺类别
   - **产品**：选择关联的产品
   - **封面图片**：上传封面图
   - **详情图片**：上传详情展示图
4. 点击 **"确定"** 保存。

#### 新增故障处理

1. 点击 **"新增"** 按钮，弹出新增对话框。
2. 在"类别"下拉框中选择 **"故障处理"**。
3. 填写以下必填信息：
   - **故障描述**：输入故障现象描述
   - **所属工艺**：选择关联的工艺类别
   - **解决办法**：输入详细的解决方案
   - **封面图片**：上传封面图
   - **详情图片**：上传详情展示图
   - **公共标签**：选择适用的标签
   - **自定义标签**（选填）：输入自定义标签
   - **相关链接**（选填）：输入关联链接名称和地址
4. 点击 **"确定"** 保存。

#### 编辑知识条目

1. 在列表中找到目标条目，点击操作列的 **"编辑"** 按钮。
2. 在弹出的对话框中修改信息。
3. 点击 **"确定"** 保存修改。

#### 删除知识条目

1. 在列表中找到目标条目，点击操作列的 **"删除"** 按钮。
2. 确认删除操作。

### 校验规则

| 字段 | 规则 |
|------|------|
| 类别 | 必选，可选"工艺方案"或"故障处理" |
| 标题 | 必填，最长 255 个字符 |
| 描述 | 必填 |
| 公共标签 | 必选 |
| 工艺类型 | 必选（工艺方案时） |
| 产品 | 必选（工艺方案时） |
| 封面图片 | 必须上传 |
| 详情图片 | 必须上传 |
| 故障描述 | 必填（故障处理时） |
| 所属工艺 | 必选（故障处理时） |
| 解决办法 | 必填（故障处理时） |

### 状态说明

- 知识条目无状态流转，保存后即生效展示在知识库中。

## 登录

### 用途

RMP 平台（新佰人智能机器人管理平台）的登录入口，支持三种登录方式：**账号密码登录**、**企业微信扫码登录** 和 **微信扫码登录**。

### 页面路径

- 浏览器访问 RMP 平台地址，自动跳转至登录页。
- 页面路径：`/login`

### 主要功能

| 功能区域 | 说明 |
|---------|------|
| 登录方式切换 | 顶部提供三个图标按钮：**企业微信登录**、**微信登录**、**账号密码登录**。默认选中账号密码登录。 |
| 公司选择 | 企业微信登录模式下，需先选择所属公司。 |
| 账号密码表单 | 输入 **账号** 和 **密码**，支持"记住密码"功能。 |
| 验证码 | 系统根据安全策略自动判断是否需要验证码（图形验证码或邮箱验证码）。 |
| 联系 IT | 当账号被锁定或需要 IT 协助时，系统会弹出"联系 IT 助手"窗口，展示企业微信 IT 助手二维码。 |
| 登录过期弹窗 | 当登录凭证过期时，系统自动弹出重新登录对话框，可直接在当前页面完成登录。 |

### 操作步骤

#### 账号密码登录

1. 在登录页确认已选中 **账号密码登录** 方式（默认）。
2. 输入 **账号**。
3. 输入 **密码**（密码使用 RSA 加密传输，确保安全）。
4. 如需浏览器记住密码，勾选 **"记住密码"** 复选框。
5. 如系统要求输入验证码，在弹出的验证码输入框中输入正确的验证码。
6. 点击 **"登录"** 按钮。
7. 登录成功后自动跳转至工作台页面。

#### 企业微信扫码登录

1. 点击顶部的 **企业微信图标** 切换到企业微信登录模式。
2. 在下拉框中选择所属 **公司**。
3. 使用企业微信扫描页面上的二维码完成登录。

#### 微信扫码登录

1. 点击顶部的 **微信图标** 切换到微信登录模式。
2. 使用微信扫描页面上的二维码完成登录。

#### 记住密码

1. 在账号密码登录模式下，勾选 **"记住密码"** 复选框。
2. 下次打开登录页时，账号和密码将自动填入（密码经过加密存储）。

#### 联系 IT 解锁

1. 当登录遇到账号锁定等情况时，系统会弹出提示框。
2. 点击 **"联系IT解锁登录"** 按钮。
3. 在弹出的窗口中，使用企业微信扫描二维码联系 IT 助手。
4. 或直接在企业微信中搜索 **"IT助手"** 进行联系。

#### 登录过期重新登录

1. 当系统检测到登录凭证过期时，会自动弹出登录对话框。
2. 输入账号密码完成重新登录。
3. 也可点击 **"返回登录页"** 跳转到完整登录页面。

### 校验规则

| 字段 | 规则 |
|------|------|
| 账号 | 必填 |
| 密码 | 必填 |
| 验证码 | 当系统要求时必填，不能为空 |
| 公司 | 企业微信登录时必选 |

### 状态说明

| 状态/错误码 | 说明 | 处理方式 |
|------------|------|---------|
| 密码错误 | 账号或密码不正确 | 重新输入正确密码 |
| 超过30天未登录 | 30天内未通过PC或小程序登录过 | 使用邮箱验证码登录 |
| 密码过期（3个月） | 密码超过3个月未修改 | 使用邮箱验证码登录，或使用企业微信登录 |
| 验证码错误 | 输入的验证码不正确或已过期 | 重新输入正确验证码 |
| 账号锁定 | 账号被安全策略锁定 | 联系 IT 助手解锁 |

## 待入职员工

### 用途

待入职员工模块用于管理面试人员和人才信息，支持新增、编辑、标记流失、联系面试等操作，并提供生成入职二维码（微信小程序码）功能，方便候选人扫码填写入职登记表。

### 页面路径

- 登录后，在左侧菜单栏点击 **"待入职员工信息"** 进入。

### 主要功能

| 功能区域 | 说明 |
|---------|------|
| 标签切换 | 顶部提供 **"面试人员"** 和 **"人才信息"** 两个标签，点击切换。 |
| 新增按钮 | 点击 **"新增"** 按钮（黄色），弹出新增人员信息对话框。 |
| 生成入职二维码 | 点击 **"生成入职二维码"** 按钮，弹出扫码入职对话框，展示微信小程序码。 |
| 刷新/重置 | 刷新列表数据 / 重置所有筛选条件。 |
| 月份筛选 | 右侧提供月份范围选择器，可按沟通入职日期范围筛选。 |
| 列表筛选 | 表头支持按各列进行筛选（输入框筛选或下拉选择筛选）。 |
| 列表排序 | 支持按"状态"和"沟通入职日期"列进行升降序排序。 |

#### 面试人员列表列

| 列名 | 说明 |
|------|------|
| 岗位角色 | 候选人应聘的岗位 |
| 姓名 | 候选人姓名 |
| 联系方式 | 手机号码 |
| 状态 | 未面试 / 待沟通入职 / 待入职 / 面试未通过 / 已正式入职 |
| 沟通入职日期 | 与候选人沟通确认的入职日期 |
| 面试进度 | 预约面试 / 第一次面试 / 第二次面试 / 面试完成 |
| 信息来源 | 招聘网站 / 校园招聘会 / 招聘会 / 内部推荐 / 人员自荐 |
| 备注 | 备注信息 |

#### 人才信息列表列

| 列名 | 说明 |
|------|------|
| 岗位角色 | 人才应聘的岗位 |
| 姓名 | 人才姓名 |
| 联系方式 | 手机号码 |
| 状态 | 未面试 / 待沟通入职 / 待入职 / 面试未通过 / 已正式入职 |
| 信息来源 | 招聘网站 / 校园招聘会 / 招聘会 / 内部推荐 / 人员自荐 |
| 备注 | 备注信息（含流失原因，如有） |

### 操作步骤

#### 新增面试人员（手动添加）

1. 在 **"面试人员"** 标签下，点击 **"新增"** 按钮。
2. 在弹出的对话框中，确认选中 **"手动添加"** 标签。
3. 填写以下信息：
   - **姓名**（必填）：输入候选人姓名
   - **岗位角色**（必填）：输入应聘岗位
   - **手机**（必填）：输入手机号（自动带 +86 前缀），需为 11 位有效手机号
   - **性别**：选择"男"或"女"
   - **状态**（必填）：选择当前状态（未面试/待沟通入职/待入职）
   - **沟通入职日期**（选填）：选择日期
   - **面试进度**（选填）：选择面试进度
   - **信息来源**（必填）：选择信息来源渠道
   - **备注**（选填）：输入备注信息，最多 50 字
4. 勾选 **"保存后发送入职登记表填写通知"**（默认勾选），系统将在保存后向候选人发送通知。
5. 点击 **"保存"** 完成新增，或点击 **"保存并继续添加"** 连续新增多条。
6. 点击 **"取消"** 关闭对话框。

#### 生成入职二维码（扫码入职）

1. 在 **"面试人员"** 标签下，点击 **"生成入职二维码"** 按钮。
2. 在弹出的对话框中，默认显示 **"扫码入职"** 标签。
3. 系统自动生成微信小程序码，候选人可使用微信扫码填写入职登记表。
4. 如需刷新二维码，点击右上角的刷新图标。
5. 点击 **"下载二维码"** 可将小程序码保存为图片。
6. 也可切换到 **"手动添加"** 标签直接填写信息。

#### 编辑人员信息

1. 在列表中找到目标人员，点击操作列的 **"编辑"** 按钮。
2. 在弹出的对话框中修改信息。
3. 点击 **"保存"** 完成修改。

#### 标记流失（面试人员）

1. 在面试人员列表中，找到状态为"待入职"的人员。
2. 点击操作列的 **"流失"** 按钮。
3. 在弹出的对话框中填写 **流失原因**（必填，最多 50 字）。
4. 点击 **"确定"** 完成流失标记。该人员将转入人才信息列表。

#### 联系面试（人才信息）

1. 在人才信息列表中，找到目标人才。
2. 点击操作列的 **"联系面试"** 按钮。
3. 在弹出的确认框中点击 **"确定"**。
4. 该人才将转入面试人员列表。

### 校验规则

| 字段 | 规则 |
|------|------|
| 姓名 | 必填，只能输入中文和字母 |
| 岗位角色 | 必填，支持中文和横线，最长 20 个字符 |
| 手机号 | 必填，必须为 11 位有效手机号（1 开头） |
| 性别 | 必选，可选"男"或"女" |
| 状态 | 必选，可选：未面试、待沟通入职、待入职 |
| 信息来源 | 必选 |
| 流失原因 | 必填，最多 200 字 |

### 状态说明

| 状态值 | 状态名称 | 说明 |
|--------|---------|------|
| 1 | 未面试 | 候选人尚未安排面试 |
| 2 | 待沟通入职 | 面试通过，待沟通入职事宜 |
| 3 | 待入职 | 已确认入职，等待正式入职 |
| 4 | 面试未通过 | 面试未通过 |
| 5 | 已正式入职 | 已完成入职流程，转为正式员工 |

**状态流转**：
- 新增时可选状态：未面试(1)、待沟通入职(2)、待入职(3)
- 面试人员标记"流失"后，转入人才信息列表
- 人才信息"联系面试"后，转入面试人员列表

## 打印

### 用途

RMP 平台提供文档导出和打印功能，支持将页面内容导出为 **PDF** 文件或 **DOCX（Word）** 文件，并支持浏览器直接打印。

### 页面路径

- 打印功能嵌入在各个业务页面中，通过页面上的 **打印按钮** 或 **导出按钮** 触发。
- 测试页面路径：`/print`（开发调试用，正式环境不对外开放）。

### 主要功能

| 功能 | 说明 |
|------|------|
| PDF 导出 | 使用 jsPDF 库将 HTML 页面内容转换为 A4 格式的 PDF 文件，支持自动分页、页眉页脚。 |
| DOCX 导出 | 使用 docxtemplater 库，基于预设的 DOCX 模板文件，填充数据后导出 Word 文档。 |
| 浏览器打印 | 调用浏览器原生打印功能，支持分页打印（通过 CSS `page-break-before` 控制分页）。 |

### 操作步骤

#### 导出 PDF

1. 在业务页面中找到 **"导出PDF"** 或 **"打印"** 按钮。
2. 点击按钮，系统自动将当前页面内容渲染为 PDF。
3. PDF 文件将在新窗口中打开，可保存或打印。

#### 导出 DOCX（Word）

1. 在业务页面中找到 **"导出Word"** 或类似按钮。
2. 点击按钮，系统基于模板和数据生成 Word 文档。
3. 文档将自动下载到本地。

#### 浏览器打印

1. 在业务页面中找到 **"打印"** 按钮。
2. 点击按钮，打开浏览器打印预览窗口。
3. 选择打印机和打印设置，点击"打印"。

### 校验规则

- 导出前确保页面数据已加载完成。
- DOCX 导出需要预先配置好模板文件。

### 状态说明

- 导出过程中页面可能显示加载状态，请耐心等待。
- 如导出失败，请检查网络连接或联系管理员。

## 外部客户信息登记

### 用途

外部客户信息登记页面是一个对外开放的独立页面，无需登录即可访问。潜在客户可以在此页面填写基本信息并提交，用于客户线索收集。

### 页面路径

- 浏览器直接访问：`/customer`
- 该页面为免登录白名单页面，外部人员可直接访问。

### 主要功能

| 功能区域 | 说明 |
|---------|------|
| 信息表单 | 包含姓名、公司名称、联系方式、备注四个字段。 |
| 退出按钮 | 点击返回欢迎页（`/welcome`）。 |
| 重写按钮 | 清空所有已填写的表单内容。 |
| 提交按钮 | 提交客户信息，成功后跳转至欢迎页。 |

### 操作步骤

1. 打开客户信息登记页面。
2. 填写以下信息：
   - **姓名**（必填）：输入联系人姓名
   - **公司名称**（必填）：输入公司名称
   - **联系方式**（必填）：输入手机号或其他联系方式
   - **备注**（选填）：输入补充说明信息
3. 如需清空重填，点击 **"重写"** 按钮。
4. 确认信息无误后，点击 **"提交"** 按钮。
5. 提交成功后显示"提交成功"提示，自动跳转至欢迎页。
6. 如需退出不提交，点击 **"退出"** 按钮。

### 校验规则

| 字段 | 规则 |
|------|------|
| 姓名 | 必填，不能为空 |
| 公司名称 | 必填，不能为空 |
| 联系方式 | 必填，不能为空 |
| 备注 | 选填 |

### 状态说明

- 提交成功后，客户信息将进入后台 CRM 系统的线索池，由业务人员进行跟进。
- 如提交失败，页面会显示"提交失败"提示，请检查网络后重试。
