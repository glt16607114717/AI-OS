# RMP 工位管理模块知识库

> 版本：v1.0 | 更新日期：2026-06-19 | 所属系统：RMP 机器人管理平台

工位管理系统是 RMP 机器人管理平台的核心模块之一，负责管理机器人部署的物理工位全生命周期，包括工位创建、方案绑定、设备配套、状态流转、工位组管理等功能。

---

### 工位12种状态流转

工位共有 **12 种状态**，按生命周期分为三个阶段：

| 状态码 | 状态名称 | 所属阶段 | 流转规则 |
|--------|----------|----------|----------|
| 1 | 方案未绑定 | 计划排产 | 工位创建后的初始状态，尚未绑定工位方案 |
| 2 | 待排产 | 计划排产 | 方案已绑定，等待排产计划 |
| 3 | 备料 | 计划排产 | 排产完成后进入备料阶段，准备物料和设备 |
| 4 | 内部模拟 | 计划排产 | 备料完成后在内部进行模拟调试 |
| 5 | 现场部署 | 交付 | 内部模拟通过后，进入客户现场部署 |
| 6 | 正常关闭 | 维护 | 部署完成且正常运行后关闭（计划排产阶段） |
| 7 | 异常关闭 | 维护 | 部署过程中出现异常导致关闭（计划排产阶段） |
| 8 | 暂停 | 维护 | 工位暂停运行（计划排产阶段） |
| 9 | 运行收费 | 维护 | 工位正常运行并计费 |
| 10 | 正常关闭 | 维护 | 运行阶段正常关闭 |
| 11 | 异常关闭 | 维护 | 运行阶段异常关闭 |
| 12 | 暂停 | 维护 | 运行阶段暂停 |

**状态流转路径**：方案未绑定(1) → 待排产(2) → 备料(3) → 内部模拟(4) → 现场部署(5) → 运行收费(9)。任意阶段可转暂停(8/12)或关闭(6/7/10/11)。

### 方案版本管理逻辑

方案支持版本管理，通过 `parent_version` 字段追溯版本链：
- 新建方案时 `parent_version=0`，表示初始版本
- 编辑方案时可选择"创建新版本"或"直接修改"
- 创建新版本时，原方案成为历史版本，新方案 `parent_version` 指向原方案ID
- 版本变更类型 `version_change_type` 记录变更原因（如 ECN 变更）
- 方案状态流转：草稿(1) → 待审核(2) → 审核通过(3) / 驳回(-1)

## 模块间数据流

```
客户 → 工位需求 → 工位方案 → 工位模板 → 工位
                    ↑              ↓
              通用工位方案    夹治具订单
                    ↓
              技术方案
```

1. 客户提出需求 → 创建**工位需求**
2. 基于需求设计**工位方案**（可引用**通用工位方案**作为模板）
3. 方案中配置设备清单、夹治具、参数、风险等子模块
4. 方案审核通过后，创建**工位模板**并绑定方案
5. 基于模板创建**工位**实例，进入状态流转
6. 夹治具需求可生成**夹治具订单**走审批流程
7. **技术方案**作为底层技术能力库独立管理
