# 操作手册-基础数据管理（上）

> 面向业务人员的操作指南，覆盖行业、产品、工艺、物料、耗材、供应商、SOP 等基础数据模块。

---

## 行业管理

### 用途
维护企业所服务的行业分类，用于后续产品、客户等模块的行业归属选择。

### 页面路径
`基础数据管理 → 行业管理`

### 主要功能

| 功能 | 说明 |
|------|------|
| 行业列表 | 展示所有已添加的行业类别，支持分页浏览 |
| 添加行业 | 新增一个行业类别 |
| 编辑行业 | 修改已有行业类别名称 |
| 删除行业 | 勾选后批量删除行业类别 |
| 搜索行业 | 按行业名称模糊搜索 |

### 操作步骤

**新增行业：**
1. 进入行业管理页面，点击右上角搜索框旁的"添加行业"按钮
2. 弹出对话框，在"行业类别"输入框中填写行业名称
3. 点击"确定"保存

**编辑行业：**
1. 在列表中找到目标行业，点击操作列的"编辑"按钮
2. 弹出对话框，修改"行业类别"名称
3. 点击"确定"保存

**删除行业：**
1. 勾选需要删除的行业（可多选）
2. 点击左上角红色"删除"按钮
3. 确认后删除

**搜索行业：**
1. 在搜索框中输入行业名称关键词
2. 点击搜索按钮或按回车键

### 校验规则

| 字段 | 规则 |
|------|------|
| 行业类别 | 必填，不能为空 |

### 状态说明
行业管理无状态流转，仅有"存在/已删除"两种状态。

## 行业资讯

### 用途
维护"大行业 → 小行业 → 工艺 → 产品"的四级分类关联关系，是整个基础数据体系的核心分类树。

### 页面路径
- 列表页：`基础数据管理 → 行业资讯`
- 详情/编辑页：`基础数据管理 → 行业资讯详情`

### 主要功能

| 功能 | 说明 |
|------|------|
| 行业信息列表 | 展示大行业、小行业、工艺、产品的层级树形表格 |
| 新增行业信息 | 创建新的大行业，并添加小行业、工艺、产品 |
| 编辑行业信息 | 修改已有的大行业及其子级数据 |
| 展开/收起 | 点击大行业行左侧箭头展开或收起子级明细 |

### 操作步骤

**新增行业信息：**
1. 进入行业资讯列表页，点击右上角"新增"按钮
2. 进入详情页，填写"大行业"名称
3. 系统默认带出一个空的小行业行，填写"小行业"名称
4. 在小行业行内可点击"添加工艺"按钮，填写工艺名称
5. 在小行业行内可点击"添加产品"按钮，填写产品名称
6. 如需添加更多小行业，点击底部"添加小行业"按钮
7. 点击右上角"保存"按钮

**编辑行业信息：**
1. 在列表页找到目标大行业，点击操作列的"编辑"按钮
2. 进入详情页，修改各字段
3. 点击"保存"按钮

**浏览行业信息：**
1. 在列表页，点击大行业行左侧的箭头图标展开子级
2. 展开后可看到该大行业下所有小行业、工艺、产品的关联关系
3. 再次点击箭头收起

### 校验规则

| 字段 | 规则 |
|------|------|
| 大行业 | 新增时如未填写会弹出确认提示，可选择不保存 |
| 小行业 | 新增时如未填写会弹出确认提示，系统自动过滤空行 |

### 状态说明
行业资讯无状态流转，数据保存后即生效。

## 产品管理-基础数据

### 用途
维护产品类别与产品名称的基础字典，同时管理各产品的附件文档（如说明书、图纸等）。

### 页面路径
- 产品类别列表：`基础数据管理 → 产品管理`
- 产品信息维护列表：`基础数据管理 → 产品信息维护`
- 产品信息维护详情：`基础数据管理 → 产品信息维护详情`

### 主要功能

#### 3.1 产品类别管理

| 功能 | 说明 |
|------|------|
| 产品列表 | 展示产品类别、产品名称、创建/更新时间 |
| 添加产品 | 新增产品类别和产品名称 |
| 编辑产品 | 修改已有产品信息 |
| 删除产品 | 勾选后批量删除 |
| 搜索产品 | 按产品名称模糊搜索 |

**操作步骤：**
1. 新增：点击搜索框旁"添加产品"按钮 → 填写"产品类别"和"产品名称" → 确定
2. 编辑：点击操作列"编辑"按钮 → 修改信息 → 确定
3. 删除：勾选目标行 → 点击左上角"删除"按钮

**校验规则：**

| 字段 | 规则 |
|------|------|
| 产品类别 | 必填 |
| 产品名称 | 必填 |

#### 3.2 产品信息维护

| 功能 | 说明 |
|------|------|
| 设备列表 | 展示设备型号、名称、类型及附件上传状态 |
| 筛选 | 按设备类别（级联选择）、设备名称/型号、菜单类型、上传状态筛选 |
| 查看附件 | 点击"附件上传"列查看已上传的 PDF 文件 |
| 编辑产品信息 | 点击操作列"编辑"进入详情页 |

**操作步骤：**
1. 进入产品信息维护页面，列表展示所有设备及其附件上传状态
2. 使用顶部筛选条件缩小范围：
   - 设备类别：级联下拉选择
   - 设备名称/型号：模糊搜索
   - 菜单类型：下拉选择
   - 上传状态：选择"已上传"/"未上传"/"全部"
3. 点击"重置"清空所有筛选条件
4. 点击"附件上传"列查看 PDF 附件（弹窗预览）
5. 点击操作列"编辑"进入详情页

#### 3.3 产品信息维护详情

| 功能 | 说明 |
|------|------|
| 设备基本信息 | 展示设备名称、类别、型号、用途 |
| 菜单标签切换 | 顶部标签栏切换不同文档类型 |
| 上传附件 | 上传 PDF/图片/Office 文件 |
| 下载附件 | 下载已上传的附件 |
| 删除附件 | 删除已上传的附件 |
| 新增/删除菜单 | 新增或删除文档类型标签 |
| 保存备注 | 填写文字备注并保存 |

**操作步骤：**
1. 进入详情页，顶部展示设备基本信息（名称、类别、型号、用途）
2. 点击标签栏切换不同菜单类型，查看对应的附件列表
3. 上传附件：点击"上传附件"按钮 → 选择文件（支持 pdf/png/jpg/jpeg/xls/xlsx/doc/docx/zip/STEP/stp/SLDPRT）→ 确定
4. 下载附件：点击操作列"下载"按钮
5. 删除附件：点击操作列"删除"按钮
6. 新增菜单：点击"新增"按钮 → 填写菜单名称（最多6个字）→ 确定（新增后会给所有产品都新增此菜单）
7. 删除菜单：点击"删除"按钮 → 勾选要删除的菜单 → 确定（已有附件的菜单不可删除）
8. 在文本框中填写备注，点击"保存"

**校验规则：**

| 字段 | 规则 |
|------|------|
| 菜单名称 | 必填，最多6个字 |
| 附件 | 单次上传限制1个文件 |

**状态说明：**

| 状态 | 说明 |
|------|------|
| 未上传 | 该菜单类型下暂无附件 |
| 已上传 | 该菜单类型下已有附件 |

## 工艺管理

### 用途
维护工位（工序）信息，包括产品名称、工位名称、结构/电气/软件需求、流程图等，并支持上传工位程序包。

### 页面路径
`基础数据管理 → 工艺管理`

### 主要功能

| 功能 | 说明 |
|------|------|
| 工位列表 | 展示名称、工位名称、结构需求、电气需求、软件需求、创建/修改时间 |
| 添加工位 | 新增工位信息 |
| 编辑工位 | 修改已有工位信息 |
| 查看工位包 | 查看已上传的程序包信息（文件名、路径、大小、类型等） |
| 上传工位程序包 | 上传 ZIP 格式的工位程序包 |

### 操作步骤

**添加工位：**
1. 点击"添加工位"按钮
2. 在弹出的对话框中：
   - 选择"客户"（必选）
   - 选择"场地"（根据客户动态加载）
   - 上传"流程图"图片（支持 png/jpg/jpeg）
   - 填写"结构需求"（如：机械手工作站一台，快换接头一个...）
   - 填写"电气需求"（如：扫码枪一个，反射光纤一个）
   - 填写"软件需求"（如：截屏软件，镭雕机与机器人通讯软件）
   - 填写"产品名称"（如：新佰人机器人）
   - 填写"工位名称"（如：组装）
   - 选择"工位类型"（级联选择）
3. 点击"确定"保存

**编辑工位：**
1. 点击操作列"编辑"按钮
2. 修改各字段
3. 点击"确定"保存

**上传工位程序包：**
1. 点击操作列"上传工位程序包"按钮
2. 选择 ZIP 格式文件
3. 等待上传完成（显示进度条）

**查看工位包：**
1. 点击操作列"查看工位包"按钮
2. 弹窗显示程序包详细信息

### 校验规则

| 字段 | 规则 |
|------|------|
| 客户 | 必选 |
| 场地 | 必选 |
| 流程图 | 必传，仅支持 png/jpg/jpeg |
| 结构需求 | 必填 |
| 电气需求 | 必填 |
| 软件需求 | 必填 |
| 产品名称 | 必填 |
| 工位名称 | 必填 |
| 工位类型 | 必选 |
| 程序包 | 仅支持 ZIP 格式 |

### 状态说明
工艺管理无状态流转，数据保存后即生效。

## 物料管理-基础数据

### 用途
维护物料（设备/零件）的基础信息，包括产品类别、型号、名称、规格参数、属性、用途、单位、图片和使用说明。

### 页面路径
`基础数据管理 → 物料管理`

### 主要功能

| 功能 | 说明 |
|------|------|
| 物料列表 | 展示序号、图片、产品类别、型号、名称、规格/参数、属性、用途、单位 |
| 新增物料 | 新增物料信息 |
| 编辑物料 | 修改已有物料信息 |
| 删除物料 | 勾选后批量删除 |
| 图片预览 | 点击图片放大查看 |

### 操作步骤

**新增物料：**
1. 点击左上角"新增"按钮
2. 在弹出的对话框中填写：
   - 产品类别：下拉选择（从配置字典加载）
   - 型号：文本输入
   - 名称：文本输入
   - 规格/参数：文本输入
   - 属性：下拉选择（从配置字典加载）
   - 用途：文本输入
   - 单位：下拉选择（从配置字典加载）
   - 图片：点击"+"按钮上传（支持 png/jpg/jpeg，最多9张）
   - 使用说明：点击"+"按钮上传 PDF 文件（最多1个）
3. 点击"确定"保存

**编辑物料：**
1. 点击操作列"编辑"按钮
2. 修改各字段
3. 点击"确定"保存

**删除物料：**
1. 勾选目标行
2. 点击左上角"删除"按钮

**查看图片：**
- 列表中直接展示物料图片缩略图

**查看使用说明：**
- 编辑时可点击"查看 PDF"预览使用说明文件

### 校验规则

| 字段 | 规则 |
|------|------|
| 产品类别 | 必选 |
| 型号 | 必填，最多50字 |
| 名称 | 必填，最多50字 |
| 规格/参数 | 必填，最多255字 |
| 属性 | 必选 |
| 用途 | 必填，最多255字 |
| 单位 | 必选 |
| 图片 | 必传 |
| 使用说明 | 可选，仅支持 PDF |

### 状态说明
物料管理无状态流转，数据保存后即生效。

## 耗材管理

### 用途
维护完整的物料主数据，涵盖基本信息、单位设置、物料特性、物料条码、价格设置、库存预警、生产信息、财务信息、其他信息、图片附件、保养清单等全方位字段。

### 页面路径
- 列表页：`基础数据管理 → 耗材管理`
- 新增/编辑页：`基础数据管理 → 新增耗材 / 编辑耗材`

### 主要功能

#### 6.1 耗材列表

| 功能 | 说明 |
|------|------|
| 物料列表 | 展示物料编码、名称及自定义可见列 |
| 左侧分类树 | 按物品类别树筛选物料 |
| 搜索 | 按物料名称/编码/规格型号搜索；支持全文检索 |
| 新增 | 跳转新增页面 |
| 导入 | 通过 Excel 批量导入物料 |
| 导出 | 导出物料列表 |
| 启用/禁用 | 批量启用或禁用物料 |
| 复制 | 复制已有物料（仅支持单选） |
| 批量修改 | 批量修改选中物料的字段 |
| 筛选可见 | 自定义列表显示的列（小齿轮设置） |
| 类别管理 | 编辑/新增/删除物品类别树节点 |

**操作步骤：**

**新增耗材：**
1. 点击"新增"按钮，跳转到新增页面
2. 依次填写各信息区块（详见6.2节）
3. 点击右上角"保存"按钮

**搜索物料：**
1. 在搜索框输入物料名称/编码/规格型号，点击搜索
2. 或在全文检索框输入关键词，按回车搜索

**导入物料：**
1. 点击"导入"按钮
2. 选择 Excel 文件（.xlsx/.xls）
3. 系统自动导入并刷新列表

**导出物料：**
1. 点击下载图标按钮
2. 系统生成导出文件

**启用/禁用：**
1. 勾选目标物料
2. 点击"启用"或"禁用"按钮

**复制物料：**
1. 勾选一个物料（不支持多选）
2. 点击"复制"按钮，跳转到新增页面并预填数据

**批量修改：**
1. 勾选目标物料
2. 点击"批量修改"按钮
3. 在弹出的对话框中修改字段
4. 确定保存

**管理物品类别：**
1. 点击左侧分类树上方的"编辑"按钮进入编辑模式
2. 点击节点旁的"+"图标新增子类别
3. 点击节点旁的编辑图标修改类别
4. 点击节点旁的删除图标删除类别（仅末级节点可删除）
5. 再次点击"完成编辑"退出编辑模式

**筛选可见列：**
1. 点击右侧小齿轮图标
2. 勾选需要显示的列
3. 点击确定

#### 6.2 新增/编辑耗材详情

新增/编辑页面包含以下信息区块，顶部有导航标签可快速跳转：

| 区块 | 包含字段 |
|------|----------|
| 基本信息 | 编码、名称、物料类别、物料类型、条形码、规格型号、计量单位、是否启用多单位、品牌、产地、助记码、物料来源、物料标签、是否损耗品、保质期、用途、概述、关键字、材质、表面处理 |
| 单位设置 | 采购单位、销售单位、库存单位、报表辅助单位、单位换算设置 |
| 物料特性 | 是否可自制、是否可受托、是否可采购、是否可销售、是否启用序列号管理、是否可为子件、是否可为组件、可保养 |
| 物料条码 | 条码规则配置 |
| 价格设置 | 采购价、最高采购价、成本价、配送价、批发价、零售价、最低销售价、销售价1/2/3 |
| 库存预警 | 最低库存量、安全库存量、最高库存量 |
| 生产信息 | 固定提前期、最小订货量、默认生产车间、计划员、生产信息1/2/3、倒冲仓库、倒冲仓位 |
| 财务信息 | 成本计算方法、物料开票名称、税率、是否免税、是否固定资产、资产分类、折旧方式、折旧值 |
| 其他信息 | 默认仓库、默认仓位、默认供应商、采购员、注册证号、生产许可证、备货天数、交易周期、重量单位、毛重、净重、长/宽/高、体积、体积单位 |
| 图片附件 | 封面图片、详情图片、附件上传 |
| 保养清单 | 当启用保养时，配置保养所需物料清单 |

**操作步骤：**
1. 进入新增/编辑页面
2. 点击顶部导航标签或滚动页面到对应区块
3. 填写各字段（带红色星号的为必填项）
4. 点击右上角"保存"按钮

**校验规则（关键字段）：**

| 字段 | 规则 |
|------|------|
| 基本信息各必填项 | 需通过表单校验 |
| 封面 | 物料类别为设备时必须上传 |
| 替代物料 | 启用替代时必须选择 |
| 计量单位 | 必须选择 |
| 保养清单 | 启用保养时每行必须选择编号 |
| 金蝶编码 | 标准-标准分类（一级NND，二级NND-BZ）时必填 |

**状态说明：**

| 状态 | 说明 |
|------|------|
| 启用 | 物料正常可用 |
| 禁用 | 物料被禁用，不可使用 |

## 供应商列表

### 用途
维护供应商主数据，包括基本信息、财务信息、联系人信息，支持审批流程。

### 页面路径
- 列表页：`基础数据管理 → 供应商列表`
- 详情/新增页：`基础数据管理 → 供应商详情`

### 主要功能

#### 7.1 供应商列表

| 功能 | 说明 |
|------|------|
| 供应商列表 | 展示供应商编码、名称、分类、结算方式、地址、状态、供应商状态、创建/变更时间 |
| 新增 | 跳转新增供应商页面 |
| 筛选 | 按时间范围、供应商编码、供应商状态、状态筛选 |
| 排序 | 按创建时间或变更时间排序 |

**操作步骤：**
1. 进入供应商列表页
2. 使用顶部筛选条件：时间范围、供应商编码（模糊搜索）、供应商状态（可用/禁用）、状态（草稿/待审批/审核通过/反审核）
3. 点击供应商编码可进入详情页
4. 点击"新增"按钮跳转新增页面

#### 7.2 供应商详情/新增

| 功能 | 说明 |
|------|------|
| 基本信息 | 供应商编号（自动生成）、创建时间、创建人、供应商名称、供应商分类、结算方式、供应商状态、供应商地址 |
| 财务信息 | 增值税税率、开票名称、开票税号、发票类型、银行账号、开户银行、开户地址 |
| 附件 | 上传相关附件（支持 pdf/png/jpg/jpeg/xls/xlsx） |
| 联系人信息 | 新增/编辑联系人（姓名、职位、手机、座机、首要联系人） |
| 审批流程 | 提交审批、反审核 |

**操作步骤：**

**新增供应商：**
1. 点击"新增"按钮进入详情页
2. 系统自动生成供应商编号
3. 填写基本信息：
   - 供应商名称（必填）
   - 供应商分类（必选，下拉选择）
   - 结算方式（必选，下拉选择）
   - 供应商状态（单选：可用/禁用，默认可用）
   - 供应商地址（必填）
4. 填写财务信息（选填）：
   - 增值税税率、开票名称、开票税号
   - 发票类型（下拉选择）
   - 银行账号（必填，仅限数字）、开户银行、开户地址
5. 上传附件：点击"上传"按钮选择文件
6. 新增联系人：点击"新增"按钮 → 填写联系人姓名、职位、手机（11位数字）、座机 → 设置首要联系人（开关）
7. 点击"保存"按钮

**编辑供应商：**
- 草稿或反审核状态下可直接编辑
- 待审批或审核通过状态下表单为只读

**提交审批：**
1. 保存成功后，点击审批流程按钮提交审批

**反审核：**
1. 审核通过后，可点击反审核按钮退回

### 校验规则

| 字段 | 规则 |
|------|------|
| 供应商名称 | 必填，最多30字 |
| 供应商分类 | 必选 |
| 结算方式 | 必选 |
| 供应商地址 | 必填，最多100字 |
| 银行账号 | 必填，仅限数字，最多50位 |
| 联系人姓名 | 必填 |
| 联系人职位 | 必填 |
| 联系人手机 | 必须为11位数字 |
| 首要联系人 | 必须设置至少一个 |

### 状态说明

| 状态码 | 状态名称 | 说明 |
|--------|----------|------|
| 1 | 草稿 | 新建未提交审批，可编辑 |
| 2 | 待审批 | 已提交审批流程，不可编辑 |
| 3 | 审核通过 | 审批通过，不可编辑 |
| 4 | 反审核 | 从审核通过退回，可编辑 |

**供应商状态（合作状态）：**

| 状态码 | 说明 |
|--------|------|
| 1 | 可用 |
| 2 | 禁用 |

## SOP管理

### 用途
维护工位类型（SOP类型）的分类层级树，用于工艺管理中的工位类型选择。

### 页面路径
- SOP类型管理：`基础数据管理 → SOP管理`
- SOP工艺管理：`基础数据管理 → 工艺管理`（详见第四章）

### 主要功能

#### 8.1 SOP类型管理

| 功能 | 说明 |
|------|------|
| 类型列表 | 展示类型名称、上级类型名称、更新时间 |
| 添加工位类型 | 新增工位类型节点 |
| 编辑工位类型 | 修改已有类型名称 |
| 删除工位类型 | 删除类型节点 |

**操作步骤：**

**添加工位类型：**
1. 点击"添加工位类型"按钮
2. 在弹出的对话框中：
   - 选择"工位层级"（级联选择，选择上级节点）
   - 填写"工位类型名称"
3. 点击"确定"保存

**编辑工位类型：**
1. 点击操作列"编辑"按钮
2. 修改"工位类型名称"（层级不可修改）
3. 点击"确定"保存

**删除工位类型：**
1. 点击操作列"删除"按钮
2. 确认删除

#### 8.2 SOP工艺管理

SOP工艺管理即"工艺管理"模块（详见第四章），在添加工位时需要选择工位类型，工位类型的数据来源即为SOP类型管理维护的分类树。

### 校验规则

| 字段 | 规则 |
|------|------|
| 工位层级 | 必选 |
| 工位类型名称 | 必填 |

### 状态说明
SOP类型管理无状态流转，数据保存后即生效。
