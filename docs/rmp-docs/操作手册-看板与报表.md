# RMP 平台操作手册 — 看板与报表

> 适用对象：业务人员、运维人员、管理层  
> 本文档介绍 RMP 平台中所有看板与报表模块的功能、页面入口和操作方法。

---

## 一、工作台/仪表盘

### 【用途】
- **仪表盘（个人BI中心）**：展示您个人关注的图表和数据看板，是一个可自定义的 BI 视图中心。
- **工作台**：根据您的角色（业务员/运维人员）展示个人待办、名下机器人和客户/场地信息。

### 【页面路径】
- 仪表盘：登录后默认首页，或点击左侧菜单 **仪表盘**
- 工作台：点击左侧菜单 **工作台**

### 【主要功能】

#### 仪表盘（个人BI中心）
- 页面加载外部 BI 图表引擎，展示您已配置的个人图表集合
- 支持**全屏模式**：点击全屏按钮可放大查看
- 首次登录时，如果系统有未读的版本更新消息，会自动弹出提示
- 如果系统提示需要修改密码，会引导您到个人资料页

#### 工作台
- **我的待办**：显示待处理的客户管理事项数量，点击可跳转到对应页面
- **个人信息区**：显示您的昵称、部门、公司、简称、固话、地址
- **现有机器人**：展示您名下的机器人列表（编号、工位、型号、状态、地址、备注）
- **现有客户**（业务员）/ **现有场地**（运维人员）：展示关联的客户或场地信息
- 支持分页浏览

### 【如何查看】
- 仪表盘：登录后自动进入，数据由系统根据您的权限自动加载
- 工作台：点击菜单进入，自动加载您名下的机器人和客户/场地数据

### 【筛选条件】
- 工作台无需手动筛选，系统根据当前登录用户自动匹配数据

### 【导出方式】
- 工作台暂不支持导出

## 二、业务面板

### 【用途】
为业务人员提供个人工作概览，查看名下机器人状态和客户信息。

### 【页面路径】
- 点击左侧菜单 **业务面板**

### 【主要功能】
- 显示业务员的个人信息（昵称、部门、公司等）
- **现有机器人**标签页：列出名下所有机器人，含编号、工位、型号、状态、省市区地址、备注
- **现有客户**标签页：列出名下所有客户，含客户名称、手机号、固话、所属业务、地址、备注
- 支持分页浏览

### 【如何查看】
进入页面后自动加载数据，切换标签页查看机器人或客户。

### 【筛选条件】
- 无需手动筛选，系统根据当前登录用户自动匹配

### 【导出方式】
- 暂不支持导出

## 四、图表管理（看板配置/图表设计）

### 【用途】
管理系统中的图表和看板配置。管理员可以在此创建、编辑、停用图表，并配置图表在哪些场景下展示。

### 【页面路径】
- 点击左侧菜单 **图表管理**

### 【主要功能】

页面顶部有四个标签页：

#### 个人BI中心
- 以卡片网格形式展示所有已配置的"个人BI中心"图表
- 每个卡片显示图表的**预览图**、**图表名称**和**数据类别**
- 点击卡片可编辑图表配置
- 已停用的图表会显示"已停用"遮罩
- 点击预览图可放大查看

#### 工作台
- 展示配置在"工作台"场景下的图表
- 操作方式同"个人BI中心"

#### 客户看板
- 展示配置在"客户看板"场景下的图表
- 操作方式同"个人BI中心"

#### 小看板数据
- 以表格形式展示小看板数据列表
- 列表字段：序号、名称、类别、标识、备注
- 点击行可编辑，点击"新增"按钮可添加

### 【筛选条件】
- **数据类别**：下拉选择图表的数据类别进行筛选
- **图表名称**：输入关键词模糊搜索
- 点击**重置**按钮清空筛选条件

### 【新增/编辑图表】
点击"新增"或点击已有图表卡片，弹出编辑窗口，可配置：
- **图表名称**：必填
- **数据类别**：下拉选择
- **前端组件标识**：遵循命名规范，如 `customer_pie_stateStatistics_now`
- **应用场景**：多选，可选个人BI中心/工作台/客户看板
- **预览图**：上传图表的预览图片
- **状态**：启用或停用
- **备注**：可选

### 【导出方式】
- 暂不支持导出

## 五、客户日统计

### 【用途】
按天查看单个客户的运营日报，了解该客户当天的工时、稼动率、机器人状态等核心指标。

### 【页面路径】
- 点击左侧菜单 **客户日统计**

### 【主要功能】

#### 顶部指标区（环形进度图）
- **今日工时(H)**：当天总工时，显示环比昨日变化（绿色下降、黄色上升）
- **今日平均工时(H)**：每台机器人的平均工时
- **今日已部署机器人数**：当天在线的机器人数量
- **今日正常工作(H)**：机器人正常生产时长
- **今日稼动率**：机器人实际工作时间占比
- **今日正常待料(H)**：因正常原因等待物料的时间
- **今日异常待料(H)**：因异常原因等待物料的时间

#### 机器人状态饼图
以饼图展示当天所有机器人的状态分布：
- 正在生产、调机试产、正常停机、断网离线、生产完成、等待物料、安全故障、生产故障

#### 排名区（TOP10）
- **工时排名TOP10**：按实际生产工时排序的工位
- **稼动率排名TOP10**：按稼动率排序的工位
- **异常待料排名TOP10**：按异常待料时间排序的工位

### 【如何查看】
1. 选择**数据日期**（日期选择器）
2. 选择**客户简称**（支持模糊搜索，下拉滚动加载更多）
3. 页面自动加载该客户当天的日报数据
4. 系统每 **5 分钟**自动刷新数据
5. 点击右上角全屏按钮可进入全屏模式查看

### 【筛选条件】
- **数据日期**：必选，选择要查看的日期
- **客户简称**：必选，输入关键词搜索客户

### 【导出方式】
- 暂不支持导出

## 六、数据报表

### 【用途】
按公司、部门、员工、月份统计销售业务数据，包括客户拜访、新客户开发、协议签订、合同签订、工位订单等。

### 【页面路径】
- 点击左侧菜单 **数据报表**

### 【主要功能】
以表格形式展示销售统计数据，包含以下指标：

| 指标 | 说明 |
|------|------|
| 客户拜访数量 | 本月新增 / 本年累计 |
| 新客户拜访数量 | 本月新增 / 本年累计 |
| 新增意向协议数量 | 本月新增 / 本年累计 |
| 新增正式合同数量 | 本月新增 / 本年累计 |
| 新增订单工位数量 | 本月新增 / 本年累计 |

- 表格底部自动显示**合计行**
- 点击数字可跳转到**数据报表详情页**，查看明细

### 【如何查看】
1. 选择**公司**（下拉选择）
2. 选择**部门**（可选，联动员工列表）
3. 选择**员工**（可选）
4. 选择**月份**（月份选择器）
5. 表格自动加载数据

### 【筛选条件】
- **公司**：下拉选择
- **部门**：下拉选择（选择公司后联动）
- **员工**：下拉选择（选择部门后联动）
- **月份**：月份选择器

### 【导出方式】
- 点击**导出**按钮（需要导出权限），将当前报表导出为 Excel 文件

## 七、数据报表详情

### 【用途】
从数据报表点击数字后进入，查看某个指标的明细数据。

### 【页面路径】

点击客户名称可跳转到客户详情页。

### 【如何查看】
从数据报表页面点击数字进入，无需额外操作。

### 【筛选条件】
- 由上级页面传入，无需手动筛选

### 【导出方式】
- 点击**导出**按钮（需要导出权限），导出当前明细表

## 八、交付看板

### 【用途】
实时监控交付环节中模拟卡位的状态，了解各卡位的交付进度和工单情况。

### 【页面路径】
- 点击左侧菜单 **交付看板**

### 【主要功能】

#### 交付-模拟工位状态图
以卡片网格形式展示每个模拟卡位的状态，每页显示 12 个卡位（含过道分隔）：

每个卡片显示：
- **卡位名称**和**状态标签**
- **上月交付**：上个月该卡位完成的交付套数
- **平均周转率**：该卡位的平均周转效率
- **本月已交付工单**：当月已完成的交付工单数（大号数字突出显示）
- **模拟中工单**：当前正在模拟的工单名称 + 计划完成时间 + 进度条
- **现场部署中**：当前正在部署的工单名称 + 计划完成时间 + 进度条
- **预排工单**：已排期等待执行的工单名称 + 计划完成时间

### 【如何查看】
1. 顶部下拉选择看板类型（当前为"交付-模拟工位状态图"）
2. 卡片网格自动展示数据
3. 底部**分页器**切换页面查看更多卡位

### 【筛选条件】
- 无额外筛选条件

### 【导出方式】
- 暂不支持导出

## 九、数据报表（交付/运维/角色任务/工位数据）

### 【用途】
这是数据报表模块下的四个子看板，分别从不同维度统计业务数据。

### 【页面路径】
- 点击左侧菜单 **数据报表** → 顶部下拉切换子看板

### 【主要功能】

#### 交付/运维-统计报表
以交叉表格展示交付和运维的核心指标，按月份展开：

| 指标类别 | 包含指标 |
|----------|----------|
| 计划与交付 | 计划交付目标数、月累计排单数、实际排单数、计划差异数、实际交付数、计划交付达成率 |
| 出货与退库 | 月出货量、运维退库数、运维退库率 |
| 增长指标 | 新增交付数、新增交付增长率、市场保有工位数、保有量增长率 |
| 需求管理 | 需求发布数、需求承接数、需求承接率 |
| 方案与合同 | 方案异常结案数、方案异常结案率、新签合同客户数、新签工位数 |
| 工单与模拟 | 新增工单数、模拟完成数、工位总周转率 |
| 退库明细 | 模拟异常退库数、部署异常退库数、运维异常退库数、运维异常退库率、运维正常退库数、运维正常退库率、运维总退库率 |

操作功能：
- 选择**时间范围**（月份区间选择器）
- 选择**公司**筛选
- 点击**本年**快速切换到本年度
- 点击**设置目标**设定计划交付目标数
- 勾选行数据后点击**生成趋势图**，最多选4条生成折线图对比
- 点击**清空趋势图**清除图表
- 点击数字可跳转到对应的工位/工单/客户列表
- 点击**导出**下载 Excel

#### 角色任务-统计报表
按**方案师**或**销售代表**维度统计需求到交付的全流程数据：

**顶部汇总区**：
- 总需求发布数、总承接数、承接率
- 总工单数、已验收数、需求交付验收率

**主体表格**（按角色/客户分组，支持展开/收起）：
- 总计发布需求、总计被承接数、需求被承接率
- 总计生成工单、承接后工单生成率
- 总计已验收数、承接后工单验收率
- 总计交付数

**分阶段明细**（7个阶段）：
1. **需求阶段**：已发布需求、需求未承接
2. **初步方案阶段**：进行中、暂停中、异常结案
3. **合同阶段**：合同洽谈中、合同暂停中、合同异常结案、位置单确认中、位置单暂停中、位置单异常结案
4. **正式方案阶段**：等待分配、进行中、暂停中、异常结案
5. **交付模拟阶段**：等待排单、物料采购中、物料采购暂停中、模拟中、模拟暂停中、异常结案、等待出货、设备出货中
6. **交付部署阶段**：等待部署、现场部署中、暂停中、异常退库结案
7. **持续运维阶段**：非稳定运行中、稳定运行中、正常暂停中、异常暂停中、异常退库结案、正常退库结案

操作功能：
- 选择**时间范围**（日期区间）
- 选择**公司**
- 选择**角色**（方案师/销售代表）
- 选择**账号状态**（全部/正常/停用）
- 点击**本年**快速切换
- 点击**重置**恢复默认
- 支持**列排序**
- 点击数字跳转到对应列表
- 点击**导出**下载 Excel

#### 工位数据报表
以可自定义列的表格展示所有工位的详细数据：

**可筛选字段**（支持自定义显示/隐藏）：
- 客户编号、客户简称、级别、行业、工艺类型、产品
- 工位别名、工位编号、工位名称、位置
- 销售代表、PM、工程师、交付技术经理/主管/组长/专员
- 部署工程师、电气工程师、视觉工程师
- 交付经理/主管/组长/工程师
- 运维经理/主管/组长/工程师
- 工位状态、班次、最低收费方式
- 需求发货日期、预计排期、计划发货日期、计划收款日期
- 实际发货时间、正常退库时间、异常退库时间、实际收款时间
- 模拟时长、部署时长、总交付时长、延期时长、延期次数
- 运行天数、运行月数
- 退库时间、退库原因、退库次数

操作功能：
- 点击**设置**按钮自定义显示列
- 选择**公司**（级联选择器，支持选"全部"）
- 点击**导出**下载 Excel
- 点击**刷新**重新加载
- 点击**重置**恢复默认筛选
- 支持**列排序**

## 十二、机器人运营日志统计

### 【用途】
监控机器人的故障情况和运行状态，帮助运维人员及时发现和处理问题。

### 【页面路径】
- 点击左侧菜单 **机器人运营日志统计**

### 【主要功能】

页面分为四个区域：

#### 故障数量
- 以**柱状图**展示各故障代码的发生次数
- 支持按时间范围、客户、机器人筛选
- 图表支持缩放和拖拽

#### 故障趋势
- 以**折线图**展示选定月份内每天的故障数量变化趋势
- 支持按月份、故障代码（多选）、客户、机器人筛选
- 鼠标悬停可查看每天的故障代码明细

#### 24H全时段统计上报信息
- 以**时间轴色块图**展示选定机器人在一天内的上报状态
- 绿色 = 有上报，黄色 = 无上报
- 支持按日期和机器人筛选
- 底部有图例说明
- 每 **30 分钟**自动刷新

#### 24H全时段统计异常信息
- 以**柱状图**展示选定机器人在一天内的异常发生时间点
- 红色柱状标记异常时刻
- 与上报信息共用日期和机器人筛选条件

### 【如何查看】
1. **故障数量**：选择时间范围 → 选择客户 → 选择机器人 → 图表自动更新
2. **故障趋势**：选择月份 → 选择故障代码 → 选择客户 → 选择机器人 → 图表自动更新
3. **24H统计**：选择日期 → 选择机器人 → 图表自动更新

### 【筛选条件】
- **故障数量**：时间范围（日期区间）、客户（模糊搜索）、机器人（模糊搜索）
- **故障趋势**：月份、故障代码（多选）、客户、机器人
- **24H统计**：日期（不能选未来日期）、机器人

### 【导出方式】
- 暂不支持导出

## 常见问题

### Q1：仪表盘页面加载不出来或显示空白？
- 检查网络连接是否正常
- 尝试刷新页面
- 如果持续加载中，可能是外部 BI 服务异常，请联系管理员

### Q2：客户日统计选择客户后没有数据？
- 确认选择的日期是否有运营数据（当天是否有机器人运行）
- 确认该客户名下是否有已部署的机器人
- 尝试切换日期查看

### Q3：数据报表导出的 Excel 在哪里下载？
- 点击导出后，系统会生成导出任务
- 在页面右下角或通知中心查看下载进度
- 导出完成后自动下载

### Q4：角色任务报表数据量很大，加载慢怎么办？
- 尽量缩小时间范围
- 选择具体的公司而非全部
- 系统已做分页处理，耐心等待即可

### Q5：工位数据报表中想看的列没有显示？
- 点击表格上方的**设置**按钮
- 在自定义列弹窗中勾选需要显示的字段
- 保存后表格会按新配置显示

### Q6：交付看板中卡位显示为空？
- 确认是否有正在进行的交付工单
- 使用底部分页器切换到其他页面查看

### Q7：机器人运营日志统计中24H图表没有数据？
- 确认已选择机器人
- 确认选择的日期不是未来日期
- 确认该机器人在选定日期有上报数据

### Q8：投资方看板数据不更新？
- 投资方看板数据为定期刷新，非实时数据
- 可尝试刷新页面获取最新数据

### Q9：N3D 数字孪生页面打不开？
- N3D 是独立部署的系统，确认 N3D 服务是否正常运行
- 检查是否有访问 N3D 系统的权限
- 联系管理员确认 N3D 服务地址配置是否正确

### Q10：如何给工作台添加更多图表？
- 进入**图表管理** → 选择对应场景标签页（个人BI中心/工作台/客户看板）
- 点击**新增**创建图表，配置应用场景
- 保存后对应场景下即可看到新图表
