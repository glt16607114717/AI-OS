## 一、机器人列表/详情（robotInfo）

### 【用途】

用于查看所有机器人的实时状态、硬件信息和 SIM 卡信息；对机器人进行部署、取消部署、远程强制停机/解除停机、查看生产数据记录、查看定位记录、设置定位频率、发送密钥等操作。

这是机器人日常运维最核心的页面。

### 【页面路径】

- 主菜单 → 机器人管理 → 机器人列表
- 也可从「客户管理 → 客户详情」或「订单管理 → 订单详情」点击「机器人列表」跳转进入（此时仅展示该客户/订单关联的机器人）。

### 【主要功能】

页面顶部有 3 个页签：

| 页签 | 说明 |
|------|------|
| 机器人状态 | 查看机器人实时运行状态，每 10 秒自动刷新一次 |
| 硬件信息 | 查看机器人硬件详情，支持自定义筛选和排序 |
| SIM 卡信息 | 查看 SIM 卡流量、套餐、到期日、预警等 |

页签下方为筛选区和操作按钮，主体为数据表格。

#### 1) 机器人状态页签

**筛选条件**

- 搜索框：下拉选择「机器人编号 / 所在地 / 当前部署客户」，输入关键字后点击搜索。
- 公司：级联选择器，可选择某一家公司或其下「全部」子公司。
- 状态：下拉选择机器人状态（全部 / 正常停机 / 断网离线 / 等待物料 / 正在生产 / 生产故障 / 安全故障 / 调机试产 / 生产完成 / 上电初始状态 / 初始化状态 / 待机状态 / 自动状态 / 暂停状态 / 调试状态 / 手动状态 / 模拟状态 / 强制停止状态）。

**操作按钮**

- 添加机器人（黄色按钮）：打开新增机器人弹窗。
- 刷新（黄色按钮）：手动刷新当前列表（页签本身也会每 10 秒自动刷新）。

**表格列**

| 列名 | 说明 |
|------|------|
| 机器人编号 | 机器人唯一编号 |
| 当前部署客户 | 当前部署到的客户名称 |
| 运维人员 | 负责该机器人的运维人员 |
| 状态 | 机器人当前运行状态（带颜色标识） |
| 所在地 | 当前部署场地地址（省市区+详细地址） |

**行操作按钮**（根据权限和机器人状态显示）

| 按钮 | 触发条件 | 说明 |
|------|----------|------|
| 强制停机 | 当 `remote_control_status` 为 0（未停机）时显示 | 弹出确认框，确认后下发强制停机信号 |
| 解除停机 | 当 `remote_control_status` 为 1（已停机）时显示 | 弹出确认框，确认后解除强制停机状态 |
| 数据记录 | 始终显示 | 打开该机器人的生产数据记录弹窗 |
| 发送密钥 | 始终显示 | 向该机器人下发密钥 |
| 定位记录 | 始终显示 | 打开该机器人的 GPS 定位历史记录 |
| 定位频率 | 始终显示 | 设置该机器人的 GPS 定位上报频率 |

#### 2) 硬件信息页签

**筛选条件**

- 硬件搜索组：支持按机器人编号、机器臂 SN、控制箱 SN、MAC、SIM、GPS-IMEI、路由器 SN、供应商等多个硬件字段自定义筛选。
- 刷新按钮：手动刷新。
- 导入/导出按钮：支持批量导入硬件信息或导出当前列表。

**表格列**

机器人编号、机械臂 SN、工业路由器 SN、物联网卡、物联网卡套餐到期日（可排序）、RUSTDESK 远程码、GPS IMEI:SN、codesys 授权码、物联网（银尔达）SIM、物联网卡/云兔 ICCD、物联网卡 IMEDI、控制箱 SN、MAC 地址、供应商名称、备注。

**行操作按钮**

- 编辑：打开硬件编辑弹窗。
- 查看：以只读方式查看硬件详情。

#### 3) SIM 卡信息页签

**筛选条件**

- 公司：级联选择器筛选 SIM 卡所属公司。
- 刷新按钮：手动刷新。
- 导出按钮：导出当前选中或全部 SIM 卡信息。

**表格列**

机器人编号、工业路由器 SN、卡号（物联网卡）、GPS IMEI:SN、卡状态、运营商、总流量(MB)（可排序）、已用流量(MB)、剩余流量(MB)（可排序）、主套餐、套餐失效时间（可排序）、主套餐剩余服务周、预警、备注。

> 该页签支持多选行后批量导出。

---

### 【操作步骤】

#### 操作 1：添加机器人

1. 在「机器人状态」页签下，点击右上角「添加机器人」按钮。
2. 弹窗中填写：
   - **机器人型号**（必填）：从下拉列表选择。
3. 点击「确定」提交。
4. 提交成功后，列表自动刷新，新机器人出现在列表中。

#### 操作 2：部署机器人到客户工位

1. 在机器人列表中找到待部署的机器人。
2. 点击行操作中的「部署」按钮（如有该权限）。
3. 弹窗中依次选择：
   - **客户**（必填）：从下拉列表选择。
   - **客户场地**（必填）：选择客户后，场地下拉会联动刷新。
   - **客户工位**（必填）：选择场地后，工位下拉会联动刷新。
4. 点击「确定」提交，机器人即绑定到该工位。

#### 操作 3：强制停机 / 解除停机

1. 找到目标机器人。
2. 点击「强制停机」或「解除停机」按钮。
3. 弹出确认提示，点击「确定」后，停机指令下发到机器人。
4. 机器人列表自动刷新，状态列会显示「强制停止状态」。

#### 操作 4：查看机器人数据记录

1. 点击机器人行的「数据记录」按钮。
2. 弹窗顶部显示「本月稼动率」。
3. 可选择时间范围（默认最近 30 天）、数据类型（正式 / 测试）。
4. 表格展示：类型、机器人编号、数据采集时间段、工件/产品、实际生产时间、运行待料时间、单位时间内产能、时间嫁动率、数据上传时间。
5. 表格底部有总计行，汇总所有页的实际生产时间、运行待料时间、产能。

#### 操作 5：查看定位记录

1. 点击机器人行的「定位记录」按钮。
2. 弹窗顶部显示「当前电量」百分比。
3. 可通过 GPS-IMEI 下拉筛选特定设备。
4. 表格展示：机器人编号、GPS-IMEI、地址、定位时间。

#### 操作 6：设置定位频率

1. 点击机器人行的「定位频率」按钮。
2. 弹窗显示：
   - 机器人编号（只读）
   - GPS-IMEI（只读）
   - 起止时间（只读，默认全天）
   - 是否启用：选择「是」
   - **定位间隔**（必填）：数字输入框，范围 **5~120 分钟**，单位为分钟。
3. 点击「确定」下发指令。

### 【校验规则】

| 场景 | 校验规则 |
|------|----------|
| 添加机器人 | 机器人型号必填；数量必须大于 0 的整数；物料 ID 必填；用户必须有关联公司 |
| 部署机器人 | 机器人 ID、场地 ID、工位 ID 均为必填且必须为大于 0 的整数 |
| 取消部署 | 机器人 ID 必填且为大于 0 的整数 |
| 编辑机器人 | 机器人 ID 必填；工位名称（jobs）必填 |
| 强制停机 | 机器人 ID 必填；状态值必须为 1（停机）或 2（解除停机） |
| 定位频率 | 定位间隔必须是 5~120 之间的整数 |

### 【状态说明】

机器人状态码对照表见[附录](#机器人状态码对照表)。

- 远程控制状态 `remote_control_status`：0 = 未停机（可下发停机），1 = 已停机（可解除停机）。
- 机器人状态页签每 10 秒自动刷新一次，便于实时监控。
- 心跳数据由机器人上位机定时上报，系统据此更新机器人状态。

## 二、机器人管理视图（robotInfoForManage）

### 【用途】

以统计概览的形式，按「客户 / 行业 / 工艺 / 未部署」四种维度查看机器人的分布情况和运行状态，支持展开查看每个维度下的机器人明细，并可查看单台机器人的生产数据记录。

### 【页面路径】

主菜单 → 机器人管理 → 机器人管理视图

### 【主要功能】

#### 顶部统计看板

展示 5 个统计指标卡片：

| 指标 | 说明 |
|------|------|
| 机器人总数 | 当前公司下的机器人总数 |
| 已部署机器人 | 已部署到客户工位的机器人数量 |
| 当月活跃机器人数量 | 当月有生产数据的机器人数量 |
| 当月总运行工时 | 当月所有机器人运行工时合计 |
| 月时间稼动率 | 当月时间稼动率（百分比） |

#### 四种视图切换

页面左上角有 4 个切换按钮：

| 视图 | 说明 |
|------|------|
| 按客户 | 以客户为分组，展示每个客户下的机器人数、场地数、工位数、行业数、工艺数 |
| 按行业 | 以行业为分组，展示每个行业下的机器人数、客户数、场地数、工位数、工艺数 |
| 按工艺 | 以工艺类型为分组，展示每个工艺下的机器人数、客户数、场地数、工位数、行业数 |
| 未部署 | 直接列出所有未部署的机器人，显示机器人编号和状态 |

#### 筛选条件（右侧）

- 公司：选择公司（按客户/行业/工艺视图时可用）。
- 机器人编号：远程搜索下拉。
- 行业 / 工艺 / 客户名称：远程搜索下拉（根据当前视图动态显示）。
- 状态：下拉选择机器人状态。
- 重置按钮：清空所有筛选条件。

#### 表格（按客户/行业/工艺视图）

- 支持展开行，展开后显示该分组下的机器人明细（嵌套表格）。
- 嵌套表格行操作：「数据记录」按钮，可查看该机器人的生产数据。
- 点击客户/行业/工艺名称可打开对应的编辑/查看弹窗。

#### 表格（未部署视图）

- 直接以平铺列表展示，列为：机器人编号、状态。
- 行操作：「数据记录」按钮。

### 【操作步骤】

1. 进入页面，默认显示「按客户」视图，统计看板和列表自动加载。
2. 点击左上角切换视图按钮，切换到「按行业 / 按工艺 / 未部署」。
3. 如需筛选，在右侧下拉框中选择条件，列表自动刷新。
4. 如需查看某台机器人的生产数据，展开对应分组行（按客户/行业/工艺视图）或直接点击行操作（未部署视图）中的「数据记录」。
5. 点击「重置」按钮可清空所有筛选条件。

### 【校验规则】

- 公司 ID、业务员 ID、运维人员 ID 等必须为整数。
- `list_type`（列表类型）为必填，取值范围 1（客户）、2（行业）、3（工艺）、4（未部署）。

### 【状态说明】

- 嵌套表格中的机器人状态会根据状态码显示对应文本和颜色。
- 统计看板数据随筛选条件变化而实时更新。

## 三、机器人硬件（robotHardware）

### 【用途】

独立管理机器人的硬件信息档案，包括机械臂、控制箱、物联网卡、GPS 模块、路由器、远程码等。支持新增、编辑、删除和批量导入。

> 注意：此页面标注「此页不开放所以不更改」，实际硬件信息的维护建议在「机器人列表 → 硬件信息」页签中操作。此独立页面保留但可能受限。

### 【页面路径】

主菜单 → 机器人管理 → 机器人硬件（如菜单可见）

### 【主要功能】

#### 筛选条件

- 搜索框：下拉选择「机器人编号 / 机器臂」，输入关键字搜索。
- 添加硬件信息按钮。

#### 表格列

机器人编号、机器臂 SN、控制箱 SN、MAC 地址、物联网 SIM、物联网卡 ICCD、物联网 IMEDI、GPS-IMEI。

#### 行操作按钮

- 编辑：打开硬件编辑弹窗。
- 删除：删除该条硬件信息（需确认）。

### 【操作步骤】

#### 操作 1：添加硬件信息

1. 点击「添加硬件信息」按钮。
2. 在弹窗中填写硬件信息（字段见下方校验规则）。
3. 点击「确定」提交。

#### 操作 2：编辑硬件信息

1. 点击行操作中的「编辑」按钮。
2. 修改需要更新的字段。
3. 点击「确定」提交。

#### 操作 3：删除硬件信息

1. 点击行操作中的「删除」按钮。
2. 弹出确认框，点击「确认」删除。

### 【校验规则】

| 字段 | 规则 |
|------|------|
| 机器人编号（robot_no） | **必填**，最大 32 字符 |
| 机器臂 SN（robot_arm_sn） | **必填**，最大 50 字符 |
| MAC 地址 | 选填，最大 50 字符 |
| 物联网（银尔达）SIM | 选填，最大 50 字符 |
| 控制箱 SN | 选填，最大 50 字符 |
| 物联网卡/云兔 ICCD | 选填，最大 50 字符 |
| 物联网卡 IMEDI | 选填，最大 50 字符 |
| GPS IMEI:SN | 选填，最大 50 字符 |
| 物联网卡 | 选填，最大 200 字符 |
| 工业路由器 SN | 选填，最大 200 字符 |
| 物联网卡套餐到期日 | 选填，必须为有效日期格式 |
| codesys 授权码 | 选填，最大 200 字符 |
| RUSTDESK 远程码 | 选填，最大 200 字符 |
| 供应商名称 | 选填，必须为大于 0 的整数（供应商 ID） |
| 备注 | 选填，最大 500 字符 |

> 批量导入时必须使用系统提供的模板，表头需完全匹配，否则会提示「导入文件格式错误」。

### 【状态说明】

- 删除操作为软删除，可通过数据库恢复（联系技术支持）。
- 导入失败的数据会生成《失败详情文档》供下载查看。

## 四、日结核签（dailySettlement）

### 【用途】

按日维护机器人的生产结签数据，用于后续的产能核算和客户对账。每天的生产数据需要人工确认「签核工时/件数」后方可生效。

### 【页面路径】

主菜单 → 机器人管理 → 日结核签

### 【主要功能】

#### 筛选条件

- 新建按钮：新建一条日结记录。
- 日期时间段：日期选择器。
- 创建人：下拉筛选。
- 客户：下拉筛选。
- 场地：下拉筛选。

#### 表格列

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 日结时间段 | 可点击，点击后跳转到「结算详情」页面 |
| 创建人 | 创建该日结的人员 |
| 客户 | 关联的客户名称 |
| 场地 | 关联的场地 |
| 场地负责人 | 该场地的负责人 |
| 上次修改时间 | 最后一次修改时间 |
| 上次修改人 | 最后一次修改人 |

#### 行操作按钮

- 删除：删除该日结记录（需有删除权限）。

### 【操作步骤】

#### 操作 1：新建日结

1. 点击「新建」按钮。
2. 在弹窗中选择客户、场地、日结时间段等信息。
3. 点击「确定」提交，新日结记录出现在列表中。

#### 操作 2：进入结算详情

1. 点击表格中「日结时间段」列的链接，或点击该行任意位置。
2. 页面跳转到「结算详情」，展示该日结下的工位级结签数据。

#### 操作 3：删除日结

1. 点击行操作中的「删除」按钮。
2. 确认后删除。

### 【校验规则】

- 删除操作需要 `delDaily` 权限。
- 日结时间段不可与已有记录重叠。

### 【状态说明】

- 点击日结时间段时，如果系统检测到所选时间段内有机器人生产但未维护日结，会弹出提示「您选择的场地在时间段 XX 有机器人生产但未维护日结」，可选择「重选日结时间段」或「忽略」。

## 五、月结核签（monthlySettlement）

### 【用途】

按月汇总各工位的结签数据，支持导出 Excel 用于客户对账和财务核算。

## 六、结算详情（settlementDetails）

### 【用途】

### 【主要功能】

#### 筛选条件

- 导出 Excel 按钮。
- 添加数据按钮：添加一条新的结签数据。
- 工位编号：下拉筛选。
- 工位名称：下拉筛选。
- 机器人编号：下拉筛选。
- 结算模式：下拉筛选（计时/计件）。
- 状态：下拉筛选。

#### 表格列

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 工位编号 | 工位编号 |
| 工位名称 | 工位名称 |
| 机器人编号 | 机器人编号 |
| 结算模式 | 计时 或 计件 |
| 系统工时(H)/件数 | 系统自动统计的数据 |
| 签核工时(H)/件数 | 人工确认的数据 |
| 签核文件 | 可点击查看签核附件 |
| 状态 | 审核状态 |

#### 行操作按钮

| 按钮 | 权限 | 说明 |
|------|------|------|
| 审核 | `approvalDaily` | 弹出确认框「认可系统工时/件数、签核工时/件数？」，点击「认可」后该条数据变为已审核 |
| 反审核 | `deApprovalDaily` | 弹出确认框「此日结数据已审核，确认反审核？」，确认后恢复为未审核 |
| 编辑 | `updateDaily` | 打开编辑弹窗，修改签核数据 |

### 【操作步骤】

#### 操作 1：审核结签数据

1. 在列表中找到状态为「未审核」的记录。
2. 点击「审核」按钮。
3. 弹出确认框，显示「认可系统工时(H)/件数、签核工时(H)/件数？」。
4. 点击「认可」完成审核，状态变为「已审核」。
5. 如不认可，点击「不认可」取消。

#### 操作 2：反审核

1. 找到状态为「已审核」的记录。
2. 点击「反审核」按钮。
3. 弹出确认框「此日结数据已审核，确认反审核？」。
4. 点击「确认」恢复为未审核状态。

#### 操作 3：编辑签核数据

1. 点击「编辑」按钮。
2. 在弹窗中修改签核工时/件数等字段。
3. 点击「确定」保存。

#### 操作 4：添加数据

1. 点击「添加数据」按钮。
2. 在弹窗中填写工位、机器人、签核数据等信息。
3. 点击「确定」提交。

#### 操作 5：导出 Excel

1. 点击「导出 Excel」按钮。
2. 系统生成并下载 Excel 文件。

### 【校验规则】

- 审核操作需有 `approvalDaily` 权限。
- 反审核操作需有 `deApprovalDaily` 权限。
- 编辑操作需有 `updateDaily` 权限。
- 添加数据需有 `addDailyInfo` 权限。
- 导出需有 `exportDaily` 权限。

### 【状态说明】

- **未审核**：数据已录入但未经人工确认，可编辑。
- **已审核**：数据已经人工确认，不可直接编辑，需先「反审核」后才能修改。

## 七、警报列表（warningList）

### 【用途】

查看和处理所有机器人的故障警报记录。支持按运维人员、客户、机器人编号、状态筛选；支持手动上报故障；支持导出警报数据。

当机器人发生故障或断网离线时，系统会自动生成警报记录并推送到企业微信通知相关负责人。

### 【页面路径】

主菜单 → 机器人管理 → 警报列表

### 【主要功能】

#### 筛选条件

- 新增手动上报按钮：手动添加一条故障警报。
- 导出按钮：导出当前筛选条件下的警报数据。
- 运维人员：输入框，支持回车搜索。
- 客户名称：远程搜索下拉（带分页）。
- 机器人编号：远程搜索下拉（带分页）。
- 状态：下拉选择（全部 / 待处理 / 已处理）。
- 重置按钮：清空所有筛选条件。

#### 表格列

| 列名 | 说明 |
|------|------|
| 序号 | 自动编号 |
| 状态 | 待处理（红色）/ 已处理（绿色），带颜色标识 |
| 机器人编号 | 可点击，点击后跳转到「警报详情」页面 |
| 客户名称 | 客户名称 |
| 错误代码 | 故障错误代码 |
| 错误详情 | 故障详细描述 |
| 故障工位 | 发生故障的工位名称 |
| 机器状态 | 故障发生时机器人的运行状态 |
| 运维人员 | 负责处理的运维人员 |
| 解决方法 | 故障处理方法描述 |
| 创建时间 | 警报创建时间 |
| 处理人 | 实际处理人姓名 |
| 处理时长(分钟) | 从创建到处理完成耗时 |

#### 行操作按钮

| 按钮 | 显示条件 | 说明 |
|------|----------|------|
| 故障修复 | 状态为「待处理」且 `repairBtn` 为 1 时显示 | 打开故障修复弹窗，填写解决方法 |

### 【操作步骤】

#### 操作 1：处理故障警报（故障修复）

1. 在列表中找到状态为「待处理」的警报。
2. 点击「故障修复」按钮。
3. 弹窗中填写：
   - **处理人**：自动填写当前登录用户（如已有处理人则显示原处理人）。
   - **处理时长(分)**：输入处理耗时（只能输入数字）。
   - **解决方法**：文本框，填写故障解决方法。
   - **照片/视频**：可上传相关照片或视频（支持 png、jpg、jpeg、mp4，最多 50 个）。
4. 点击「确定」提交，警报状态变为「已处理」，提示「故障修复成功」。

#### 操作 2：新增手动上报

1. 点击「新增手动上报」按钮。
2. 弹窗中填写：
   - **客户编码**（必填）：远程搜索选择客户。
   - **机器人编号**（必填）：选择客户后联动出该客户下的机器人列表。
   - **故障代码**：自动填写（默认 10000002）。
   - **错误级别**：自动填写（默认「严重」）。
   - **处理人**：自动填写当前登录用户。
   - **处理时长(分)**：输入处理耗时。
   - **故障工位**：选择机器人后自动填写。
   - **机器人状态**：选择机器人后自动填写。
   - **错误详情**：输入故障详情描述。
   - **状态**：选择「已处理」或「待处理」。
   - **解决方法**：填写解决方法。
   - **照片/视频**：可上传附件。
3. 点击「确定」提交，提示「手动上报成功」。

#### 操作 3：查看警报详情

1. 点击表格中「机器人编号」列的链接。
2. 跳转到「警报详情」页面，查看完整警报信息。

#### 操作 4：导出警报数据

1. 设置好筛选条件。
2. 点击「导出」按钮。
3. 系统生成导出任务，完成后弹出下载提示。

### 【校验规则】

| 场景 | 校验规则 |
|------|----------|
| 手动上报 | 客户 ID 必填且为大于 0 的整数；机器人编号必填；状态必填 |
| 故障修复 | 警报 ID 必填且为大于 0 的整数；解决方法必填；处理时长为整数 |
| 上传附件 | 文件 MD5 必填；支持格式：png、jpg、jpeg、mp4；最多 50 个文件 |

### 【状态说明】

- **待处理（status=0）**：警报尚未处理，显示「故障修复」按钮。
- **已处理（status=2）**：警报已处理完成，不显示「故障修复」按钮。
- 致命级别故障会触发语音告警通知部门负责人。
- 警报未处理时，系统会每 30 分钟向上级部门逐级推送通知（最多 3 级）。

### 【用途】

通过可视化拖拽的方式，为不同设备类型设计调试页面（设备信息配置），并将设计好的页面发布到「单设备调试库」供现场使用。

### 【页面路径】

主菜单 → 机器人管理 → 上位机资源库

该模块包含两个子页面：

1. 设备信息（deviceInfo）：可视化页面设计器

### 10.1 设备信息（页面设计器）

#### 【页面路径】

上位机资源库 → 设备信息

#### 【主要功能】

这是一个**可视化拖拽设计器**，用于配置设备的调试界面。

**页面布局**

- **顶部**：预览按钮、保存按钮。
- **左侧**：设备图片展示区，可选择设备类型。
- **中间**：设计画布区域，可拖入组件。
- **组件区**：提供可拖拽的 UI 组件（按钮、输入框、指示灯、文本数据等）。
- **右侧抽屉**：点击画布中的组件后弹出，配置组件属性（如通道、控制源等）。

**操作按钮**

- 预览：进入全屏预览模式。
- 保存：保存当前页面配置。
- 退出全屏：预览模式下退出全屏。

#### 【操作步骤】

##### 操作 1：设计设备调试页面

1. 进入设备信息页面。
2. 在左侧选择设备类型（或输入自定义设备名称）。
3. 从组件区拖拽需要的组件（按钮、指示灯、输入框等）到中间画布。
4. 点击画布中的组件，在右侧抽屉中配置：
   - 组件名称
   - 通道类型
   - 控制源绑定
   - 其他属性
5. 可添加「区域模块」组件对多个子组件进行分组。
6. 点击「预览」查看效果。
7. 确认无误后点击「保存」。

##### 操作 2：保存页面

1. 确保已选择设备或输入自定义设备名称。
2. 确保所有组件信息完整（名称、通道等必填）。
3. 点击「保存」按钮。
4. 如果未选择设备，系统会提示「检测到你正在进行无设备保存」，确认后需输入自定义设备名称。
5. 保存成功后，页面跳转并带上页面 ID。

#### 【校验规则】

- 组件的按钮名称、通道等信息必须完整，否则保存时会提示「请填写完整的设备按钮信息」。
- 区域模块组件不能为空，否则提示「不能提交空的组件」。
- 组件名称不能缺失，否则提示「请填写完整的组件名称」。
- 如检测到老版本数据，会提示「建议你重新绑定控制源」。
- 物料编码（material_number）最大 64 字符。
- 发布状态（status）取值为 -1（未发布）或 1（已发布）。

#### 【状态说明】

- 保存时如果是从已有页面进入（带 id 参数），则为编辑模式，会更新原有页面。
- 如果是新建设备页面，保存后生成新的页面 ID。

### 10.2 单设备调试库

#### 【页面路径】

上位机资源库 → 单设备调试库

#### 【主要功能】

**筛选条件**

- 搜索/筛选区域：支持按页面名称、状态、创建时间筛选。

**列表展示**

以卡片形式展示已保存的设备调试页面，每个卡片包含：
- 设备图片
- 设备名称
- 创建时间
- 状态（已发布/未发布）

**卡片操作**

- 发布/取消发布：切换页面的发布状态。
- 编辑：跳转到设备信息设计器编辑该页面。

#### 【操作步骤】

##### 操作 1：发布/取消发布页面

1. 在列表中找到目标页面。
2. 点击「发布」按钮（未发布状态时显示）或「取消发布」按钮（已发布状态时显示）。
3. 弹出确认框，确认后状态切换。
4. 提示「发布成功」或「取消发布成功」。

##### 操作 2：编辑页面

1. 点击卡片上的编辑入口。
2. 跳转到设备信息设计器，加载该页面的配置。
3. 修改后保存。

#### 【校验规则】

- 发布状态切换需确认操作。
- 页面列表支持分页。

#### 【状态说明】

- **未发布（status=-1）**：页面已保存但未对外可见，可继续编辑。
- **已发布（status=1）**：页面已发布，现场设备可使用该调试页面。

### 常见问题

#### Q1：机器人列表状态不更新怎么办？

A：机器人状态页签每 10 秒自动刷新一次。如果状态长时间不更新，可能是机器人网络断开（状态会显示「断网离线」），请检查机器人网络连接或联系运维人员。

#### Q2：强制停机后如何恢复？

A：在机器人列表中找到该机器人（状态显示「强制停止状态」），点击「解除停机」按钮，确认后即可恢复。

#### Q3：硬件信息导入失败怎么办？

A：请使用系统提供的标准模板进行导入。如果表头不匹配，系统会提示「导入文件格式错误，请下载模板导入」。部分数据导入失败时，系统会生成《失败详情文档》供下载查看具体原因。

#### Q4：日结数据审核后发现错误怎么办？

A：在「结算详情」页面，找到已审核的记录，点击「反审核」按钮，确认后该数据恢复为未审核状态，然后点击「编辑」修改数据，修改完成后重新「审核」。

#### Q5：警报一直没人处理怎么办？

A：系统会每 30 分钟自动向上级部门逐级推送通知（最多 3 级）。致命级别故障还会触发语音告警。如果仍未处理，请联系相关运维人员或上级主管。

#### Q6：定位频率设置多少合适？

A：定位间隔可设置为 5~120 分钟。建议根据实际需求设置：频繁定位会增加设备功耗和流量消耗，通常建议设置为 20~60 分钟。

#### Q7：机器人调试状态下的数据会结算吗？

A：不会。当机器人处于「调试状态（15）」或「调机试产（5）」时，生产数据不会进入结算流程，系统会标记为「调试状态不做结算」。

#### Q8：如何查看 SIM 卡流量使用情况？

A：在机器人列表中切换到「SIM 卡信息」页签，可以查看每张 SIM 卡的总流量、已用流量、剩余流量、套餐到期时间等信息。支持按公司筛选和导出。

#### Q9：上位机版本更新后机器人没有生效？

A：版本更新指令下发后，机器人需要联网接收更新。请确认机器人处于在线状态。如长时间未更新，请联系技术支持检查网络连接和版本配置。

#### Q10：设备调试页面设计后如何使用？

A：在「上位机资源库 → 设备信息」中设计好页面后，需到「单设备调试库」中点击「发布」按钮将页面发布。发布后的页面才能在现场设备上使用。
