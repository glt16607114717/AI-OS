# 数据库字典管理

管理开发库的数据字典文件，支持查询和更新两个操作。

## 数据源

字典文件位于 `.trae/docs/db-dict/`，共 7 个文件（339 张表，每文件约 50 张），由导出脚本生成。

| 文件 | 表范围 |
|------|--------|
| db-dict-01.md | 1-50 (c_migrations ~ r_charts 系列) |
| db-dict-02.md | 51-100 (r_charts ~ r_delivery 交付模块) |
| db-dict-03.md | 101-150 (r_delivery ~ r_log 日志模块) |
| db-dict-04.md | 151-200 (r_log ~ r_pay 支付模块) |
| db-dict-05.md | 201-250 (r_post ~ r_sale 销售模块) |
| db-dict-06.md | 251-300 (r_setting ~ r_work_flow 流程模块) |
| db-dict-07.md | 301-339 (r_work_flow ~ r_yunying 运营模块) |

## 操作一：查询表结构

用户问某张表的字段、类型、注释等信息时，直接从字典文件中读取。

**步骤**：

1. 用 Grep 在 `D:\wwwroot\.trae\docs\db-dict\` 目录搜索 `## 表名` 定位到具体文件
2. 用 Read 读取该文件中对应表的内容（每个 `## 表名` 到下一个 `---` 之间即为该表的完整结构）
3. 将结果直接展示给用户

**示例**：用户问"r_customer 表有哪些字段"
- Grep 搜索 `## r_customer`，定位到 db-dict-01.md
- Read 该文件，提取 r_customer 的字段表

**批量查询**：用户一次问多张表时，逐个查询汇总。如果表名不确定，先 Grep 模糊搜索。

## 操作二：更新字典

用户要求重新导出或刷新字典时执行。

**命令**：

```powershell
python .trae/skills/db-dict/scripts/export_db_dict.py
```

**说明**：

- 脚本连接开发库 `172.16.90.62:3306/dev_nndrobot_20251027`，导出全部表结构
- 输出到 `.trae/docs/db-dict/`，自动覆盖旧文件
- 每文件 50 张表，只包含字段结构（不含索引）
- 执行后报告文件数量和大小即可

## 注意事项

- 字典文件是静态快照，不会实时同步数据库变更，需要用户手动触发更新
- 查询时优先从字典文件读取，速度远快于直接查数据库
- 如果字典文件不存在或用户反馈数据过时，提示用户执行更新操作
