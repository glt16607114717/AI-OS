# README 自动生成规则

本文件定义 `docs/` 下各子目录 `README.md` 的生成模板、链接格式和增量同步策略。仅在 Step 2 索引生成阶段读取。

---

## 1. 场景判断

根据目录实际内容选择对应模板：

| 目录内容 | 使用模板 | 说明 |
|---------|---------|------|
| 含子目录 / `.md` / `.html` 文件 | 文档索引模板 | 包含文档索引表 |
| 仅含 `.gitkeep`（或完全空） | 空白占位模板 | 仅包含"暂无文档"提示 |

### 跳过规则

以下目录**不生成** README.md：
- `assets/` 及其子目录
- 已存在 README.md 的目录
- **静态原型站目录**（存在 `index.html` 且不存在 `README.md` 和 `_sidebar.md`）

### 递归范围

必须对 `docs/` 下**所有层级**子目录检查，不能只扫描一级。额外扫描含 `.gitkeep` 的占位空目录，为它们生成占位 README.md 防止导航 404，并提示用户可删除对应的 `.gitkeep`。

---

## 2. 模板

### 文档索引模板（目录含实际文档内容时使用）

```markdown
# {目录显示名}

> {一句话描述该目录的用途}

## 文档索引

| 文档 | 说明 |
|------|------|
| [{子目录显示名}](./{子目录名}/) | {子目录简述} |
| [{.md 文件标题}](./{文件名}.md) | {.md 文件简述} |
| <a href="/{docs下的绝对路径}/{文件名}.html" target="_blank">{原型标题}原型</a> | {原型简述} |
```

### 空白占位模板（目录仅含 `.gitkeep` 或为空时使用）

```markdown
# {目录显示名}

> {一句话描述该目录的用途}

## 文档索引

| 文档 | 说明 |
|------|------|
| 暂无文档 | 待补充 |
```

---

## 3. 文档索引表条目类型

索引表包含三种条目类型，**必须全部检查，缺一不可**：

| 条目类型 | 链接格式 | 排序位置 |
|---------|---------|---------|
| 子目录 | Markdown 相对链接 `[{显示名}](./{子目录名}/)` | 按目录名字母序排列 |
| `.md` 文档 | Markdown 相对链接 `[{标题}](./{文件名})` | 排在子目录之后 |
| `.html` 原型 | HTML `<a>` 标签 + **绝对路径** `<a href="/{docs下的路径}" target="_blank">{标题}原型</a>` | 排在 .md 之后 |

### 链接格式汇总

| 文件类型 | 链接格式 | 示例 |
|---------|---------|------|
| `.md` 文档 | Markdown 标准相对链接 | `[{标题}](./{文件名})` |
| `.html` 原型 | HTML `<a>` 标签 + **绝对路径** | `<a href="/{docs下的路径}" target="_blank">{标题}</a>` |
| 子目录 | Markdown 标准相对链接 | `[{标题}](./{子目录名}/)` |

---

## 4. HTML 原型链接规则

**关键约束：HTML 原型文件必须使用绝对路径（以 `/` 开头），禁止使用相对路径（`./`）。**

原因：Docsify 是 SPA 单页应用，会拦截所有相对路径链接点击并当作路由处理，导致 `.html` 文件返回 `Cannot GET` 错误。绝对路径让 Docsify 静态文件服务正确代理 `.html` 文件。

绝对路径计算方式：从 `docs/` 根目录开始拼接。例如 `docs/prd/02-CRM/新增字段弹窗.html` → `/prd/02-CRM/新增字段弹窗.html`。

### URL 编码规则

路径中的空格使用 `%20` 编码。例如 `docs/prd/12-BI 中心/报表.html` → `/prd/12-BI%20中心/报表.html`。

中文字符**保持原样不编码**（docsify-cli 和现代浏览器均支持 UTF-8 URL）。

---

## 5. 多级目录处理策略

- **包含子目录的目录**（如 `02-CRM/`）：README 的文档索引表中，子目录条目链接指向 `./{子目录名}/`，普通 `.md` 文件条目链接指向 `./{文件名}`
- **叶子目录**（只有文档文件、没有子目录的最底层目录）：如果该目录下只有一个 `.md` 文件，README 仍需生成作为目录索引页，确保 Docsify 路由能正确解析

---

## 6. 增量同步机制

对每个**已存在** README.md 的目录，执行以下对比检查：

1. 扫描该目录下实际存在的 `.md` 文件、`.html` 文件、子目录
2. 解析已有 README.md 中「文档索引」表格的现有条目
3. **新增文件/目录**（实际存在但未出现在索引表中）→ 追加到表格末尾
4. **已删除文件/目录**（索引表中有但实际不存在）→ 从表格中移除
5. **条目格式修正**（如 `.html` 文件使用了 `./` 相对路径而非绝对路径）→ 修正格式
6. 其他内容（标题、描述、非索引表部分）保持不变

对不存在 README.md 的目录 → 按模板完整生成。
