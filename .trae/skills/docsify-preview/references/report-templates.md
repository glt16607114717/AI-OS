# 输出报告模板

本文件包含技能各步骤的输出报告格式。在对应步骤执行完毕后，按模板格式输出结果。

---

## 4. 启动与分享报告（Step 4）

在 `<service_share>` 标签内输出：

```markdown
<service_share>
### 📊 文档预览服务已启动！

**服务状态：**
- 启动命令：`npx docsify-cli serve docs --port [端口]`
- 启动结果：✅成功 / ❌失败
- 最终端口：[实际端口]
- 端口处理：✅空闲 / ⚠️已终止旧进程 / 🔄切换到新端口

**访问地址：**
- 本地访问：http://localhost:[端口]
- 局域网访问：http://[局域网IP]:[端口]

**分享说明：**
💡 将局域网链接发送给同一网络下的团队成员即可访问。

**服务管理：**
- 停止服务：在终端按 `Ctrl + C`
- 服务会在关闭终端时自动停止
</service_share>
```
