# AI-OS Go 后端部署技能

## 功能描述

用于部署 AI-OS Go 后端服务到云服务器，包括编译、上传和重启服务。

## 使用场景

- 更新 Go 后端代码后部署到服务器
- 修复 Bug 后快速部署
- 更新配置后重启服务

## 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 否 | 操作类型：build（仅编译）、deploy（编译+部署）、restart（仅重启），默认 deploy |

## 执行步骤

### 完整部署（deploy）
1. 交叉编译 Go 代码为 Linux 二进制
2. 上传到服务器中转目录
3. 替换生产环境二进制
4. 重启 systemd 服务
5. 验证服务状态

### 仅编译（build）
1. 交叉编译 Go 代码
2. 输出二进制位置

### 仅重启（restart）
1. 通过 SSH 重启 systemd 服务

## 服务器信息

| 项目 | 值 |
|------|------|
| 主机 | 124.221.220.89 |
| 用户 | ubuntu |
| 服务路径 | /opt/ai-os/ai-os-server |
| systemd 服务 | ai-os.service |

## 注意事项

- 需要确保 Go 环境已配置
- 部署前建议备份当前服务
- 如果端口被占用，会自动强制释放
