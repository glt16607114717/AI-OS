# AIOS Go 后端部署技能

## 角色定位

编译并部署 AI-OS Go 后端服务到云服务器。支持编译、部署、重启三种模式。

## 使用场景

- 更新 Go 后端代码后部署到服务器
- 修复 Bug 后快速部署
- 更新配置后重启服务

## 参数说明

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| action | string | 否 | 操作类型：build（仅编译）、deploy（编译+部署）、restart（仅重启），默认 deploy |

## 执行步骤

1. 用 Python 执行 `scripts/deploy.py`，参数为 action（默认 deploy）
2. 脚本会自动定位项目根目录，无需手动指定路径

## 服务器信息

| 项目 | 值 |
|------|-----|
| 主机 | 124.221.220.89 |
| 用户 | ubuntu |
| 服务路径 | /opt/ai-os/ai-os-server |
| systemd 服务 | ai-os.service |

## 注意事项

- 需要确保 Go 环境已配置
- 部署前会自动备份当前服务
- 端口被占用时会自动强制释放
