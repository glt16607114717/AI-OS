# 企业微信消息通知技能

## 角色定位

通过企业微信发送消息通知，支持向指定人员发送开发完成通知、提测通知等消息。

## 脚本目录

所有脚本位于 `.trae/skills/wecom/`，相对于工作区根目录。

## 脚本调用方式

使用 `RunCommand` 工具执行，`cwd` 设为 `.trae/skills/wecom/`，`blocking` 设为 `true`。

## 发送方式

### 方式一：应用 API（推荐）

**适用场景**：需要 @ 具体人员，需要精确发送

```bash
python scripts/wecom_notify.py "<接收人>" "<发送人>" "<消息内容>" [TAPD链接] [消息标题]
```

**参数说明：**

| 参数     | 必填 | 说明                         |
| ------ | -- | -------------------------- |
| 接收人    | 是  | 中文姓名，多人用逗号分隔               |
| 发送人    | 是  | 发送人姓名（显示在消息中）              |
| 消息内容   | 是  | 消息文本                       |
| TAPD链接 | 否  | 需求或Bug的完整URL，不传则默认跳转TAPD首页 |
| 消息标题   | 否  | 消息标题，不传则默认为"开发完成通知"        |

**支持的接收人：**

- 侯森、刘贵财、卞成龙、向海涛、张雨凯、曾燕芳、李现成、桂良涛、梁任超、王立志、罗昭鸿、谭鸿兴、陈小东、邹兴平

**消息格式**：

消息采用 TextCard 格式发送，样式美观，包含：
- 标题：自定义（默认"开发完成通知"）
- 内容：【发送人】\n消息内容
- 链接按钮：点击跳转TAPD链接

### 方式二：Webhook

**适用场景**：群发消息，无需 @ 具体人员

```bash
python scripts/wecom_bot_notify.py "<消息内容>"
```

**参数说明：**

| 参数     | 必填 | 说明                     |
| ------ | ---- | ---------------------- |
| 消息内容   | 是   | Markdown 格式的消息文本，支持多行 |

**Markdown 支持格式：**

- 标题：# 一级标题, ## 二级标题, ### 三级标题
- 引用：> 引用内容
- 加粗：**加粗文本**
- 链接：[链接文字](链接URL)
- 列表：
  - 无序列表
  - 有序列表（1. 2. 3.）
- 代码：`单行代码`
- 分隔线：---

**注意：**
- 不支持 @用户 功能
- 不支持图片链接
- 消息长度限制：单条消息不超过 4096 字节
- 频率限制：每个机器人每分钟最多发送 20 条消息

## 消息模板

### 1. 开发完成通知（后端→前端）

**触发场景**：后端开发完成，需要通知前端对接

**标题**：开发完成通知

**消息内容模板**：

```
需求名称：{需求名称}
状态：已开发完成

请前端同事及时对接联调。
```

**调用示例**：

```bash
python scripts/wecom_notify.py "张雨凯" "桂良涛" "需求名称：交付运维统计报表中新增月出货量统计项
状态：已开发完成
开发分支：feature/1011481-monthly-shipment-stat

请前端同事及时对接联调。" "https://www.tapd.cn/66680814/prong/stories/view/1166680814001011368" "开发完成通知"
```

### 2. 提测通知

**触发场景**：功能已部署到测试环境，需要通知测试人员

**标题**：提测通知

**消息内容模板**：

```

状态：已部署到测试环境
```

**调用示例**：

```bash

状态：已部署到测试环境
开发分支：feature/1011481-monthly-shipment-stat

请测试同事进行测试验证。" "https://www.tapd.cn/66680814/prong/stories/view/1166680814001011368" "提测通知"
```

### 3. Finish 通知

**触发场景**：功能开发完成，分支已 finish 合并到 develop

**标题**：Finish 通知

**消息内容模板**：

```
需求名称：{需求名称}
开发分支：{分支名}
改动项目：{RMP/图表/两者都有}
数据清洗：{有/无}
```

**调用示例**：

```bash
python scripts/wecom_notify.py "侯森" "桂良涛" "需求名称：交付运维统计报表中新增月出货量统计项
开发分支：feature/1011481-monthly-shipment-stat
改动项目：RMP
数据清洗：无" "https://www.tapd.cn/66680814/prong/stories/view/1166680814001011368" "Finish 通知"
```

### 4. Bug 修复通知

**触发场景**：Bug 已修复并部署，需要通知测试人员验证

**标题**：Bug 修复通知

**消息内容模板**：

```
Bug名称：{Bug名称}
状态：已修复
1分钟后验证
```

**调用示例**：

```bash
python scripts/wecom_notify.py "邹兴平" "桂良涛" "Bug名称：导出报表数据缺失
状态：已修复
1分钟后验证" "https://www.tapd.cn/66680814/bugtrace/bugs/view/111" "Bug修复通知"
```

## 配置文件

### 应用 API 配置

**文件路径**：`.trae/skills/wecom/scripts/wecom_config.json`

**配置格式**：

```json
{
    "corp_id": "企业微信CorpID",
    "secret": "应用Secret",
    "agent_id": 1000015,
    "server_url": "https://testapi.nndrobot.com/admin.php"
}
```

### Webhook 配置

**文件路径**：`.trae/skills/wecom/scripts/wecom_bot_config.json`

**配置格式**：

```json
{
  "webhook_url": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx"
}
```

**获取 webhook_url：**
1. 在企业微信群中，点击右上角 "..."
2. 选择 "群机器人" → "添加机器人"
3. 复制生成的 Webhook 地址
4. 将地址填写到配置文件中

## 注意事项

1. **依赖要求**：需要安装 `requests` 库，使用命令：`pip install requests`
2. **配置安全**：配置文件不要提交到版本控制，建议添加到 `.gitignore`
3. **签名验证**：脚本会自动生成签名，无需手动处理
4. **网络要求**：需能访问测试服务器 `https://testapi.nndrobot.com`
5. **结果提示**：发送消息必须返回结果，成功或失败都需给出明确提示；部分用户发送失败时，需列出失败用户名单
